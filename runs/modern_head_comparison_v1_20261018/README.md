# 检测头与入网联合比较：实现与交付 v1

2026-10-18。按10月15日已确认方案实现，真实实验尚未开始。本包比较 MLP/QUERY_BCE、官方 TabM v0.0.3、LightGBM 4.6.0；再将事前固定的 TabM、LightGBM 接入既有受约束入网模块。资源及运行入口已经配置，目标环境和完整远端资产仍须核验。验证状态见同目录 `validation.json`。

## 固定比较

- 三者同用768维RECENT表示＋14维当前包描述；原FIT/CAL/目标UID、normalizer、训练和评价权重含义保持。
- seeds为27、127、227。MLP与TabM各40轮、batch256；LightGBM固定尝试500轮，不早停或按目标结果选择终点。TabM为k32、3blocks、width512、dropout0.1，无数值嵌入；每成员分别计算加权BCE后平均。树训练使用N×w，不再额外类别平衡。
- TabM内部平均概率用稳定log-sigmoid/logsumexp转换为logit；外部三seed用float64平均logit。每头/seed/ensemble只在源CAL正常样本定阈值，严格score>cut。
- 所有候选均报告原池级、设备级及攻击组保护要求，不按A/B各自选开关，不自动选赢家。第一批是固定配方比较，不声称各模型充分调优。
- TabM和LightGBM各跑OLD_BANK/B0/B1/B2四库；同一头各策略共用一次源侧封存参数，两头各自按同一规则校准尺度。参考库来自已完成入网v1r1，复用相同参考、E3、q14，不重新解码或提特征。

## 运行顺序及产物

P核验现有输入 → 逐模型/seed训练或核验复用（最多九终点）→ K源校准/全池评价 → TabM入网配对 → LightGBM入网配对。每个训练任务及每个模块组合是独立子进程；K内逐模型加载、评分、释放。头产物封存在 `runs/modern_heads/heads`，模块结果另存，监控不写入封存树。

MLP复用只在原包/输入/配方/权重身份成立、原运行已封存的完整数值runtime指纹与当前相同、且CAL/CIC/UNSW逐位回放通过时采用。旧QUERY_TAIL包未强制保存该指纹，通常会明确记录 `BASELINE_NUMERIC_RUNTIME_FINGERPRINT_UNAVAILABLE` 并重训共同MLP；此时共九个新终点，不冒称省去三次训练。数据/封存损坏直接停止，不作为重训掩盖的理由。

每池共用一份UID保存全部头分数，避免九头重复完整身份。输出含端点、训练日志、逐行分数/决定、各头阈值与门槛、设备/协议组、成本、完整同头配对与修正轨迹。导出包含关键结果并校验SHA；运行缓存仍依赖父资产，精简结果包不能替代它们。

## 资源与环境

8CPU/16GiB，4数值线程，单重阶段进程；总RSS保护14GiB。旧P/评价预算复用，新增训练阶段按模型/矩阵/映射估计；完整峰值仍待实测，见 `RESOURCE_BUDGET.md`。运行磁盘8GiB、导出6GiB、启动空闲16GiB。

72小时Slurm/70小时程序保护仅为上限。生成输入5步TabM测量均值约0.5094秒，三seed更新纯算术约41小时，不含真实读取、生产检查、评分及模块，不能保证整包72小时完成；不因时间不足静默减少轮数或seed。

沿用只读Python3.9/NumPy2.0.1/Torch2.5.1基础环境，新增库安装至本包 `extra_deps`，不升级旧环境。离线轮子含LightGBM4.6.0、真实rtdl-num-embeddings0.0.12、SciPy1.13.1及typing_extensions4.14.1。LightGBM Linux轮子要求x86_64、glibc≥2.28；远端尚未确认，若不支持需另立构建修订，不能声称当前环境已兼容。官方TabM源码及Apache许可证已固定；旧兼容shim未随包使用。
