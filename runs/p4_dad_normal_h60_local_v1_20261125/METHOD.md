# DAD 正常查询的本地相对握手回检

只读取作者周一、周日 PCAP 和对应标签。周一前 7,200 秒取冻结库中的 1,264 条 TCP 参考，覆盖 16 个通信组件。周一建档后 8,448 条与周日 9,325 条正常 TCP 查询分别评价。逐日按真实帧顺序重建设备状态和双向握手；首个正式查询为周一第 1,305 帧。两日完整 TCP 查询与参考按原始 UID 清单验收。

采用冻结三种子 MLP、CIC 源阈值和原跨度。在相同包上比较 RAW、原三空间 CCNR、增加 60 秒相对握手的 CCNR，使用冻结的 TCP SYN 修正弃权、双组件支持、p=4 及 λ=0.25。报告各日及合计的原告警数、修正后误报、相对于原 CCNR 的增减。握手距离和范围使用原来的对数比和严格三倍界。

预检保留全部 TCP 参考，查询使用各日最前八条、在全日等距取十六个序号，并纳入所有正常 SYN 修正弃权帧。逐条核对三空间支持度和相对握手支持度。正式阶段复用同 UID 的已封存编码，在两日分别核对原冻结系统四列的误报、支持覆盖及弃权计数。原始数据在本地数据缓存，编码、判决及验收回执保存在 D 盘独立批次。
