# Prism 交接文档目录规范

固定目录：`runs/prism_handoffs/`

## 命名规则
- 一级目录按日期：`YYYY-MM-DD`
- 交接文档文件名保持 `handoff_for_prism_*.md`

## 当前文档
- `2026-03-28/handoff_for_prism_tailreg_results.md`
- `2026-03-30/handoff_for_prism_strongerood_calibration_tailreg.md`

## 使用建议
- 以后新的 Prism 交接文档只放这里，不再分散到各个 run 目录。
- 如果文档引用具体实验数据，正文里写对应 run 绝对路径即可。
