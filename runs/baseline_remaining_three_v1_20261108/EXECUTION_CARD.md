# 六基线最后三方法：独立资源门后自动训练评价

结果：本执行卡固化 TabM、TabR、Disent-AD；ModernNCA 按用户要求退出。当前本地回归通过，Linux/GPU 门在作业内实际执行后才可放行。
影响：主模型、源 FIT/CAL、目标样本与原有三基线工件不修改。不做超参数搜索，不下载作者论文数据集，不根据目标效果删掉方法。
下一步：共享真实预检后，各方法独立整轮资源检查；通过一个立即训练和评价一个。

## 数据与评价

- 同一封存 shared790，源 FIT 617908 行；无监督 Disent-AD 仅使用其中 134493 条正常。CAL 正常 33147 行只做同口径加权 1% 阈值，严格 `score > cut`。
- TabM/TabR 保留作者源验证准确率早停（连续超过 16 轮无改善）。先在 FIT 内按 capture/session/component 整组划分，选轮次，再重置初始化，在全部 FIT 重训相应轮数；每种子独立执行。源编码器曾见过内验证数据，因此该验证只用于分类头停止，并非独立编码器评价。
- 整组划分约束每设备/类别两侧覆盖；至少两独立组的协议子类同样两侧覆盖；单组协议保留训练、明确列为验证不可覆盖。不能按行拆开会话补覆盖。约束不可行则停止该监督链，Disent-AD 不受其阻塞。
- 共享790沿用既有源归一化；不额外应用 TabR 官方原始表格的 quantile 或 Disent 的逐行归一化。这是输入适配，不能称作者论文数据集逐项复现。
- 固定三种子 27/127/227 及 ensemble，报告 A/B full、post-window primary、逐设备、普通/加权指标；Edge 普通/HT、HTTP/UDP；RAW AUROC/AUPRC。A/B 是开发评价，Edge 已用于开发诊断。完整主系统另有正常参考库访问，与 RAW 基线的信息差异必须披露。

## 作者实现与参数

- TabM：原 `TabM.make`，无数值嵌入选项，32成员、每成员交叉熵、均值概率，AdamW 0.002/0.0003、batch256、clip1、patience16。
- TabR：官方归档 CA/adult default 同一固定参数（d265/context96/batch256；详 CONFIG）。归档 `mixer_dropout` 显式兼容映射到当前原类唯一的 context 概率 dropout；不宣称查到了历史更名提交。原类 AST、全候选、训练自身排除、memory-efficient 重计算均保留。权重衰减保留官方 deep.py 为论文兼容主动留下的全部参数行为。
- TabR 使用官方 CPU FAISS `IndexFlatL2`，GPU 做网络计算，边界只搬运键/查询/索引；不是 GPU FAISS，不是近似检索，不采样候选。通过 CPU/混合执行小样本分数对照和实测全库整轮才能放行。
- Disent-AD：明确采用作者 breastw/wbc/wine 现成 patch1、dim128、双头、norm-none、batch64、100轮配置来适配790维；Adam 1e-4。按最低平均训练 batch loss 保存，绝不采用作者控制台“最佳测试 AP”选择规则。不能声称这是作者针对790维给出的最优配置。

## 资源与恢复

共享预检：amd，8CPU、24GiB、2小时；真实解码、编码、距离/评价链、输入身份和 SHA、整组划分。大数组通过超算内只读链接复用。

每方法：1张 RTX4090、8CPU、32GiB、7天硬上限，资格阶段最多6小时。先独立进程恢复 CPU/CUDA RNG、模型和优化器，检查更新和预测一致；再完整真实 FIT 一轮、CAL/A/B/Edge 小切片预测和源阈值。记录主存/显存/时间，显存须留15%、主存留3GiB。按实测100轮规划视窗（三种子，监督含选轮+重训）乘安全系数估算，不足预算不放行。

7天是分配上限，非预期耗时；任务完成即释放。每128步及每轮保存模型、优化器、随机状态、排列、游标、早停计数。1000轮仅为工程保护上限，未满足早停不能当作完成。资源检查产生的模型不进入正式结果。既有 DTE/SLAD/CatBoost 包不热改。

进度由普通客户端持续更新，停止显示错误并保留回执。上传、提交、资源通过、正式训练完成、正式评价完成分别记账；只取回小 JSON 和 SHA 清单。
