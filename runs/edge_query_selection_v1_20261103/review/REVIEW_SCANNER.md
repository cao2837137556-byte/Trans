## 已核对实现

- 原包按原顺序全解码，输入 SHA/大小与既有卡相符；合法端点由既有完整 eligibility mask 确定，full/primary 两份有序 UID 摘要均重新匹配。扫描不加载 encoder，不生成数值快照。
- UID 沿用原包 SHA、原始物理帧号和 owner；component 沿用 `digest([owner, old_key(event)])`，与冻结实现一致，不把跨 capture 的 namespace 计数冒充 component。
- 正常 spool 只含 post-7200 合法位置；首窗用于参考，既无重复编码计数，也不计入正常查询分母。输出明确将原 FULL 正常比率标为不可由本样本评价。
- 哈希最小查询由负 hash/UID 最大堆维护；每组完成后检查名额、每角色 UID 唯一并按 UID 排序输出。gzip 使用固定 mtime=0、空 filename、显式 LF，不把 wall clock 混入压缩字节。
- 全部抽中元数据、UID 和帧调度清单相互连接；人口估计保存精确有理包含概率，正常回退的 C/K 因子已在核心中实现。
- 从原封存读到：正常 TCP 19,503 + UDP 497 = 20,000；HTTP SYN 8,092、PSH+ACK 8,882、ACK-only 1,026、FIN 1,000、RST 1,000；UDP 20,000。

## 可在无评分时登记的区间规范

- 主点估计保持 HT 扩张错误总量除以已知完整人口 N。完整组件分层样本的设计方差为 `Σ_h N_h²(1−m_h/N_h) S_h²/m_h / N²`。m_h≥2 时可用所抽 binary 误差的组内样本方差；m_h=1 且 N_h>1 时该组方差不能从一个观测识别，可预登记 bounded binary 上限 `floor(N_h²/4)/(N_h*(N_h−1))`；N_h=m_h=1 的贡献为零。若转入组件回退，方差还须包含两阶段取样，不能照用单阶段公式。
- 主 agent 拟定的 60s 非重叠时间块、2,000 次、seed=20261103，可作为**条件时间敏感性分析**：块按各 capture/scenario 原始最早时间锚定，分 capture/scenario 独立重采样，不跨边界混合。块宇宙应来自完整候选元数据，包含“有候选但零抽中行”的块，不能只列有抽中行的块。
- HTTP 仅约 271.93s、UDP 约 400.91s，即约 5/7 个 60s 块；这些不是独立重复攻击事件。固定 2 倍相关性膨胀不能保证 0.3pp 半宽；此敏感性区间不得冒充完整调查设计方差、独立事件置信区间或精度保证。
- 如完整设计区间暂未实现，应在正式评价执行卡保持明确待办；不影响只读选取或有界 Linux 工程预检，也不授权提前发布外部效果。
