## 封存与复现

```text
python -X utf8 -B runs/edge_query_selection_v1_20261103/select_queries.py --output <new-output-directory>
```

默认解码器为本机既有 TShark；异地可显式传 `--tshark`。原路径映射与原包必须满足冻结卡的 SHA。选取不删除未选包的因果上下文，不做模型输入去重。完整元数据 spool 留在本地取证目录，不进 Git/作业包；清单、源码、UID封存和小型核验回执入作业包。

`QUERY_SELECTION_SEAL.json` 为 f=1 的基准候选封存；不得原地重写。如 Linux 纯工程吞吐要求缩量，三份定额使用同一个整数 K（10,000–20,000），同一盐和规则重新生成一个有父封存身份的新版本；参考仍为4,124。最低定额仍超24小时即停止，不自动延时、重投或看分数再调整。

## 报告边界

- 样本比率只表示选中的查询；人口估计使用已知全 N 和逆纳入概率，未选包不当正确阴性。
- 正常组件回退必须补上 C/K：人口扩张系数 C*N_g/K；不得仅用 N_g。当前 B 分支则为 N_g/m_g。
- 首窗参考不计入 post-window 测试分母。本轮不能估计完整首窗+后窗的 normal FULL FPR，明确记 `NOT_EVALUABLE_FROM_THIS_POSTWINDOW_SAMPLE`。
- 60秒块、2,000次、固定种子20261103的预登记只定义条件性时间敏感性分析；HTTP约5块、UDP约7块，不能承诺0.3pp半宽或独立攻击事件区间。完整设计方差与抽样权重的正式评价路径仍待全量 worker 接通及验证。

未加载模型、未训练、未提交超算；旧 C5 和 A/B 46项冻结资产 SHA 未变。Linux 小切片通过也不自动授权或启动60,000条查询的正式评价。
