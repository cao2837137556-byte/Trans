# 同服务的 1% 连接级阈值校准

复用 formal_20261122_402788 的 4,096 条冻结正常参考和原 v12 三个检测头。先核对两小时截止帧、参考 UID、参考 SHA、三头、原归一化、源阈值和评分。新启动同一 WSL 登录服务，沿用相同实现、地址、MAC、端口、URL 及测试账号。两个独立采集文件均由这个新进程生成。

校准和正常留出各约 60 分钟，用不同固定随机种子。沿用建档期的三客户端、32–89 秒随机间隔及 76:12:5:7 的正常行为抽样权重，分别对应成功登录、同连接纠错、重建连接纠错和合法重连。两段之间保留至少 60 秒静默，阈值及校准回执封存后启动留出采集。纳入的正常请求和连接由客户端、原帧和服务端日志核对。上批每分钟 1、3、5、8 次的突发重连仅作独立压力测试。

三组为 RAW、原 CCNR、CCNR＋相对握手。共同保留 v12 分数、双组件搜索和已封存的扣分参数，第三组采用原 ln(3) 握手距离。每组在相同校准 UID 和 TCP 连接上分别定阈值。先对每个连接取其纳入请求的最高分，设有 N 条连接，最多允许 floor(N/100) 条报警。阈值取连接分数降序第 floor(N/100)+1 名，分数严格大于阈值才报警。同分按同一个数值阈值完整处理。集成是主结果，单种子另列。留出批次和旧压力测试共用本次封存阈值；同时在原 CIC 源阈值下各自报告。

已有攻击记录按同一登录端点、独立采集、请求和连接标签同时核查。不具备资格时，攻击检出标为待测。CIC、UNSW、Edge 的原场景按冻结口径复核已验收的泛洪检出和正常误报，保留原分母和 CIC 阈值。
