# 冻结 v12 的 60 秒连接历史回放

本轮用冻结 v12 的判决对照全局减轻扣分。训练、模型选择和目标阈值重标定次数均为零。

- **主规则**。在每个冻结的采集时钟分段内，对当前入站 TCP 查询，计 \((t_i-60s,t_i]\) 内同一源 IP、同一受保护设备、同一目的端口的合格入站不同有向五元组。当前帧计入，同时间戳未处理的帧留给后续查询。相同元组的重传或重复业务包在活动窗内只记一次。长期活跃元组可反复出现在不同查询的统计中。三次握手另用已见 SYN、反向匹配的 SYN+ACK、再正向确认 ACK 的序列校验，计窗内可证实启动并完成的入站握手元组。它只供解释。
- **源门槛**。在原 CIC CAL 的 16,430 条正常 TCP 查询上，使用与源校准一致的设备→活动→采集→会话→查询层级，条件到该 TCP 子集后归一。出站查询的主指标记 0，并保留其在该 TCP 子集的权重。加权经验 P99.9 取累计权重首次达到 0.999 的观测值。先写出门槛和源序列回执，再启动目标全量阶段。
- **判决**。新旁路仅适用于入站 TCP，要求计数严格大于源门槛。原旁路与新旁路取 OR。命中时保留该头的 RAW，所有分数判决仍严格大于原源阈值。参考、支持度、种子、原分数、原旁路以及原 \(p=4,\lambda=0.25\) 均来自冻结资产。
- **统计**。三种子集成为主，附 27、127、227。Win10 主视图只用原旁路外带传输数据查询触发连接告警。复现可评价 18,194、RAW 有警 14,024、原 CCNR 245，目标为新规则或以上 7,012。全包副视图、Edge POST、Edge 全包、.152／.190 和三个正常主机分开统计。正常侧计逐查询净新增和该连接从零到有，预算一律用同一批已冻结查询。CIC 连接使用冻结采集内的双向会话键，UNSW 和 Edge 正常使用已绑定传输流。ToN 按原连接键和逻辑主机配对。首次告警时间从该视图首个合格包开始，用观察流的前缀时钟统计，同时附相对该连接首个 RAW 告警的时间差。
- **决策**。CIC 正常查询新增 ≤20，Edge 正常查询及连接各 ≤20，UNSW 正常查询 ≤74，ToN 三主机正常连接合计 ≤2。全局 λ 对照用三头固定原尺度以及完全相同的分数和支持。对 \([0,0.25]\) 中的二进制浮点 λ 逐查询求严格判决翻转边界，按查询或连接计入正常代价。当每个正常组均不高于新旁路的代价时取最小可行 λ。报告端点、旧六档和这个同代价点。主结论按 Win10 主视图的正确连接比较，同时报告其他攻击与泛洪的差异。
- **供体**。按原已告警且 CCNR 后撤回的查询取样本集合。在合法参考内重放原三空间距离，取两个实际支持组件及其确定性最优记录。验证较弱匹配支持度与原缓存一致。法定缺失单列。服务与客户端端口由完整双向观测辅助判定，只将有入站／出站三次握手证据的发起端标作客户端。若供体本身缺少握手证据，保留数值端口对并标明角色待核。对两供体核对是否仅观测到的客户端端口不同。临时端口分配机制及业务标签分别说明。
- **外推**。同业务合法登录和独立采集是后续验证。当前 Edge 正常为同设备原业务，ToN 跨抓包采用逻辑主机配对。两类缺口保留在结论。

正式计算前以已封存缓存和真实原帧小切片验收。原包和大数组保存在原位置或超算。本地保留小表、中文结论、SHA-256 和验收回执。
