# 固定阈值的同服务正常留出扩充

同一 WSL HTTP 登录端点使用四个独立服务实例，各按接近两小时建档的节奏录制约 65 分钟。每批覆盖成功登录、同连接输错后纠正、跨连接输错后纠正、合法掉线重连。固定随机种子和时长在正式录制前封存。批次间隔超过 60 秒。以合法请求、双向数据包、服务端认证日志一一对齐和同批连接计数为验收。短小预检使用独立服务实例。

沿用原两小时参考库、原三种子模型、原 CIC 阈值，以及上一轮的三组本地阈值。三组分别为 RAW、原 CCNR、相对握手。严格使用连接内合格 POST 的最高分，按分数严格大于阈值统计告警。预检与阈值校准样本不进入普通留出。照录原有 194 条普通留出连接、单列每个新批次、新批次合计及普通留出总计。连接级误报预算为 1%，并附请求级计数和上一轮独立合法重连压力结果。

攻击资格沿用原封存报告并核查原包目录变化。仅同端点、独立采集且请求与连接标签均可核实的既有记录可用于离线比较。本批正常留出只能估计正常侧误报。
