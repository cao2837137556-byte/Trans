## 3. 新确认的代码边界及其含义

原前缀保留每方向最多12个突发、每突发6包；后续原 `netfound_flow` 会再保留总计前12个突发。合成例中，14包仍在前缀里，转换后的包级表示只有12包，而 `flow_duration` 仍反映全部14包。

因此审计分别记录前缀、输入转换和 tokenizer 证据。**这不能证明某条真实攻击完全不可见，更不能直接归因为漏检根因。**没有准确的帧到转换/tokenizer 输出映射时，相关字段保持 INCONCLUSIVE。实际 tokenizer 来源映射适配器尚未在真实数据上验证。

源桥接器保证只调用一次迭代工厂、不请求最大指定目标帧之后的下一行，并在异常时关闭迭代器。真实解码器自己的预取不由桥接器控制；将来实际工厂必须把同样的最大帧限制传给解码器。测试未调用真实解码器。
