# UNSW 五设备固定评估输入准备

2026-09-26。输入规则、数据用途、标签依据与对照设计已冻结，可进入实现。**尚未生成逐条参考/查询UID清单，尚未进行特征提取或模型评分。** 本轮接受用户“可以”所授权的评估输入准备；不新增真实模型执行、训练、校准、下载或超算提交。

## 1. 这次具体检验什么

在同一批五台UNSW设备上，保持E3、R、Q、FULL、NO_CF、RAW及全部阈值和seed不变，只使用设备首小时的正常历史建立参考，比较后续正常误报与攻击检出。新增数据全部为参考或评估数据，训练和阈值校准均为0。
研究范围限定为**外部采集环境中的被动档案迁移**：Q及校验器训练来源排重有直接证据；外部基础预训练全量来源仍未排除，且档案没有六阶段操作日志。本实验不冒充完整主动入网、全系统完全零样本、全新攻击机制或真实同时混合流验证。

- 另核对CIC11台设备和302条捕获来源元数据，MAC及文件SHA交集均为0。共享Active采集的目录owner为空，其训练行owner按已冻结设备表核验，不能把文件名owner当作唯一物理设备。
- 旧R相关27份FIT-prefix来源清单属于24项Gotham/IoTSIM和3项ToN来源。这是该清单范围的核查，不据此声称旧R全部拟合、阈值、基础模型预训练和整个项目历史都已排重。
- 11份冻结判别器/阈值工件和本地E3 checkpoint/config字节身份已核对，没有加载模型或计算新分数。
- 五台MAC曾出现在旧UNSW元数据调研中，此事实保留。见过设备表不是训练暴露证明；缺少原始预训练清单，也不能反推绝对无暴露。
- 本次Netatmo是70:ee:50:18:34:43，之前CIC的同名设备是70:ee:50:68:0e:32。名称相同、物理标识不同；后者已消费的确认身份仍封闭。

- 正类定义为原合法输入检查通过，且官方区间、目标MAC/IP、攻击者IP、目标主服务、SYN且非ACK同时成立；属于**有来源依据的窄规则派生标签**，并非官方完整逐包真值。混合文件其它流量继续未标注，不能默认正常。工作簿异常日期保持原值，以注释epoch及文件名确定时间。
- 规则证据已核定；逐包UID和标签证据行仍须在物化阶段落盘，并与每区间/设备预封存数量相等后才允许评分。

## 3. 数据量与选择规则

保留全部五台，不按参考覆盖好坏排除设备。原983,788个后续正常合法位置作为总体清单；为控制E3特征成本，每台最多选择20,000个，少于上限则全取。每个合法canonical component至少一个位置，其余预算按组件剩余容量比例分配，整数余数确定性分配，组件内按固定UID哈希选择。没有使用模型分数、对错或新阈值。
首小时只用于参考，沿用固定3600秒、原始因果前缀、每协议至少两不同组件及总计64组上限。未观测协议不能用未来查询补库。92个参考是按已核验数量推导的预期数，实际UID及特征尚未生成。

主要正常指标按设备→UNKNOWN活动→捕获→canonical component→选中查询等权；同时报告样本原始误报率和用总体组大小校正的全位置误报率估计。后者必须标注估计，不能将75,763个抽样查询的原始比例写成983,788个全量包的精确误报率。逐设备、协议、时间块、共享/新组件和回退分层全部保留；不做包级IID置信区间。

## 4. 对照和结果解释

同一批输入及同一参考库比较Q-only、普通相似度RAW、学习校验器FULL；保留NO_CF学习消融与R上下文基线，三个seed27/127/227和ensemble算法照旧。只提取一份共享特征，不为各对照重复提取。
已按正常库存固定8个可匹配的同协议、同参考数量、时间合法的正确/错误设备参考对照；两个TCP单组条件明确NOT_ELIGIBLE。错误参考仅作诊断，不能成为部署分支，也不能用结果重新选择捐赠设备。
攻击保持要求：FULL ensemble以及每个seed相对自己的Q均无新增漏检，逐设备/区间检查；任何损失都要报告并使该保持声明失败。新档案实验的有意义正常收益里程碑在评分前定为主加权误报相对下降至少30%，且三台双协议参考设备中至少两台有正收益。此门槛不修改历史Job174666的FAIL，不等于一区或部署达标。Q无误报时保留该设备，不能制造改善比例。
只有同时保攻击并获得正常收益，且FULL优于RAW、相对NO_CF具备联合优势，才支持学习机制收益；正确参考优于等量错误参考另支持个体化贡献。绝对攻击检出和误报始终单列，不能用“相对改善”掩盖绝对能力不足。此次仍不补独立ID测试。

## 5. 已查出的实现边界与下一步

现有开发执行器只接受LEARN/DEV角色，按名称拒绝已消费设备，并要求声明早于捕获t0；这些约束不能直接容纳2026年设计、2018年录制的外部档案。下一步需实现独立版本的EXTERNAL_ARCHIVAL_EVALUATION入口，按源SHA/MAC/来源谱系排重，并分开当前政策声明时间与历史捕获时间。旧开发验证器、已消费CIC设备及旧结果保持；不能靠改名、伪装LEARN或回填2018年声明绕过检查。
实现后依次完成：来源和合成预检→按已冻结规则生成参考与查询UID/标签/组件权重→核对原983,788正常总体、72,553正类及15区间数量→封存148,316查询/92参考身份→只在通过后提取特征、冻结模型评分和导出。缺行、错时、来源漂移或任何计数不符均停止，不自动重试，不调模型。
物化须顺序读取原PCAP以取得真实frame/UID及因果前缀，这是新增产物生成，不重做已完成的资格判断。复用超算已上传文件及Job176183收据；无需再传7GB数据，除非目标缺失或校验不符。具体资源和执行包须在实现时给出，不能把12分钟原始核验当作E3推理耗时。用户仍自行上传、提交、拉回。
当前完成的是输入冻结与自审；生产档案入口和真实UID清单尚未完成，未取得模型运行结果。未来可对准备好的具体包一次授权“目标预检通过后物化、评分、导出”，无需逐文件反复授权。
