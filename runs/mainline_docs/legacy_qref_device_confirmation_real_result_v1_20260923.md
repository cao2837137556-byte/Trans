## 为什么加权收益几乎没有

Q的51条误报中，Borun30条处于可修正范围；Netatmo5条全在TCP回退范围，
Ring16条全在回退范围。Netatmo可修正的3378条UDP正常查询，Q本来就零误报，
因此它没有可观察的误报改善空间，不能把它报告成第二台自适应成功设备。

按原始device/activity/capture/session层级权重，Borun的30条只占全部误报权重
的0.226609%，其余99.773391%位于固定回退区。因此即使完美修复所有合法可修正
的正常误报，且不损失任何攻击，这个固定机制在本轮也最多改善0.226609%，
达不到冻结30%目标。实际改善0.165755%。这是一条从保存预测得出的事后范围上界，
不是重新评分、另选阈值或更改验收标准。

这暴露的是全局确认目标与机制可作用范围的错位。不能将FAIL全部解释为学习模型
不具备效果，也不能因此豁免门槛：预留确认仍FAIL，只有Borun的局部收益得到复现。
下一轮方案必须先论证参考覆盖和可观察改善空间，不应继续对相同DEV做邻近参数搜索。
