## 对“模型没正常工作”的判断

本次证据支持：**模型按已冻结的782维实现执行，Edge与A/B没有出现本轮检查可见的执行漂移。**相同模型能够重现A/B较高的攻击分数，也重现Edge UDP约−38的分数；不是Edge换成空模型、全零特征或没有使用编码器。

E3分支的三头首层各有98,304个非零权重；q14分支分别有1,480/1,472/1,486个。两种置零干预均改变输出，证明特征确实接入。此干预仅用于查连接，不代表移除特征后可获得有效性能，更不能据此更换主方法。

原冻结设计明确指定base_dimension=768、query_dimension=14、state26=false。当前未使用额外26维状态符合该设计，不是Edge新增的切片遗漏。模型输入没有HTTP方法/URL/正文，也没有跨连接聚合速率；这些属于当前特征定义的范围，尚不能把它们与本次漏检建立完整因果归因。

独立UDP扫描得到20,000个选中连接键、19,998个不同源IP；所有查询在所属键中都是首包。全捕获中，其中19,998个键只出现一次，另2个键稍后又出现一次，但查询时不能使用未来包。所有选中UDP头均为`(20,0,28,0,64,8)`，与已存快照一致。这样形成大量相同输入，就可能得到相同的漏检判决；20,000条查询不能理解为20,000种独立输入上的失败。此前“可能漏掉同连接上下文”的疑点在该UDP范围内已得到直接原包核对。

HTTP独立重建的保留包数分别为ACK_ONLY 13、FIN 13、SYN_NO_ACK 3、PSH_ACK 12、RST 14，完整张量哈希匹配，包含token、mask、方向、时间间隔、字节数、包数、协议、突发大小及位置索引。因此不仅是比较维数或文件名。

但这不等于证明模型设计正确或检测效果合格。19条前向样本不能证明所有代码路径无缺陷；本轮没有独立重建A/B原始包、没有全量HTTP原包对照，也没有消融分离编码器表示与分类头学习边界的因果作用。原RAW外部HTTP区分弱、C5撤回攻击告警、UDP零检出的科学失败完整保留。
