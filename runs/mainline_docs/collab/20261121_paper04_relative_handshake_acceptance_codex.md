# 设备本地相对握手次数：独立复核

在这批冻结查询上，优先保留“v12 加相对握手距离”作为后续验证候选。它在 Win10 的严格数据视图中多保住 13,768 条原有攻击告警连接，在 Edge 多保住 4,390 个登录 POST 告警，同时新增 18 条 Edge 正常误报连接和 92 条 UNSW 正常误报查询。叠加角色筛选仅再保住 11 条 Win10 连接，Edge 登录 POST 结果相同，UNSW 正常误报则又增加 125 条。

Win10 的基础头原有 14,024 条告警连接，因此 14,013 条对应 99.92% 的原告警保留率、77.02% 的全部合格连接检出率。ToN 属逻辑主机配对。Edge 登录 POST 的基础头原有告警为 23,606 个，全部可评价 POST 为 23,608 个。旧泛洪告警均保留，UDP 判决复现原版。若参照此前的误报预算，v12＋相对握手在 UNSW 上新增 92 条查询，比上次参照值 74 条多 18 条。[配对表](../../p4_ccnr_relative_handshake_v1_20261121/received/PAIRED.csv)

**握手约束作用在哪里。** 各库每条 TCP 参考均能重建其原帧时刻的握手计数。Edge 的 4,096 条 TCP 参考中位数 60、最大值 64，其正常 TCP 评价查询中位数同为 60；密码场景评价查询中位数 390。Win10 的 4,096 条 TCP 参考均为观测零。相对握手加在 v12 上后，Win10 新保住的 13,768 条连接均在握手条件这一层就已找不够两个相容参考组件。Edge 新保住的 4,390 个 POST 中，4,286 个归于握手条件不足两个组件，2 个归于四项条件联合后不足两个，102 个仍有正支持但扣分减少。两组因参考握手值缺失而恢复的告警均为零。这里核实的是设备自身既有参考与这些查询的差异。[参考与查询的实际分布](../../p4_ccnr_relative_handshake_v1_20261121/received/H_COVERAGE.csv) · [分阶段归因](../../p4_ccnr_relative_handshake_v1_20261121/received/MECHANISM.csv)

**上轮 UNSW 的 6,550 条查询。** 逐连接相加得到 2,600 条落在原已报警的 2 条连接，另 3,950 条落在原先无警的 26 条连接，合计 28 条连接。按设备分组，其中 6,546 条查询来自同一设备；端口 40000 占 3,562 条，涉及 20 条原先无警的连接。端口号能定位业务流量，具体应用语义仍需证据。[逐连接核查](../../p4_ccnr_relative_handshake_v1_20261121/received/UNSW_ATTRIBUTION_BY_CONNECTION.csv) · [设备与端口](../../p4_ccnr_relative_handshake_v1_20261121/received/UNSW_ATTRIBUTION_BY_DEVICE_ROLE_PORT.csv)

**同服务登录。** 本机已核资料中，尚未找到同一认证服务同时具备可信正常建档、隔离的正常评价和可归属的密码攻击。ToN 的 286 条同端口正常记录均在 .152:1880，认证业务待证；Edge 的同设备正常评价缺少合法 DVWA 登录。下一轮优先验证成功登录、输错后重试和合法重连，用独立于建档的采集评价同服务误报。[各来源资格与缺项](../../p4_ccnr_relative_handshake_v1_20261121/received/LOGIN_QUALIFICATION.md)

**验收范围。** 超算清单中的 51 份回传文件逐一核对字节数、SHA-256，另核本地登录资料清单的三项摘要。10 项 Slurm 作业均有 `COMPLETED 0:0` 记账。复核部署包、方法摘要、700 行配对计数和 280 行增量归因，原 v12、R1 与 RAW 计数同上轮逐组逐种子对齐。逐包数组留存超算，本次本地复核使用回传表与回执。[验收回执](../../p4_ccnr_relative_handshake_v1_20261121/received/LOCAL_ACCEPTANCE.json) · [结果汇总](../../p4_ccnr_relative_handshake_v1_20261121/received/RESULTS_FOR_PAPER.md)
