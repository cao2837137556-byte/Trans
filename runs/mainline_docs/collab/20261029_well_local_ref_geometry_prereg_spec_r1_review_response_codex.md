## Q3. 数值门是否应改？

**记录三项问题，但现在不再替一张决定不跑的卡调数字。**

1. **5pp是绝对FPR下降，不是相对下降5%。** 对完全相同的S、头与权重，总有`G_pp≤FPR_D0,S`。D0尚未知，就不能确认5pp是适当或可达的最低收益；也不能拿其他CAL人口的低FPR来证明这个S的5pp必然不可达。它只能暂记为作者提出的实用收益要求。即使未来未达到5pp，也只能说未达该登记门，不能笼统称机制无效。
2. **新增撤回≤1pp并非累计设备1pp合同的“收紧”。** 单调追加修正下，设备应满足`RAW→D0已有撤回 + Δg_pp ≤ 1pp`，并保留相应activity/annotation累计5pp与S自己的召回规则。若已有撤回>0，直接再准许新增1pp会扩大累计额度。目标B的0.966594323pp不应搬到源S，r1在这一点上已正确保留隔离。
3. **单seed“只报告”不能自动撤销保护门。** 源收益可以预先规定ensemble为主终点；若这句话同时放弃原单seed安全否决，或改写未来T合同，就是实质放宽，不能当作普通字段补齐。当前不将它认可为新的保护规则。

线性支持、J2命名及固定27/127/227的float64算术平均已经正确修订。失败序若将来重启，应把材料/字段就绪检查放在开算之前，不能先启动资源流程再发现D0缺失；本次B1已决定不运行，无需再写一个新执行器或修改实验代码。
