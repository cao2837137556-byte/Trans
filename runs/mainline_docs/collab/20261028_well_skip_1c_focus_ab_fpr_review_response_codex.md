## Q1. 是否同意搁置主头源 1C？

**同意。没有“不做它就堵死 A/B 路线”的现成反证。**

把 `SOURCE_MAINHEAD_DENSE_1C_C5_FIXED_V1` 保留为 `DRAFT_NOT_AUTHORIZED`，研究优先级另记 `DEFERRED_UNTIL_AB_PATH_NEEDS_IT`。原卡只测主头源 CAL 的 Atomi 单组件支持，不改变 A/B 部署分数；它完成后也不解除已知迁移保护证据不足。因此，这个独立卡目前不是冲 2%/99% 的关键路径。

“与 A/B 无直接因果路径”宜限定到**这张独立卡的输出与推进条件**：1C 规则本身当然可以改变目标评分，只是源 Atomi 支持分布没有被证明是目标成功的必要条件。若未来完整目标候选明确依赖同一源侧对照、机制声明或源选择步骤，再说明依赖关系及其能改变的研究决定，而不是用“可能有用”恢复优先级。

这也不是把源保护省掉：未来候选的源侧保护与目标累计风险仍需交代，只是不再把当前缺少边界压力的源 1C 补算当成唯一入口。

## Q2. 现有材料中，是否有冲 B≤2% 的就绪有限机制族？

**有足够材料界定和筛查有限候选；目前没有已经明确规则、保护合同并具备推进证据的完整达标候选。** “没有现成达标方案”不能进一步推出“必须新训练/新前向/新协议”。

现有汇总已经允许先排除几个过窄的作用范围。固定对象为 179700 DENSE、观察期后、原加权分母、原 ensemble/cut；假设候选只改变指定块，其他判定保持。即使无代价消掉该块全部 FP，仍有下表限制：

| 限定干预 | 最乐观的剩余误报 | 对目标的含义 |
| --- | --- | --- |
| B 仅消掉 Samsung 与 WEMO Power 的两个组件不足块 | `9.519653948711 − 7.007137146893 = 2.512516801818%`（池 FPR） | 即使两块全消，池 FPR 仍 >2%；固定 1C 不能仅凭这两块独立达标 |
| B 保持 TP Link 的零支持块不变，其他 TP Link FP 假设全消 | `1.373945641987 / 0.2 = 6.869728209934%`（设备 FPR） | 仍违反原逐设备 ≤2% 门；只改组件资格或只加大已有正支持修正都不够 |
| A 仅消掉 HeimVision 组件不足块 | 池 FPR ≥`1.256213012351%`，但 HeimVision 设备 FPR ≥`2.512194113757%` | 池门可能过，完整合同仍不过；见 Q3 |

这些下界故意忽略新增 FP/FN 和有限修正强度，已经是对候选最有利的情况；加上攻击护栏不会让它们变得更低。它们只排除表中**其余判定冻结的限定干预**，不适用于同时改变 cut、几何、支持集合或其他分支的新完整方案。

数据依据是现存[残留互斥分账](../../dense_reference_ab_stage_dependency_repair_execution_20261028/result_retrieval_179700_20261028/RESIDUAL_FP_DECOMPOSITION.json)及[保存 READOUT](../../dense_reference_ab_stage_dependency_repair_execution_20261028/result_retrieval_179700_20261028/READOUT.json)。TP Link 的 136 条零支持和 89 条正支持不足互斥，合计 225 条，与保存设备 FP 数吻合；其正常权重分母为池的 0.2。上述两块的 73.61% 只是残留构成，不是修复收益。

**对 B 的下一步要求已经具体化：在只改参考修正、其余冻结的路线中，除单组件块外，必须能改变 TP Link 的零支持问题；否则不应把它登记为完整达标方案。** 更一般的判别路线可以改变其他冻结条件，但必须明确写出，不能借“条件修正”省略机制。

现有查询 E3/q14、完整合法参考、RAW/DENSE 分数、原支持 trace 和参数已经保存。有限资格或支持几何变化可能只需要新的距离/support 计算，未必需要新前向；但具体几何公式、源侧选择方法和保护合同尚未确定，不能把“向量有了”写成“新方法 ready”。

完整合法窗口的枚举还确认：Samsung TCP 717、WEMO Power TCP 88、HeimVision TCP 2521 个位置，各只有一个真实组件，均未触抽样 cap。对**这个冻结窗口和生产合法性定义**，不是只有模糊的“怀疑遗漏第二组件”；见[完整库存](../../diagnostics_c5_step2_package_v1_20261025/target_inventory/READOUT.md)。获得新的真实组件需要不同材料或协议，但这不等于任何改支持/判别的路线都必须换协议。

目前还不足以宣布所有已有特征路线无解，也不足以承诺新表示能解决。可以按有限研究预算收束论文边界；若保留研究机会，应先排除上述明显够不到完整目标的范围，再决定是否需要新材料。

## Q3. A 应优先资格/支持，还是先修 WRONG 归因？

**先用当前 DENSE 的资格与支持分账界定性能候选；WRONG 用于归因核查，不是降低 FPR 的操作本身。**

A 已有当前身份的完整分账，无需再停留在 V4 历史叙事：

| 当前 DENSE 残留 | FP 条数 | 池 FPR 贡献（pp） |
| --- | ---: | ---: |
| HeimVision 组件不足 | 42 | 2.737268518519 |
| HeimVision 正支持但修正不足 | 21 | 1.256097056878 |
| Eufy 无参考 | 1 | 0.000115955473 |

只清正支持不足块，池 FPR 仍 ≥2.737384473992%；只清组件不足块，虽然池级乐观下界降到约 1.2562%，但 HeimVision 仍约 2.5122%。因此，在原 cut 等条件不变时，**两种残留都要进入完整达标方案的作用范围**。这里沿用 r1 明确保留的逐设备 FPR≤2%，没有自行放宽为只看池均值。

优先级可分为：

1. 用当前 UID/权重和保存的 cap/score 检查资格扩展与已有支持不足两块的可触达范围，评估它们的联合上界。
2. 若范围尚未被排除，明确有限规则和源选择/保护程序，再决定是否计算新支持。固定 1C 和使用现有 E3/q14 的支持几何核查已有向量输入，原则上无需新前向；实际新距离仍是新计算。
3. 同时保留匹配 WRONG 的声明约束。现存 WRONG 分数、支持和 donor 计划可读；换 donor、改匹配或改几何会产生新的合同/计算，不因 WRONG 当前更低就把它事后换成主方法。

“性能达到 2%/99%”与“自身参考比匹配 WRONG 更有效”是两个问题。前者不逻辑要求先修好后者；后者不通过，就不能宣称设备自身参考特异性。A 的现有 DENSE 分数在描述性 oracle 下已经存在满足池级 2%/99% 的工作点，也说明性能与归因不能混同；但 oracle 不是合法源选择的部署点，不能拿来复活原 P1 或直接选 A 的 cut。

历史代理 A 降 1.879340pp 仍只解释当时的代理，不能加到当前 DENSE 或预测完整密库 1C 的收益。对应限制与攻击风险见[C5 记录](20261025_c5_readonly_audit_response_codex.md)。

## Q4. 目标侧 1C 与源侧 Atomi 审计是否必须拆卡？

**目的、数据角色、计算范围、保护结论与授权必须分开；不要求物理上恰好两份文件。** 可以两张独立卡，也可以一张总卡下两个严格分开的阶段，文件数量不是科学门槛。

当前独立源卡应搁置。未来若登记目标 1C 候选，应明确：目标实际使用什么规则，源保护提供哪些证据，哪些仍缺失，何时能进入目标开发评价。不能用源卡的审计完成覆盖目标计算，也不能把源侧支持存在写成目标安全成立。

同样，不能将“拆开”理解为目标 1C 无需保护即可直接试。在当前 A/B 已被开发接触的情况下，针对残留设计新规则必须披露这一接触；当前池结果继续只是开发评价。若规则改变历史 λ、资格、半径、cut 或其他条件，旧源 q14 零撤回证明也不能不经核对就继承。

| 身份与目标 | 179700 DENSE、固定 seed/ensemble、观察期后 UID、原层级权重、设备分母、RAW→D0 已有攻击损失；明确池与逐设备门 | 避免把旧 V4、旧代理、全量与后窗口混在一起 |

## 对原稿 §4 准入门的具体修订

1. **同意目标相关性门。** 每项工作应说明如何改变 A/B 相关决策，或为何是已定义路线的必要对照。不能要求源实验事先证明会外推成功；应要求可检验的迁移假设、预算和失败门。
2. **非 phase-only 可以作为下一轮预算选择，不是普遍不可能定理。** 当前数学界限覆盖冻结 DENSE 的全局 cut 与原 QG；P1 是原 QP 的经验失败。`s−b(phase)>C` 等价于阶段 cut，只证明它没有增加新机制，不证明所有阶段 cut 都不可能。本文不建议再重启原方案，但必须保留这个逻辑范围。
3. **把“上界不够就不跑”限定到独立达标主张。** 对上表范围，可写 `INFEASIBLE_AS_STANDALONE_FOR_CURRENT_TARGET`；一个局部模块仍可能是已登记组合中的必要部分。组合必须先列完整作用范围、UID 并集及整体停止预算，不能用“以后能组合”无限续跑。关键诊断也可以按信息价值执行，但须说明哪种结果会使路线被放弃或改变。
4. **保留攻击保护与开发隔离。** 凡引用 HELD 做规则设计，仅取原 FIT 部分；不禁止其他合法 FIT，也不把过滤后数据重新称为独立验证。CAL 不回流否决拟合。当前逐设备 FPR≤2% 与组攻击预算继续保留，不能在讨论中悄悄降成只看池均值。
5. **标签按证据使用。** 数学范围不够、现有样本安全失败、无迁移收益、材料缺失与研究预算停止分开。`NOT_EVALUABLE` 不能写成 `INFEASIBLE`，`DEFERRED_UNTIL_AB_PATH_NEEDS_IT` 也不是方法无效。

**当前建议：搁置独立源 1C；先做上述目标上界盘点，重点覆盖单组件块、HeimVision 的支持不足块和 TP Link 的零支持块。** 已有汇总足以放弃“只处理两个 B 单组件块就能达完整目标”的主张，但还不足以要求立即换头、增加数据或收束全部方法。先让有限候选的作用范围经得起这项必要条件检查，再决定是否投入新的支持计算。

原 1C 卡与准备包保持封存，入口以本回复记录新的研究优先级。本回复不是执行授权，当前正式 A/B 结果仍为 A **3.993482% / 100%**、B **9.519654% / 99.966594%**。
