## 2. 因果诊断（最终问题定义）

半年卡住，不是「头不够强」或「再训几轮」，而是三块石头同时成立：

1. **A 资格天花板**：绝大多数误报进不了修正门 → 不改资格，A 加权 FPR 几乎不可能动。
2. **归因失败**：进了门也学不会「必须靠自身参考才降分」→ 不能写成设备入网适应。
3. **B 上几何仍系统性强于学习**：资格内大量未跨 cut；V3 是必须保留的主对照，不是可被学习模块偷换的旁支。

因此科研问题应改写为：

> 在**不扩大攻击可达修正**的前提下，把可修集合做成足够大，并让修正的充分统计量来自**该设备早期正常参考相对查询的几何/残差**，使得 own ≫ wrong 在预登记检验上成立；再用同一合约看能否逼近或超过 V3，并同时守住双池攻击合约。

## 3. 四阶段方案（含停刀）

### 阶段 0 — 冻结审计（不做训练）

目的：按**原权重**把「资格外 / cap 不可达 / 可修未修 / own vs wrong」拆成可加减的账，避免用原始条数 16.10% 误判加权可达性。

必出三张表（A/B × B2，必要时加 OLD_BANK）：

1. 原 FP 的权重质量：资格外、超 cap、资格内未跨 cut、已修正  
2. 资格内未跨 cut 的 margin、参考相似度、查询侧特征  
3. 旧 344 条成功修正在**当前头**上的命运（已变正常 / 无参考 / 零支持 / 修正不足）

**停刀：** 若加权口径下 A 的资格+cap 可达质量仍接近 0，则阶段 1 为硬前置，禁止先改损失再训。  
**成功：** 得到「改资格能释放多少加权质量、改学习只能动多少」的分账，作为后续预登记分子。

### 阶段 1 — 资格合约重做（破 A 天花板，服务 B）

**机制：** 资格 =「早期可信正常参考是否覆盖该查询的合法邻域」，不是「库里有没有随便一条参考」。在源 FIT 入网模拟上设计。  
允许旋钮：参考选取 / 分层 / 时效 / 组件数 + **攻击侧否决**（CAL 近邻禁止入资格）。  
**先不动 λ/cap。**

**最小验证：** 离线换 2–3 个资格策略 → 重算可修权重质量与 CAL cap_reachable_detected_attack；再固定同一 HARD 检查点只换资格。

**成功：** A 出现稳定非零修正，且下降主要来自新纳入资格集合；CAL 无新增 FN、cap 仍够不着已检出攻击。  
**停刀：** 资格一放宽，CAL 可达攻击 >0 或出现新增 FN → 收回该规则，**不靠加大 cap 补救**。

### 阶段 2 — 自身参考可归因学习（破 attribution FAIL + 可修未修）

**机制：** 在源 FIT 构造与正式 WRONG 控制同构的 own/wrong 配对：  
损失 = 有界降分（只降攻击分） + **惩罚「错参考同样能降」** + 奖励「仅当自身参考残差/几何支持时降」。  
输入显式保留 query–ref 关系（旧 Qref 真正值钱的部分），但：

- **禁止加载旧 Qref 权重**
- **禁止用 A/B 标签挖困难样本**
- **禁止把 QUERY_ONLY / OLD_BANK 解释成「无参考 / 旧修正器」**

**成功：** wrong_control.equally_effective=false；own 修正按预登记边际显著高于 wrong；资格内可达 FP 跨 cut 率上升；攻击格 0 新增 FN。  
**停刀：** 对比损失下 own 仍打不过 wrong → **放弃「设备个性入网」主叙事**，转入阶段 3 的诚实混合（V3 几何为主、学习只做残差精修），并改论文主张。

### 阶段 3 — 仅当 1+2 在资格内子集已胜出，才碰「为何 V3>学习」

- 若资格内子集上学习已赢 V3 而全池仍输：缺口在资格/覆盖。  
- 若资格内仍输 V3：缺口在**参考几何表征** → 才允许研究「可学习的几何修正」（把 V3 的有效归纳偏置参数化），而不是再叠 MLP 头。

B 的任何候选还必须过：**近撤警攻击探针 + 源侧留出设备攻击**。

## 5. 论文级成功定义（提前选一条）

- **主成功：** 同一预登记合约下，A/B 池加权 FPR 与逐设备门槛达研究目标，攻击加权检出守门，且 
eference_attribution=PASS。  
- **次成功：** 证明在严格保护下，可归因的学习修正稳定优于纯几何；即便未到 1%，也给出可迁移机制与失败边界。
