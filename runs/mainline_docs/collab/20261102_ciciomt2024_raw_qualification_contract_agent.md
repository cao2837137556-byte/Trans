最新攻击记录至最早可用正常记录的间隔，独立算得 **5,288,759.896431 秒 = 61.212498801284722… 天**。不是文件创建时间，不是本地时区显示误差，也不是取首尾帧假定有序。两包的 capture-order 倒退不改变全量极值；微秒倒退不能解释两个月的逆序。

现有材料没有官方时钟纠正、同步日志或可交叉验证的捕获时钟偏移证据。可以保持“真实时钟关系仍可能由新的一手证据修正”的认识论边界，但不能凭该可能性放行。PCAP 时钟是捕获记录时钟，不应直接说成某台 IoT 设备自己钟错了。只有与结果无关、可审计的官方/同步来源证明偏移后，才可另登记时间解释并重新核验全部角色；不能为满足合同任意平移 61 天。

**失败范围是已得四包的角色组合。** 未来得到更早可信正常、完整入网和同一真实目标映射，可能使部分攻击资产重新具备资格；作者 train/test 目录自身不提供这个证据。两份攻击文件各自不足 7200 秒，又不具备纯正常入网来源，不能靠改名充当缺失的正常入网窗口。

还有两项独立限制，不能被大包数量掩盖：

- TCP 前 100000 帧的主流是 flags=0 的 TCP，不能将它写成已证实的 ACK 攻击；其它 ACK/PSH+ACK 双向云端流也不能直接赋恶意标签。UDP 样本中的协议与高频方向也尚缺官方目标/事件闭合。
- `.250` 在两份攻击样本中对应不同目的 MAC。私网 IP 相同不等于同一目标；一份攻击的目标 MAC 在正常包出现，也不自动证明真实物理型号/用途。

## 2. 正常侧补充及 RAW 回退的合法证据边界

若以后单独授权，11 月正常材料仍可用于**正常侧补充测试**：在核实真实物理设备、可信正常来源、合法历史/7200 秒入网/后段划分、排重与人口后，比较固定 RAW 与 C5 的逐样本/加权 FPR，并单列正常 SYN_NO_ACK、ACK、UDP 的覆盖与守卫代价。应独立命名为正常侧外部证据，公开具体设备、捕获/日期和可用查询量。

该结果不能证明攻击召回、ACK/UDP 撤警安全、完整双侧目标达标，也不能把正常包里出现 ACK/UDP 当作相应攻击资格。两份文件帧多不等于独立设备/事件多；时长和事件覆盖仍要按已声明的单位报告。

若对 8—9 月攻击严格执行未来正常库不可用的规则，相关查询只能保持 RAW，C5 与 RAW 的预测相同。此时“零新增漏报”是**模块没有参与的结构性结果**，不是参考增强经受过攻击背书考验。需把 `BANK_NOT_YET_AVAILABLE`、有效参考覆盖率及增强实际参与人口写明，相应增强安全门记为未被有效检验，不能以零撤警包装成保护通过。

也不能把正常侧 C5 FPR 与早期攻击 RAW 召回拼成一个“完整增强方法外部确认”结论，或把未来正常同时给基线后声称已满足因果同信息预算。即使离线实验有其它研究意义，也已经是不同的任务定义，本轮不应借此改变预先固定的确认合同。

## 3. 建议先走 Benign 元数据资格门，不能盲下攻击大包

已登记 `Benign_train.pcap`、`Benign_test.pcap` 是合理的**最小救援核查入口**。当前它们尚未获取，未知不能填成通过，也不能预判失败。先检查发布者能否提供每个文件的字节数、捕获时段、设备/攻击事件说明及正常标签依据；若要定向取得原包，应先由这些证据确定有界的必要范围。文件名前缀或首尾少量字节只能作初筛，面对已观察到的记录倒序，不能替代全量最小/最大时间与完整捕获边界验收。

继续作为因果主测试候选至少需要：

1. 存在早于拟评价攻击的**同目标**可信正常来源；真实 MAC/设备与攻击目标闭合，排除 AP、网关、控制器及模拟设备。TCP 目的端点不能靠 `.250` 与另一份文件强连。
2. 合法不预过滤的完整 7200 秒正常入网上下文，以及后段正常；不能把跨长空洞的跨度或零散短包拼成连续入网。历史增强若无合法更早历史，必须登记为 commissioning-only，不能声称完整历史增强已经验证。
3. 官方正常与攻击来源/事件、攻击向、反向响应和背景/未知人口可以区分；ACK=1、SYN=0 的**攻击向**与 UDP 攻击向均有实际证据，不能用来源文件名或非守卫 TCP 代替 ACK 要求。
4. 输入/参考/终评物理身份排重、完整人口和边界可登记，评分前固定选择及执行卡；所有候选选择仅依上述资格，不看分数。

如果 Benign 文件或其它现有官方说明不能提供更早正常、合法两小时与同设备对应，就暂停 CICIoMT2024 的**主确认线**，保留已下载资产和正常侧补充潜力，转入其它候选的元数据资格门。没有理由为了当前时序失败继续下载更多同类攻击大包；更多攻击帧也不能补出早期正常历史。

本轮不授权或建议立即做任何检测评价。先关闭这一有界原包核验与讨论回执即可。
