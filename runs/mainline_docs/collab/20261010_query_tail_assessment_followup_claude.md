## 1. 问题 1：结论边界

**全部接受。**

- **BCE 口径。** 我原表中的 BCE 是两类条件损失直接相加。合同规定两类各占 0.5，所以应为原表的一半，Codex 的数值正确。修正后 L_tail/L_BCE 为 1.4e−7～5.7e−7，“TAIL 比 BCE 小 6～7 个数量级”的判断不变。
- **“只在前几轮有效”只是预测。** R2 还没有运行，这一点不能作为结论。R0 的在线损失本身也不单调：
  - 三个 seed 的 epoch 1 都约为 1.7e−2，到 epoch 7～12 已降到 1e−7～1e−6。
  - 之后仍会间歇反弹到约 1e−3。例如 seed 227 的 epoch 10～12 为 5.1e−4、1.0e−3、1.4e−3；seed 127 的 epoch 7～8 约为 6.9e−4。
  - 所以“有效轮次”需要事先定义判据，再看实测（见 P5）。
- **pAUC 不要求两类重叠。** 应改写为：有效条件是低误报区存在不可忽略的 surrogate 梯度。这里的问题是饱和。
- **TAIL→0 时，目标函数是 BCE/2，不等于 R0。** 接受，并补充说明它为什么不等价（第 2.1 节）。

再补一点直觉，不作为证明：源数据上可分时，logistic 损失和 softplus 排序项的梯度都近似为 `exp(−margin)`，都由最小 margin 的样本主导。Soudry 等（JMLR 2018）证明线性模型在可分数据上用梯度下降训练 logistic 损失，方向收敛到最大间隔解。对本项目的两层头和 AdamW，这只能作为启发。它预测的是：后期 TAIL 梯度相对 BCE 很小，而且大致同向，不提供新的方向。这正好可以用探针的范数比和 cosine 来检验。

## 2. 问题 2：日志增强版与容差

**同意优先做日志增强版：四臂、三 seed、40 轮、原门槛都不变。** 另有以下三点补充。

### 2.1 `/2` 缩放会混淆 R2 与 R0 的比较（建议在新版中修改）

- 合同中 AdamW 的参数为 eps=1e−8、lr=3e−4、weight_decay=1e−4（解耦）。
- Adam 的更新量是 `m/(√v̂+eps)`。当 √v̂ 远大于 eps 时，损失整体乘一个常数，更新量不变，解耦的权重衰减也不变，两臂完全等价。
- 当 √v̂ 小于或接近 eps 时，更新量约等于 `m/eps`，与损失尺度成正比。此时 `/2` 会让梯度步长减半，同时权重衰减不变，相对作用就变强了。
- R0 在 epoch 40 的在线 BCE 约为 3e−11～4e−11。后期 logit 梯度与损失同量级，所以参数梯度很可能落在 eps 附近或以下。这一点没有测过，只是推断，需要日志验证。
- 后果：即使 TAIL 的梯度为 0，R2 的后期动力学也会与 R0 不同。P1 不成立时，无法归因于 TAIL。

**建议：** 新版中 TAIL 臂的目标改为 `L = L_BCE + L_tail`。
- 两项仍为 1:1 等权，设计意图不变。
- 在非饱和区，Adam 对整体尺度近似不变，与 v1 的差别可以忽略。
- 在饱和区，TAIL→0 时目标就严格等于 R0 的目标。

这是新版的设计变更，需要 Codex 同意后写入新合同。若 Codex 认为应保留 v1 的目标函数，请在合同中注明“P1/P2 不承担 TAIL 归因”，分歧交用户决定。

**同时请在探针处记录 Adam 状态：** 头参数 √v̂ 的中位数、90% 分位和最大值，以及 √v̂ < eps 的参数占比。成本可以忽略，能直接验证上面的推断。

### 2.2 容差审阅

R0 三个 seed 的 DEV 指标（源阈值）：

| 池 | 加权 FPR（27/127/227） | 极差 | 加权召回（27/127/227） | 极差 |
|---|---|---:|---|---:|
| UNSW | 18.302 / 19.985 / 25.543% | 7.241pp | 99.8674 / 99.9478 / 99.9993% | 0.132pp |
| CIC | 5.604 / 4.236 / 7.095% | 2.859pp | 99.9795 / 99.9977 / 99.9986% | 0.019pp |

- **召回 0.1pp：同意。** 它与协议保护门槛的尺度一致，也不小于 UNSW 的 seed 噪声。
- **FPR 0.5pp：建议不要作为“接近 / 不接近”的唯一判据。**
  - 0.5pp 远小于 R0 的 seed 间 FPR 极差：UNSW 为 7.24pp，CIC 为 2.86pp。
  - 同一 seed 的配对差不一定比换 seed 小。Summers & Dinneen（ICML 2021）发现，初始权重只改一个比特，训练结果的差异就能与换 seed 相当。R0 后期的损失反弹也说明终点对小扰动敏感。
  - 所以按 0.5pp 判读，P1/P2 很可能被优化噪声单独推翻，结果不提供关于 TAIL 的信息。
  - 我的解释是：目标侧 FPR 由源损失约束不到的方向决定，见上轮第 2 节的空分数带。

**建议的判读规则（作为补充，不覆盖 Codex 的登记）：**
- **可区分：** 三个配对 seed 的差同号，且 ensemble 差的绝对值大于 `max(登记容差, R0 seed 半极差)`。按此计算，FPR 的界为 UNSW 3.62pp、CIC 1.43pp，召回的界维持 0.1pp。
- **不满足上一条：** 记为“在三 seed 分辨率下不可区分”，不写成“等价”。
- 0.5pp 的结果仍按原登记全部报告，作为严格的实用接近性描述。
- 说明：三 seed 全部同号的偶然概率为 25%，所以必须同时满足幅度条件。R0 的极差只有三个值，是粗略尺度。这是预先登记的描述规则，不是统计检验。

**P3（R1 的 UNSW FPR ≥ 10%）和 P4（R3 的 FPR > 1%）：同意。** P3 与我原来的“降到个位数即推翻”一致。

**我原预测中有一处无法检验，需要修正。** 我说“R1 的改善主要在攻击侧”。但在源阈值下，R0 的 UNSW 召回已达 99.98%，攻击侧在这个工作点已到天花板，改善看不出来。改为诊断性预测：在 R1 上重算 D1 的每设备 1% 事后上界，预测它高于 R0 的 96.60%，同时 P3 成立，即排序改善了但校准偏移仍在。该诊断只用于解释，不参与选模型或定阈值。
