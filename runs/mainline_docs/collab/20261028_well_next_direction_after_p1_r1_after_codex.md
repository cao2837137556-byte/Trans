## 0. 一句话立场

**有条件同意改变研究重点。** 停止原登记 QP 升级，以及已被固定分数边界排除的全局/原 QG 搜索；DENSE 保留为主基线锚点，RAW 保留为必要对照。下一版先修订合同与只读资产清单，再决定是否为固定 1C 完整支持/保护核查另写独立执行卡；复杂条件修正须先给出超过 phase-only cut 的信息与机制。达不到就用可审计停止标签收束，不把一次有限 FAIL 写成所有浅条件方法数学不可能，也不把约 74% 描述性分账写成已证可消除规模。

## 2. 研究重点与停止边界

### 2.1 停止什么

1. 原 QP 未过 P1 预登记门 → **不改门后升 P2/P3**。
2. 固定 DENSE 分数的全局阈值：B 保召回 ≥99% 时最低 FPR **3.676680%** → 已排除其达 2%/99%。
3. 原 QG 家族（UDP/SYN/OTHER 共用可调 cut、其他阶段回退原 cut）：B 攻击均在可调 SYN；该特定家族也被固定分数边界排除 → **不把原 QG/QP 搬到 A/B**。
4. 无近边界攻击保护合同就开 A/B 正式结算。
5. 默认回退 V4 学习主线。
6. 把「改排序」或 `s_new = s_old - b(phase)` 包装成新机制而不写 phase-only 对照。

### 2.2 不停什么（仍开放、须另卡）

1. **超过 phase-only cut 的条件/资格/支持机制**（须写清新增信息与不可由阶段阈值表达的决策）。
2. **固定 1C 机制审计**（见 §3.2；零新参数搜索；不承诺解决 B）。
3. 在 metadata 证明存在遗漏真实组件时的覆盖恢复材料门（当前 B 主残留组 **未**过门，不标 ready）。
4. 只读资产/分母/角色交叉表盘点（无新前向、无新距离）。

### 2.3 与 well 旧 r1 的关系

well 旧 r1（`20261025_well_final_breakout_plan_r1_after_codex.md`）核心仍成立：先把资产用尽，主线仍是密参考+V3，不默认 V4。其中「CAL 不作资格合取」「归因门收窄」「先分任务再动机」应继承。**不要**把折头或 seed27 学习模块当默认突破口。本 r1 在其之上吸收 Codex 对 P1 后事实边界与保护合同的硬修。

3. 复杂条件修正须先给出超过 phase cut 的信息与机制，再谈执行卡

### 3.2 固定 1C 机制审计（待另卡；本稿不执行）

建议首先讨论一个**不搜索新公式的机制核查**：

- 同一完整密库上：原 **2C** 规则对照历史冻结 **1C** 规则
- 1C 仅覆盖「恰一个真实组件且至少 8 个去重位置」；原 2C 分支保持原样
- `joint = max(dz/rho_z, dq/rho_q)`；`support = clip(1 - second_joint, 0, 1)`
- 固定原半径、scale、cut、λ = **.25**
- **零新参数搜索**
- 改变的是资格及支持估计 → 属单组件新方法，**不能**叫「修复遗漏第二组件」
- **不承诺解决 B**；完整支持尚未计算，本轮不执行

若进一步声称收益来自「密度」，保留同 UID、同权重、同 cut 的 2×2 机制身份（历史代理只作开发对照，不作新独立试验）：

| 参考材料 | 原 2C | 固定 1C 扩展 |
| --- | --- | --- |
| 历史稀疏已编码代理 | 稀疏基线 | 历史 1C 代理 |
| 完整密库 | 当前 D0 | 待核查的 1C 候选 |

历史风险须与历史收益并列（不可把旧代理收益加到当前 DENSE）：代理 A 观察期后 FPR 降 1.879340pp、B 仅 0.325053pp；A 集成新增 7 条 FN 等。源侧真 1C 且 ≥8 位置的 donor 当时只有 Atomi TCP 12 位置；即使之后 CAL 零新增 FN，也可能只是缺少能触及工作点的攻击压力。

### 3.3 复杂条件修正准入

新卡必须写出：

1. 增加了什么查询/参考信息
2. 改变了什么资格或支持运算
3. 哪些决策**不能**由原 phase-only cut 表达
4. 若含阶段项 → 匹配的 phase-only 对照
5. 只报告跨阶段排序改变 → **不够**

现阶段更稳妥的因果表述：**现有支持资格限制了能修正的正常样本，当前 CAL 对跨设备困难攻击的保护也不充分；二者都值得检查，但可修复规模及迁移能力未知。**

## 4. 近边界保护合同（数值，可机器读）

近边界相对**冻结基线**定义。逐 UID 保留原 RAW 与 D0 的 `margin = score - cut`，注明同头 FIT 固定尺度。风险集合在新资格/否决生效前建立，不能先把危险样本 support 置零再证明风险低。

账本至少三层：**合法结构下能否越过 cut → 规则门是否放行 → 实际是否撤回原 TP**。同时记录 own、每个合法 donor、raw fallback；最坏 donor 风险按同一 UID 并集/最大风险聚合。

### 4.1 累计与增量撤警

1. **累计撤警**参照：原 **RAW**。
2. **新增撤警**另报：相对同头 **D0**。
3. 组 g 损失：

```
L_g = 100 × Σw[攻击且 RAW 原 TP 且候选变 FN] / Σw[该组全部攻击]
```

单位 pp。**分母不是原 TP 权重**，是该组全部攻击权重。

4. 设备 `L_g ≤ 1pp`；activity/annotation `L_g ≤ 5pp`（累计保护）。
5. 原 FN、原 TP 新撤回、原 FN 恢复及净召回分别报告；**原 FN 恢复不能抵扣撤回**。
6. 原 RAW 召回 ≥99% 的折/suffix，候选须保持 ≥99%；原 RAW 低于 99% 时至少净召回不下降。另对 D0 写明增量底线（建议同样：基线 ≥99% 则保 ≥99%，低于则不下降）。G0 原召回约 88.6%，通过增量保护也不等于达成 99%。
7. Hydra、低 margin、小样本高权重组单列绝对损失和组内损失。
8. **92.74% 是历史损失构成比例，不是新的失败阈值**；具体失败以累计/增量数值门判定。
9. CAL 无攻击或无越界可能的组标注 `PROTECTION_EVIDENCE_INSUFFICIENT`，按冻结回退；不能用「CAL 全过」替代外推证据。
10. 新目标：A、B 各自观察期后 ensemble **FPR ≤ 2%**、召回 **≥ 99%**；原逐设备 FPR ≤ 2% 保留；全量并列，三 seed 全报，四 suffix 检查保护。旧 179700 池 ε=.1pp 只解释旧结果；新版本**不额外恢复**这一旧池限制。

## 5. 对照臂与声明边界

| 比较臂 | 用途与冻结要求 |
| --- | --- |
| RAW | 同一冻结头、同输入原分数；确定参考修正总贡献及累计攻击损失；不新训练「对照原头」 |
| D0 | 主头评价 = 原 179700 DENSE；源两折需各自合法、同头对齐的 DENSE 基线，不能把主头 D0 代入 |
| D1 候选 | 与 D0 同头、同输入、同查询/权重；只有预登记的资格/支持/条件机制变化 |
| 匹配 WRONG | 声称自身参考身份收益时：数量、组件、协议/时间资格等匹配的 donor；共同合格 UID 归因与全池覆盖效果分开报告 |
| RAW＋同规则 / query-only | 仅当新规则在不使用参考时确实有定义；不能用无定义输入制造对照 |

同一 V3 机制下，D1 应从 RAW 按新 support 生成，或在 D0 上精确加上新旧修正差值；不能在已修正的 D0 上再次减去完整修正量。A 现有 own 特异性失败不因增加对照臂而自动消失。

**真实扩覆盖 vs 2C→1C**：分开声明。复制、切分同一组件不算新增真实覆盖。当前 Samsung/WEMO/HeimVision 无遗漏组件证据 → 覆盖恢复 **不标 ready**。

## 6. 停止 / 失败标签字典

| 触发 | 标签 | 允许结论 |
| --- | --- | --- |
| 任一折、任一规定 suffix 违反累计/增量攻击门 | `SAFETY_FAIL` | 不推进 A/B；另一折更好不能抵扣；保留全部已登记安全比较结果 |
| 安全通过但未达预先固定的两折误报增益/稳定性门 | `NO_TRANSFER_GAIN` | 停止该候选；不得改成只挑最好折/seed |
| 缺合法参考、缺对齐 D0、缺可施压保护材料 | `NOT_EVALUABLE` 或 `PROTECTION_EVIDENCE_INSUFFICIENT` | 说明缺口；不冒充实验性证伪或安全 PASS |
| 有严密固定分数/候选家族界限 | `INFEASIBLE` | **仅**对满足该界限假设的家族（如现有全局 cut、原 QG 范围） |
| 有限登记集合用尽或研究预算到期 | `FAMILY_STOP_BUDGET` | 可收束论文边界；是研究决策，不是「所有条件方法不可能」定理 |

**增益门**：须相对 D0 **新填** `gain_min_G0`、`gain_min_G1`、`seed_consistency`；在任何候选效果计算前冻结。未填或仍写「明显改善」→ 卡**不可执行**。**不能**机械搬 P1 的 20%/10% 门（那比较的是 QP 对 Q0/QG，当前尚缺两折 D0）。

对固定 1C：可先限定一个历史冻结公式、零新参数搜索。若攻击压力不足或两折不过门，写出原因后停止，不追加基于此次 HELD 的第三个阶段例外。

## 7. 下一张执行卡必须补齐的最小七字段（Codex §7）

1. **候选与边界**：候选 ID、唯一公式/有限候选清单、可改字段、停止范围；说明是否等价于阶段阈值。

3. **参考合同**：可信正常来源、截止与共同评价窗口、真实组件定义、去重位置、donor 匹配；真实扩覆盖与 2C→1C 分开。
4. **基线及计算**：RAW/D0 身份、normalizer、geometry、scale、cut、λ 与选择权限；逐项标记已有结果、纯导出、新前向、新距离或新拟合。
5. **保护与评价**：预先定义近边界、cap/门/实际撤回账本、累计和增量参照、组分母、数值预算、低支持处理、四 suffix、固定 ensemble、两折增益与停止门；明确原 FN 恢复不能抵扣新增撤回。
6. **归因与声明**：是否需要匹配 WRONG、phase-only、RAW＋同规则；共同资格结果与覆盖结果分开；A 特异性及独立确认缺口保留。
7. **成本与运行范围**：先按材料盘点估算需补哪些计算及资源，区分本地/远端；不借「不重训」自动取得新实验授权，不复用原 P2/P3 或已消费的授权。

未齐七字段 → 卡不具可执行性；well 不将其当作已获准执行。
