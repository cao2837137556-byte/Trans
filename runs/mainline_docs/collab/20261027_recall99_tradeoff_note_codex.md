## 更直接的检验方向

应区分提高报警阈值与增强参考修正。固定分数下，提高判攻击阈值可同时减少误报和检出；λ仅对获得参考支持的查询起作用，不能覆盖所有零支持残差。下一项可准备无需训练的阈值—召回/FPR诊断，在至少99%加权召回下量化误报能否显著下降，同时检查逐设备及攻击类型，避免漏检集中。

主方法BASE、原参考、密参考应在统一条件下比较。源侧99.9%、99.5%、99%可作为候选工作点研究，但具体选择及分组护栏须登记；最终阈值仍应源CAL确定、冻结，再评价A/B。若直接用A/B攻击标签求99%阈值，其FPR@99%只能是事后区分能力诊断，不能当成源侧可获得的部署阈值；源CAL达到99%也不保证目标仍达到99%。密参考逐行修正分数目前未保存，完整曲线需要在后续获准评价时明确持久化，不能用汇总指标虚构曲线。
