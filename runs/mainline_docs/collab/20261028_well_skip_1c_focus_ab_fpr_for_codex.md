## 1. 为何跳过 / 搁置主头源 1C 卡

### 1.1 完成期望态对不准用户目标

该卡自我定位（且 well / 用户已接受）大致是：

- 闭合**源侧** C5 实际支持账本 / 1C 实际支持分布；
- **不**证迁移保护；
- **不**自动落到 A/B 评价口径；
- **不**动观察期后 ensemble 加权 FPR 目标。

因此跑完最可能得到的是：源侧支持分布说清楚了，保护证据仍不足，A/B 数字几乎不动。这与用户当前目标「降 A/B 误报到 ≤2% / ≥99%」**不对齐**。

### 1.2 对 A/B 无直接因果路径

- **B 主残留**：约 **73.61%** 描述性分账在 Samsung + WEMO Power；瓶颈叙事是**目标侧组件资格 / 覆盖不足**，不是「源侧 Atomi 1C 审计还没写完」。
- **A 卡点**：DENSE 下 own 特异性仍不成立；历史 eligibility 瓶颈（V4 时期大量 FP 资格外）——须用**当前 DENSE 身份**重述，勿直接搬 V4 数字当现证据。源侧 1C 账本闭合**不修复**这些目标侧几何 / 归因问题。

### 1.3 成本虽低，机会成本不低

只读盘点已 PASS，执行卡草案已在，跑卡本身算力/工程成本可能不高。但机会成本是：

- 延误对准 **A/B 目标残留** 的只读可触达上界与机制设计；
- 把「看起来在推进」的动作误当成冲 2%/99% 的进度；
- 与用户明确同意的「不做无意义实验」相悖。

**well 建议标签：** `DEFERRED_UNTIL_AB_PATH_NEEDS_IT`（除非满足 §2 的例外）。

## 4. 下一刀候选原则（请 Codex 打）

**任何新卡必须同时满足**下列门，否则 well 主张直接拒写执行卡或不授权：

1. **作用点对准目标**  
   直接作用于 **目标 A 和/或 B** 的观察期后评价口径；  
   **或**有预登记的、能外推到 A/B 的源→目标迁移链，且迁移链本身有预算与失败门。  
   （主头源 1C 草案当前两条都不满足。）

2. **信息不可被 phase-only 表达**  
   改变的信息 / 运算不能由已排除的 phase-only cut 表达。

3. **先只读分账，上界不达标就不跑**  
   哪些 FP UID **理论上**可被该机制碰到（资格 / donor / 排序）；  
   **可修复上界** vs **2% 缺口**；上界达不到 → **不跑**，标 `INFEASIBLE` 或等价。

4. **保护与开发约束**  
   - 近边界 / 累计 **RAW + 增量 D0**；  
   - **HELD∩FIT** 开发约束；  
   - **不把 CAL 回流**否决拟合。

5. **明确负结果标签**（预先登记，禁止失败后改口成「浅层超参」）：  
   `SAFETY_FAIL` / `NO_TRANSFER_GAIN` / `NOT_EVALUABLE` / `INFEASIBLE` / `FAMILY_STOP_BUDGET`  
   （以及既有 `PROTECTION_EVIDENCE_INSUFFICIENT` 等，按卡适用。）
