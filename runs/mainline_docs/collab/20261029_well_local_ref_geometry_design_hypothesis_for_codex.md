## 3. 设计假说：局部正常参考几何（Local Normal-Reference Geometry）

### 3.1 名称与意图

- **名称：** `LOCAL_NORMAL_REF_GEOMETRY_V1`（设计假说；非执行卡）
- **意图：** 查询相对**可信正常参考**的局部几何关系——统一协议半径可能把某些设备的正常局部变化当成异常；若查询落在冻结正常参考的稳定局部邻域、按邻域尺度仍近，而攻击仍偏，则有机会抬正常 support、限制攻击修正。
- **不是：** 裸 donor / 设备身份主信号；**不建议**攻击记忆库第二路线。
- **信息假设（可失败）：** 参考局部尺度归一化能使原协议半径下过远的部分正常查询回到正常邻域，而攻击在同一规则下仍偏离。「密参考更多」或「≥8 UID」本身**不**构成局部尺度可靠或统计独立的证据。

### 3.2 公式（精确化 Codex 示意；本轮冻结形态）

对每个合法参考 `r`，从冻结参考内部（排除自身；处理重复/组件相关性后），按**事先固定程序**得到局部半径 `ρ_z_local(r)`、`ρ_q_local(r)`。对**同一个** `r`：

```
J_local(x, r) = max( dz(x,r) / ρ_z_local(r) , dq(x,r) / ρ_q_local(r) )
```

聚合：1C 按原固定资格取同组件不同位置的第二小值；2C 取两个不同真实组件的第二值 → `J2_local(x)`。

新增支持原型（保留 D0、支持上限 1、原 λ / score-scale / cut）：

```
a_new(x) = max( a0(x) , I_legal_and_scale_ready(x) × clip(1 − J2_local(x), 0, 1) )
```

- 若登记软化形式 `clip(1 − J2_local(x)^2, 0, 1)`，须在诊断前**二选一冻结**，不得事后互换。
- **λ = .25**：冻结来源 = **上界盘点合同**（既有主头/目标工作点），**非**本轮新选。
- 协议几何半径 ρ 与分数修正 scale **不是**同一参数；改局部 ρ/度量即改几何，旧 C5「真实 q14 零撤回」证明**不**自动继承。
- **空操作检查：** 若所有参考局部半径都 ≤ 原协议半径，则局部 joint 只会更大、局部 support 只会更小，`max(a0,·)` 后原 2C 不变 → 仍修不了 TP Link 零 support。故必须明确允许何种有依据的局部放宽、放宽哪项阻断条件及其上限；不能把上限一律钉在原 ρ 后仍声称有 2C 收益空间。

### 3.3 硬事实（禁止误拼）

**`second_dz` / `second_dq` 不是同一参考上的两轴。** 生产实现对 dz、dq 与 `max(dz/ρ_z, dq/ρ_q)` 分别做组件顺序统计；两单轴第二距离可能对应不同参考。**禁止**把两个独立最优距离拼成「两空间都近」的虚拟共同参考；也不能仅比较这两数断言 joint 代表受哪一轴主导。新几何要求：**两空间距离必须对应同一个参考 r**。

### 3.4 输入 / 角色 / 冻结量

| 项 | 冻结方向 | 定稿前精确项 |
| --- | --- | --- |
| 输入向量 | 已保存查询/参考 E3、q14 | 新 1C 联合距离、参考—参考局部尺度/密度 = **需新算**（本文不授） |
| 数据角色 | 合法原 FIT；开发只用 **HELD∩FIT** | 同头身份分别绑定；目标残留已启发设计 → **披露开发接触**；后续数值规则不按 A/B 标签选择；CAL 不回流否决拟合 |
| 冻结量 | λ=.25、scale、cut、三 seed+集成、参考 UID/窗口/因果历史、主评价视图与权重 | 旧 D0 = 回退锚；引入源折头则绑各自同头参数，不搬主头阈值 |
| 尺度质量 | 近邻阶数/组件权重/去重/零尺度处理/最小有效样本/绝对尺度上限 | 仅用源合法 FIT 定程序；目标只按冻结公式用既有参考，不纳入待评查询自适应 |

### 3.5 作用范围

- 固定：**目标 1C 资格 ∪ 现有合格 2C**，含原零 support；**不为** TP Link 写设备专属例外。
- 目标残留 FP——尤其 B 的 Samsung / WEMO Power 组件不足桶；且必须能碰 **TP Link 零 support**（**136** 条 → ≈**1.373946pp** 池 FPR / **6.869728%** 设备 FPR）。
- A：同时覆盖 HeimVision 组件不足 + 正支持不足（seed127 HeimVision 最大额外暴露 **1.471271pp**）。

### 3.6 可证伪选择性声明（设计阶段操作化；本文**不**声称已证明）

**声明（待检验，非已证）：** 在冻结公式与合法开发样本上，相对对照 D0，新几何对**正常近邻查询**产生可度量的正 support 增益，而对**攻击近邻查询**的新增撤回不超过预登记组预算。

**操作化检验（诊断前须数值化阈值；数值 = `UNKNOWN_PENDING_REGISTRATION`）：**

1. **正常抬升：** 在预登记的目标残留 FP 桶（至少含 TP Link 零 support 子集）上，`a_new > a0` 的加权质量占比 / 平均增益 ≥ 预登记下限。
2. **攻击克制：** 对每个固定攻击组 g，候选专属上界 `Ug` 或实际新增撤回 `Δg` 满足 §3.7；不得靠「一律放宽半径」使正常与攻击同等接近。
3. **非空操作：** 存在预登记子集，其阻断条件在局部放宽后可改变（否则记几何无效，不进入「有选择性」叙事）。
4. **禁止伪选择性：** 禁止用目标攻击标签逐查询关修正/反向调门；禁止按目标成绩挑 donor；标签仅分账。

未达预登记标准 → `NO_SELECTIVITY`（对该冻结统计），**不是**「一切 E3/q14 表示无信息」。

### 3.7 暴露硬门（采用 C）

- 对固定组 g：真实新增撤回 `Δg`，有效上界 `Ug`，有 `0 ≤ Δg ≤ Ug`。
  - `Ug ≤ 剩余预算` → **充分保护证据**（有限数据上）。
  - `Ug > 剩余预算` → 仅说明该上界不能认证安全，**不推出** `Δg` 超预算。
- 宽包络不过时：仅允许**已预登记、限额、一次、无自动追加**诊断；诊断失败或写不出选择性 → 失败结项。
- 冻结候选必须过**实际保护门**才推进：目标 A/B 召回 ≥99%；设备累计 1pp；activity/annotation 累计 5pp（UNSW annotation = 现合同一部分，非临时可删）；主 ensemble 与三 seed **分别**记账。
- 单调追加假定下：`RAW→候选累计撤回 = RAW→D0 已有 + D0→候选新增`；绝对召回另加 RAW 原 FN。
- 失败标签（Codex 表，沿用）：`INFEASIBLE` / `NO_SELECTIVITY` / `SAFETY_FAIL` / `PROTECTION_EVIDENCE_INSUFFICIENT` / `FAMILY_STOP_BUDGET`。
  - 宽包络可能危险本身**不**触发 `SAFETY_FAIL`；实际冻结规则违门槛才触发。

### 3.8 对照 / 停止 / 成本

- **对照：** DENSE 主锚 + RAW 对照；开发只用 HELD∩FIT；**不**重建两折 DENSE、**不**训。
- **停止规则（一轮设计关口）：**
  - 写不出可证伪机制 → `FAMILY_STOP_BUDGET`，不再重复上界盘点。
  - 机制写得出且关键未知仅是未算几何 → 可**提议**最多一次最小诊断的预登记字段清单（见下）；**明确：本文不授予该计算。**
  - 诊断按预登记结项：`NO_SELECTIVITY` / `SAFETY_FAIL` / `PROTECTION_EVIDENCE_INSUFFICIENT` 等；禁止看结果追加候选或扩大门槛。
- **成本占位：** CPU / 内存 / 时间 / 距离对数硬上限 = **`UNKNOWN_PENDING_REGISTRATION`**。未填齐前禁止称 `EXECUTION_READY`。
