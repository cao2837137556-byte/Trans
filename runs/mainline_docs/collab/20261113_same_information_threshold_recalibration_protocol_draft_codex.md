# 同正常资料下的阈值重校准对照

结果：认可 anti 提议的主方向。比较同一冻结 MLP 在同一批目标正常参考上做查询级 p4 修正或分位阈值重校准，源阈值 RAW 作参照。
影响：本文件是待授权的执行草案。完整库 p4 仍为主系统。当前未补算前向、未校准、未提交作业。
下一步：范围获授权后，先在现有资产上通过远端 SHA/UID、时间资格和真实小切片门，再做一次正式对照。

## 固定对照

| 比较项 | 建档后判定 |
|---|---|
| RAW | 同一 FUSION790 的原始分数与源阈值。 |
| P4_MAIN | 直接复用已验收完整库 p4，使用同款 SYN 保护与原源阈值。 |
| RECAL_WITH_GUARD | 主比较。SYN 且非 ACK 的查询使用源阈值，其余查询使用由未命中保护的正常参考拟合的目标阈值。 |
| RECAL_NO_GUARD | 补充比较。由所有正常参考拟合一个目标阈值，在开放后用于全部查询。用于描述不带保护的普通重校准；两种重校准臂拟合的样本范围也不同，其差异不单独归因于保护开关。 |

各测试床各自拟合种子 27／127／227 和集成的四个阈值。集成先对三个原始分数按原顺序取 float64 均值，再独立求分位，不能平均三个单头阈值。CIC、UNSW、Edge 不混池。不重选参考、不重训。首轮只做分层权重和完整库，不加逐设备阈值、等行权重、只升不降夹紧或 COMMISSION_ONLY 结果行。目标阈值低于源阈值时按预定规则保留，并如实报告新增告警。

相同的是每个测试床可用的正常资料、开放时间和冻结检测头。池级阈值汇总了同池各设备、协议的正常分数，p4 逐查询只匹配同设备、同协议的合法参考。这个差异是两种策略的组成部分。重校准开放不依赖 p4 的支持度或双组件资格，否则会把待比较的匹配机制带入基线。

拟合器只读取正常 REFERENCE、基础分数和静态元数据。按 device → capture_id → component_id 对每层非空分支等分质量，叶内等分至各记录。三池本地封存参考元数据字段齐全、条数与最终参考身份相符。该权重沿用 Edge 正常侧分层的思想；源 CAL 实际用 device → activity → capture_id → session_id，因此两者共享 1% 预算与严格上尾算法，不称权重完全相同。

令 G 为 q14[0] == 1 且 q14[2] == 1 且 q14[5] == 0。RECAL_WITH_GUARD 在完整参考的分层权重上筛选 G=0 后重新归一化，严格以 score > cut 定义告警，选择使拟合集加权严格上尾不超过 0.01 的最小观测分值；平分按同值分组处理，记录实际参考尾部质量、阈值相等的权重与有效组数。G=1 保持 RAW，其校准侧误报如实报告。1% 是 G=0 条件预算，既不扣除 G=1 的固定告警质量，也不承诺全体或评价集 FPR 为 1%。G=0 无合法参考或权重不可用时阻断该池，不以评价集补阈值。无保护臂在全体正常参考上求同一规则。目标分位计算复用源函数的严格上尾语义和原 tie 规则，使用单独的目标正常角色验证；源函数只接收 LEARN/CAL，不改原角色或代码绕过。

## 资产与生效条件

- 完整参考 UID：CIC 8,863，UNSW 66,082，Edge 4,124，共 79,069。沿已验收的建档库、历史 union 与 Edge 编码批次重组。Edge 的本地参考元数据按正式编码批次 UID 排序后，有序摘要与 p4 回执一致；不能把原清单顺序直接当编码顺序。校准前在超算核对各输入当前存在性、大小、SHA、特征及元数据 UID 逐行对齐，确认每条均为正常参考。
- 旧回执已登记三块参考特征、冻结头及归一化器；目前未找到覆盖整库且可验证为现行 FUSION790 的参考基础分数缓存。只对未获可验证缓存的参考补分，最多 79,069 条参考 × 3 个冻结头。用生产 790 维输入拼装和源归一化；参考 context8 缓存是原值，需按现行头的变换归一化一次。正式预算按真实 CPU 小切片实测定，不从资产存在推断当前耗时。期望不重编码 PCAP、不重放上下文、不重算查询前向与距离；缺缓存或版本不一致就明确列出并停在资产门。
- 校准只能在该池完整校准参考已合法可用后生效。CIC 和 UNSW 每池内设备的时间截止一致，仍需核对原窗口及适用的同采集帧截止。完整视图保留建档期行和已允许的同 UID 历史回放，窗口未开放时严格复用源 RAW 判定；建档后不允许参考与评价查询重叠。本地核实 CIC/UNSW 的建档前查询分别为 4,789/1,319，其中同参考 UID 为 3,334/1,319，建档后均为零。Edge 的 NORMAL、HTTP、UDP 各 20,000 条选中查询均在原截止之后，且与 4,124 条参考 UID 零重叠。
- 阈值清单先写出并封存，含参考身份、规则、每臂/池/头阈值及尾部质量。之后评价端才读取冻结查询的 UID、RAW、P4_MAIN、q14、视图与权重。真实小切片核对参考读取到四路分数、校准与判定链；正式评价复现已验收 RAW/P4_MAIN，逐查询核对未开放区域及 RECAL_WITH_GUARD 的 G=1 区域均与 RAW 完全一致。

## 报告和解释

按全部四头、完整/建档后视图、普通/分层加权指标、设备/协议与保护分层报告；Edge 沿用原角色级 HT 分母。另列逐查询配对新增及撤警、阈值方向与实际尾部质量。重点报告 CIC 未命中保护的 64,680 条攻击、Edge 未命中保护的 11,908 条 HTTP 和 20,000 条 UDP 攻击；UNSW 的 72,553 条攻击全受保护，不用它们检验带保护分支在无保护攻击上的差异。

结论限定于同一 MLP、同一批合法正常资料与已冻结评价。若两个方法的实际误报工作点不同，报告各自折中，不用评价标签追配同 FPR。重校准可解释多少收益以实际结果为准。此对照不重新验证建库策略的独立泛化，也不改变完整库 p4。
