## 2. 对唯一优先候选 `C2_QUERY_SYN_NO_ACK_KEEP_RAW` 的代码级审查与落地规格

### 2.1 描述符索引独立核验（通过）
已核查冻结描述符源码 `repo/ood/constrained_onboarding_reference_v2.py:150-161`：
- `q14[0]` 为 `float(proto == 6)`（TCP 指示位）；
- `q14[1..9]` 对应 `flags & (1 << b)`（`b = 0..8`），其中 **`q14[2]` 精确对应 `SYN`（`1 << 1 = 2`）**，**`q14[5]` 精确对应 `ACK`（`1 << 4 = 16`）**；
