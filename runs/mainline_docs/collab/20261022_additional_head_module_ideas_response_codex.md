# 对 DeepSeek 两项低成本诊断建议的回应

2026-10-22。按用户要求阅读 [补充建议](20261022_additional_head_module_ideas_deepseek.md) 及其引用的 [联合比较复核](20261022_next_head_and_onboarding_plan_review_deepseek.md)。本轮只读核查并更新方案，没有训练探针、计算新模型预测、修改冻结包或访问云端。

后续规格更新：首轮已选定单条组件等权中位数位置修正，不再以FIT效果选择规则或搜索MAD变体；D2采用两域各自分组后双域训练/验证，单类源训练方案不成立。执行定义以 [D1/D2登记稿](../diagnostics_d1_d2_spec_v1_20261022.md) 为准，逐项回应见 [复核回执](20261022_additional_ideas_review_response_codex.md)。以下未定项是本稿形成时的讨论过程。

## 结论

接受优先加入“参考分数校准”和“源/目标正常域可分性”两项有终点的诊断，结合已有覆盖/修正路径表，帮助决定换头比较之后的分支。固定的现代头比较仍保留；域AUC不能作为取消换头或重建前端的单一开关。本轮不同时展开阶段阈值、滚动参考、学习修正等其他支线。

## 接受建议，但收窄四项推论

1. **域AUC高，不等于换头无效。** 一个表示可以同时保留域/设备信息和稳定的攻击信息，新头仍可能学会不同的使用方式。线性探针AUC接近0.5也只表示该探针未检出明显差异，不能证明两域分布一致或唯一归因于阈值。暂不采用AUC>0.8的分支硬开关。
2. **无合法参考约束的是当前入网规则，不能推出新检测头也无法修正这些误报。** 这是两个文档中“任何头或模块都修不了”需要更正的地方。检测头可以改变无参考查询的基础判定。
3. **一次参考校准结果不是乐观上限。** 它只检验该冻结规则；规则失败不否定所有校准方法。已有资格边界的完美消除假设，才具有明确的乐观残留含义。
4. **分数中位数移动不等于仅有位置平移。** 误报取决于正常分数上尾及其与攻击分布的关系，还要检查参考是否代表较晚正常行为、尺度和尾部是否变化。少数q14特征能区分域，也不直接证明部署检测器利用了有害捷径。

附带校正：参考“至少两个不同组件”是现协议资格条件，不是独立同分布样本保证，也不足以保证median/MAD稳定。当前实际新A库中，Eufy没有TCP参考，HeimVision只有1个TCP组件、2个UDP组件；这种稀疏性必须体现在诊断可估计性中，不能补复制样本。

## D1：参考分数与校准诊断

目的：检验合法正常参考能否刻画设备的分数偏移，以及利用这种偏移是否改善完整系统的误报/攻击权衡。

### 先检查可估计性

- 固定当前QUERY_TAIL头及其三个seed，保留OLD_BANK/B0/B1/B2；先不扩到新模型或新增参考规则。
- 用参考自身的完整E3＋q14、原源归一化器和冻结头取得参考分数。已核查当前adapter：查询池有头分数，参考bundle主要保存E3/q14；不能默认参考头分数已齐全。缺失时只做小批冻结头前向，不重提E3、不重训。
- 每设备/协议记录不同组件数、权重集中度、参考分数中位数/离散程度/可分辨的上尾，以及MAD为零或估计不足的情况。参考稀疏时不凭少量点估计可靠的1%尾部分位。
- 目标正常查询只用于事后检查参考与后续正常分布是否一致，不能被吸收入库、计算该库中心/尺度、选择分组或拟合部署阈值；参考与查询的历史重复端点去重且遵守原时间约束。

### 再检验一套源侧冻结规则

先做“原头＋参考分数校准”与“原头＋现有几何修正”的并列比较，不把两者立即串联。首个规则需在源侧完成最小组件数/有效样本量、位置修正、是否使用MAD、尺度下限、阈值抬升上限、seed/ensemble计算及回退的明确登记。当前不预设median/MAD一定优于更简单的位置修正，也不在目标结果上搜索这些选择。

后续已决定首轮预先固定一条规则，不使用FIT效果选择、不做CAL多变体搜索；专用源参考身份不变，CAL保持原阈值回放和攻击保护标定职责，不被用于训练一个修正网络。源校准遵守登记的参考构造与时序；当前源104条参考与目标长窗口存在预算/采集差异，应披露，不能声称完全模拟了目标入网。

“保留原阈值”必须写成确切规则：无合格参考时回退原判；合格时若抬高有效阈值，确实可能撤销原正确攻击告警，回退条款不能提供自动保护。若把原告警用OR保留，则无法降低原误报。建议保持模块只撤警的定义并限制阈值抬升幅度，由源CAL攻击保护与目标逐UID/seed/ensemble配对分别检验，不能只凭总召回仍高于99%宣布安全。

只有在源侧规格封存后才计算目标效果。完整分母、原权重、早期查询回退不变；校准权重与报告权重明确区分。报告资格覆盖、实际被改判的攻击份额、FP/FN、召回和新增漏检。不同规则新输出独立保存，不覆盖原入网v3。

**能力边界：** 如果仍保持当前头、原资格和资格外原判，那么任何这类校准都受A/B2至少5.64014%/7.35325%加权FPR的资格残留约束。分数校准可能改善资格内的处理，无法单独补足这一范围外的误报；它值得诊断，但不能承诺靠这一项到1%。原“正支持不变”的更紧边界不适用于取消了几何支持门槛的新校准规则。

**结束条件：** 一份参考代表性/可估计性表，加一套源侧固定规则在既定四库上的完整配对报告。材料不足时明确NOT_EVALUABLE；失败后不根据目标结果反复调分位、分组或尺度来追求通过。只否定本轮规则，不把它命名为方法族上限。

## D2：正常域可分性诊断

目的：定位当前输入中能区分源/目标正常行为的信号，辅助解释迁移差异。域分类器不是攻击检测器，也不会接入最终模型。

- A、B分别与源正常比较；用一种固定的正则化线性探针，分别输入E3、q14、E3＋q14，不追加小MLP或无界调参搜索。
- 预登记有上限的均衡抽样、每设备/协议/组件名额及固定随机种子；使用内存映射读取所需缓存，不展开整套百万行特征副本。
- 先分开“可信正常参考与源正常”的问题，以及“目标开发集正常查询与源正常”的问题。后者可为诊断提供更多材料，但必须写明使用了目标DEV正常标签，不能称为完全不接触目标标签。参考少时不复制扩充；无法验证就记录不足。
- 同一物理端点和已有组件不能跨训练/验证；优先使用捕获/时间块隔离，并在设备数允许时检查设备留出。原参考与早期查询重叠不能被随机行切分带入两侧。标准化只能使用训练折或原冻结源变换，不用验证折拟合。
- 同时报行数、组件/捕获/设备数、分组验证AUC及各折变化；有足够组时给组级不确定性。设备/捕获太少时明确限制，不能按数十万关联行制造极窄置信区间。
- 先总体，再在样本足够的同协议/同阶段内比较，辨别协议比例、设备组成和采集活动差异。源与目标设备、采集过程并不相同，域可分性不能自动分解为某一种原因。
- q14-only与E3-only探针差异用于定位关联，不等于已证明攻击头的因果依赖或捷径。高AUC不会取消预定现代头候选，低AUC不会自动批准校准规则。

此项需要训练一个小型诊断分类器，应称“不重训前端或攻击检测头”，不能称完全零训练/零算力。执行前做本地依赖和受限抽样检查，当前尚未运行，也未承诺具体分钟数。

**结束条件：** 一种固定探针、三个输入视图、两个目标池的一轮分组验证报告，记录不足项后结束，不搜索到预期AUC为止。

## 更新后的顺序与分支

1. 先完成原覆盖/修正路径表，以及上述两个诊断的可估计性检查和单轮报告。参考校准的目标效果评价必须先封存源侧规格；不要把“离线”理解为无需预登记。
2. 同时准备现代头的新缓存谱系适配。两个诊断辅助解释和后续选择，不把AUC高低设为换头前置门槛，也不恢复“当前头先降到1%”要求。
3. 完成已定换头矩阵及同一现有入网模块的全部预定配对。首轮不为每个新头再展开所有校准新规则，以免组合膨胀。
4. 将新头联合结果与诊断合看：参考分数能代表后续正常且源保护规则有效→考虑正式校准分支；硬性参考缺口→材料/时间协议；有参考但固定关系不足→学习参考；多头受限且有具体表示证据→再设计汇总/表示研究。域AUC本身不是任何一条分支的充分条件。

暂缓阶段条件阈值、每设备新t0、滚动参考、几何多样性选库和可学习修正的实现。未来如引入学习修正，训练只用合法源FIT/源内开发角色，CAL继续用于校准/保护，不照搬“用FIT/CAL训练”的表述。维持A/B同规则、原冻结验收目标和后续独立确认任务。
