# 小anti意见逐项核对

依据：用户2026-11-05转述的小anti回复，称其阅读了11月5日消融验收报告与11月4日三层诊断报告。下列为Codex的独立判断，不代表小anti已同意这些修订。

## 接受的方向

补充目标设备×协议的1s/10s包速率、IP字节速率、来源数和五元组数；保留768维编码器与q14；加入仅8维的对照；检查A/B防退化、源侧正常FPR与C5新增漏检；明确Edge采集混杂和已消费的数据角色。资源与流式状态必须实测，不能因最终输出只有8维就宣布满足边缘预算。

## 必须修正的表述

1. **架构归因范围。** 本项目被冻结的E3+q14构造缺少设备级跨连接聚合，这不等于“KitNET原生是纯单流模型”。Kitsune原论文IV-B2及Table II包含SrcMAC-IP、SrcIP、Channel、Socket不同聚合范围，KitNET是其检测模块。论文引用应准确区分组件和本项目实际实现。[原论文](https://arxiv.org/pdf/1802.09089)。不将“所有DoS从来不与包头有关”这种绝对论断写成依据，本轮证据限定为所测洪泛场景。

2. **字段捷径是待检验解释。** A64条单包全检出，证明该切片不需要长历史才能报警；A/Edge单包模式及分数不同，支持包头分布相关的泛化问题。尚无字段逐项干预或训练归因，不能声称已证明某个长度/TTL/标志的捷径。源地址多样性也不能单独证明伪造来源身份；本轮原包审计统计的是观测到的地址。

3. **当前包可以合法进入当前包检测。** 旧诊断预登记的是 `j<=i` 且 `t_i-W<t_j<=t_i`，而非小anti提出的 `[t_i-W,t_i)`。当前包已到达，其头和长度本来就用于E3/q14；此前到达且时间戳相同的包也不是未来包。真正禁止的是查询后到达的帧、未来标签等。若改为到达前预测，这是新任务/新窗口，须另行命名，不能静默替换。

4. **离线oracle与线上引擎分开验收。** 旧诊断按时间扫描并用帧前缀约束，计算结果仍只依赖已到达数据，72个真实窗口与独立暴力算法一致；离线排序本身不能证明泄漏。但它不是有界在线实现。线上按物理帧顺序推进；如选用前缀单调时钟，必须与同一种时钟定义的独立oracle对齐，并另外报告其与旧事件时间结果的差异，不能要求两种不同语义天然逐位相同。

5. **10秒过期不等于硬内存上限。** 超高包速率、随机来源和长时间相同/倒退时间戳都可能令活动状态过大。需同时规定状态条数/字节预算、过期清理、异常计数和超限动作；精确版超限明确STOP，不悄悄LRU丢弃。来源IP基数是观测地址基数，不是已认证僵尸设备数；唯一五元组是窗口内出现数，不是精确TCP并发连接数。

6. **历史基线须分口径。** A的未加权ensemble攻击率RAW100%、C5 p3 99.821645%；B为99.993108%。B的正常RAW FPR为39.898447%、C5 p3为1.547472%，不能统称“原A/B均99.99%召回且RAW/C5误报都≤2%”。必须分别列RAW/C5、加权/未加权、总体/设备/协议和分母。防退化要使用预先声明的原门槛与比较对象，不在看新结果后修改。

7. **历史HTTP子层不能冒充整体。** +8.11329裕量、11.95717扣分中位数属于PSH_ACK子层；HTTP全体RAW裕量中位数为+4.54676。7,027是全HTTP撤警数，其中6,209来自PSH_ACK。中位数不是逐条配对证据，逐条RAW/C5判决才是。

8. **C5公式与新头校准。** 冻结定义是 `g(s)=1-(1-s)^3`，`delta_j=0.25*scale_j*g(s)`；若写`1-u^3`须先明确`u=1-s`，不能混用支持度。旧ensemble最大扣分约30.224342，但新头重训后的source-CAL阈值、source-FIT分数尺度必须重新按原算法产生并封存；不能拿旧数值单位套新头。SYN保护继续按原q14规则处理。

9. **不接受+40～+60效果承诺。** 8维统计强可分并不保证新头学会，更不保证给出某个任意绝对logit。应报告RAW裕量m、实际扣分delta、m-delta，以及最大扣分界B的比较；m>B是抗任意支持度撤警的充分条件，不是必须要求所有攻击满足的前提。新头分数整体放大也会改变校准尺度，单看绝对分数变大不能证明鲁棒。

10. **训练角色和公平对照。** 新8维变换/归一化仅用LEARN中的FIT拟合，CAL正常只按原职责做阈值校准，不能把LEARN/CAL混成一个拟合池。原目标已有正常尾部挖掘与类别/设备权重，本轮先保持，不能同时新增未经控制的正常惩罚。保留旧冻结782维锚点，另加同训练配方的782维重训组，再比较8维和790维，分离重训和新增信息的贡献。
