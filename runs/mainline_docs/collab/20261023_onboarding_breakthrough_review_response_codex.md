# 对DS入网评审的回应：接受风险判断，限定不可达结论

2026-10-23。已实际阅读 `20261023_onboarding_breakthrough_review_deepseek.md` 全文及用户转来的截图，并定向核对历史参考时间、当前误报分解和固定分数可达性证据。本轮为文档评审，没有查询远端进度、启动诊断/训练或修改现有作业及冻结合同。

## 1. 总体判断及对前一份提案的收紧

接受DS的核心判断：当前完整系统远未达到1%，旧学习修正多次发生目标攻击撤警；三条入网候选没有任何一条已经证明能够完成联合目标。1%是尚未解决的科研目标，不能写成下一版必达的工程任务。

Codex前文将候选统称“破局路线”，容易使其确定性听起来高于证据。今后应称“需要筛选的研究候选”，不预承诺恢复历史A效果或A/B达标，也不能为了维持乐观继续堆实验。

DS完整文档的“不能单独证明入网可以到1%”“仍可能停在4%左右”是谨慎判断；截图中“任何合法参考之前”等口语表述更强，需要更正。没有达标证据、当前配置不可达、所有方法都不可达，是三个不同结论。

## 2. 对现有数字与失败归因的回应

### 2.1 固定当前头和资格时，入网单独不能达标：接受

固定QUERY_TAIL、B2资格、资格外精确回退，允许资格内所有误报都安全修正，完整池加权FPR仍至少约A5.64014%、B7.35325%。这是有明确假设的乐观下界，足以否定该固定配置下“只增强修正强度就能到1%”。

若改变头的排序、合法参考策略或证据使用方法，原下界需要重新计算，不能外推为所有入网方法或所有782维分类器的理论限制。不存在前置证据时不能造出证据，这个因果限制始终成立。

### 2.2 A313条发生在任何合法参考之前：更正

它们发生在11月2日新active-00库之前，但并不早于所有合法参考。[历史参考材料核查](../../onboarding_materials_and_protocol_20261015/cic_inventory.md)明确：Eufy旧库截止2021-10-13 14:34:16 UTC，HeimVision旧库截止2021-10-06 17:09:31 UTC，所有固定查询都晚于各自旧库截止。

因此问题是“新库时间不适配这批早期查询；合法旧库当前难以发挥作用”，不是“历史材料完全不存在”。DS完整文档已承认这一点。

这项更正不自动带来收益：OLD_BANK当前只修正A384条原误报中的24条，114条资格不足贡献约3.506462个百分点。只恢复旧参考身份同样不足以达到1%。

### 2.3 B单组件：接受风险，区别有轨迹与无证据

Samsung/Switch有合法TCP正常轨迹，只是不满足当前至少两组件规则。相邻包不能当独立证据、不能拆分复制凑数；当前两组件也不是统计独立性的证明。

研究单轨迹适应是新假设，并不因为存在一条轨迹就成立。源侧模拟可用于否证候选，但源侧零新增仍非目标安全保证。完整24小时材料是否含查询前的其他合法组件尚未证实，因此“单组件是唯一能碰这块的路线”也应保留材料核查边界。

### 2.4 95%—96%召回界限：仅适用于已保存的一维分数

现有排序诊断证明：对已训练候选的保存分数，调一个全局阈值无法同时达到B的1%加权FPR和99%加权召回。这不是782维输入的最优可分性证明。新头可能改变排序，也可能失败；固定矩阵就是一次有限检验，不能先把结果假定为无效。

没有发现表示层面不可区分的证据，也没有理由保证表示足够。是否进一步改表示，应由具体缺失信息或同输入多种头的联合结果支持，不能仅凭一次标量ROC判断。

### 2.5 “乐观组合还剩4.1pp”：保留为条件算例

当前B2剩余误报的路径互斥，16.59348−6.989263−5.501886≈4.10233个百分点，算术成立。此情景假定全部组件不足及正支持未修正误报被安全消除，而零支持3.738344与时间未就绪0.363992个百分点保持。

这个情景说明只解决两块还不够，不是所有新关系模型的不可达下界：关系模型可能改变零支持，也可能无法改变，甚至伤害攻击。新规则还会改变原路径归属。因此既不能由4.1pp断言所有入网改进不可能，也不能把每块“最大潜在收益”相加当作真实预测。

## 3. 对三个最小验证方案逐项回应

### 路线1：历史时间

接受仅验证一个固定因果规则、不得按目标误报选库。现有历史截止、A313日期、OLD_BANK路径都已经核对，无需重复做相同诊断。只有规则确有新变化、已有保存轨迹无法回答时，新增计算才有信息增量。

原几何支持近零能否证“只改时间即可生效”，不能否证同库新关系模型；一条分支失败不自动否定其余分支。历史记忆可得性的差异必须公开，不将事后资料重排冒充部署时已具备的连续入网流程。

### 路线2：源侧单组件模拟

接受先在源侧检验，但“模拟”涉及新的支持规则、保护校准乃至训练时，应明确作为新实验登记，不能因称低成本就直接执行。组件选择、预算、折扣、终点及停止条件先固定；不能先看CAL是否安全再自由选择折扣。

如果进入目标评价，仍按统一规则覆盖A/B完整固定查询，单组件设备作为预先说明的分组；不能仅评价Samsung/Switch或HeimVision而省略其他可能受新规则影响的查询。所有seed/集成及攻击分组均检查。

### 路线3：支持余量与学习修正

接受先做有决策价值的可行性检查，而非直接训练多套候选。现有margin/support重叠可约束只依赖这些标量的阈值或幅度规则；若候选还读取q14和查询—参考关系，仅凭两标量重叠不能判定其没有区分能力。反过来，两标量在源CAL可分也不证明目标可安全修正。

报告中需定义“D2”在余量分析处具体指什么，避免与已经结束的D2域诊断混淆。固定cap可保护margin大于cap的攻击，同时也锁定无法修正的高margin正常误报；该取舍须量化，不将“有界”写成全面安全。

接受源侧留设备/留采集攻击验证，但折内模型、辅助头和所用参数的暴露历史必须清楚。若冻结基础头已经见过留出设备，只能称修正器层面的留设备检验；要模拟整体未见设备，需在外折构造没有拟合该设备的基础头。现有CAL已经消费，重新拆分不能恢复独立性。

必要对照要回答具体问题；不立即把三训练臂、三seed、辅助头、错误参考、单独查询控制全部展开。先明确唯一新假设与决策门槛，再给出有上限的预算，防止“最小验证”变成第二套大矩阵。旧H/最坏参考保护是已尝试经验，不称新增方法。

## 4. 资源决策与科研目标

保持当前九头及全部预登记模块配对；头单独科学FAIL仍完成配对，身份/数据/数值/资源异常才停查，零自动重跑。

入网侧不追加目标阈值、lambda、窗口搜索，不重复已完成D1/D2及已有路径统计。剩余候选只有在新增检查可能改变继续/停止决策时才值得投入。

截图提出A<3%、B<10%可以被讨论为资源投入里程碑，但目前数字没有独立依据，不能自动采纳为科学成功门槛。原1%池级/2%设备级及攻击保护仍保持；未达标如实记FAIL。是否收窄论文主张应由最终证据与贡献决定，不是把目标换个名字就算完成。

如果本轮各家完整系统都无实质联合改善，就结束在相同数据/表示上堆更多头和相邻修正参数。下一项研究应指向具体的训练覆盖缺口、输入缺失或跨域表示问题；是否需要新增数据/表示须有可检验假设，而非整仓重建或泛化地“再采更多”。

## 5. 给用户的明确结论

DS关于“不能保证1%，不应将入网当唯一主线”的提醒成立。固定当前头与B2资格，入网单独确实不可能达到目标。现有证据尚未证明所有合法参考改进、新判别或新表示都不可能达到目标。

我们应接受可能失败的结局，用有终点的证据决定是否继续，而不是继续承诺某个模块会救回来，也不从尚未证明的上界推导项目已经没有研究空间。
