## 3. 完整预登记规格正文

### 3.1 假说名称与唯一性声明

- **名称：** `LOCAL_NORMAL_REF_GEOMETRY_V1`
- **唯一性：** 本文件确认其为**唯一**待定稿假说；禁止平行候选；禁止用源 Atomi 1C 账本代替本假说的保护/选择性检验。
- **意图：** 查询相对冻结正常参考的局部几何关系——统一协议半径可能把部分设备正常局部变化当异常；若查询落在稳定局部邻域且按邻域尺度仍近、攻击仍偏，则有机会抬正常 support、限制攻击修正。
- **不是：** 裸 donor / 设备身份主信号；**不建议**攻击记忆库第二路线。

### 3.2 冻结公式

对每个合法参考 `r`，从冻结参考内部（排除自身；处理重复/组件相关性后），按事先固定程序得到局部半径 `ρ_z_local(r)`、`ρ_q_local(r)`。对**同一个** `r`：

```
J_local(x, r) = max( dz(x,r) / ρ_z_local(r) , dq(x,r) / ρ_q_local(r) )
```

聚合：1C 按原固定资格取同组件不同位置的第二小值；2C 取两个不同真实组件的第二值 → `J2_local(x)`（即文中 `J_local^2` 记号所指的联合第二距离量，非对 `J_local` 再平方一次的软化强度）。

新增支持（唯一固定；保留 D0、支持上限 1、原 λ / score-scale / cut）：

```
a_new(x) = max( a0(x) , I_legal_and_scale_ready(x) × clip(1 − J_local^2, 0, 1) )
```

- **线性 clip 唯一：** `clip(1 − J_local^2, 0, 1)` 按 Codex 写法固定；**删除**平方软化备选；禁止事后互换强度曲线。
- **单 seed 额外降分：** `.25 × scale × (a_new − a0)`。
- **判定：** 集成按原保存 float64 分数算术和，严格 `score > cut`；不靠近似 margin 或新 epsilon 放过。
- **λ = .25：** 沿用上界盘点合同（既有主头/目标工作点），**非**本轮新选。
- **空操作检查：** 若所有参考局部半径都 ≤ 原协议半径，则局部 joint 只会更大、局部 support 只会更小，`max(a0,·)` 后原 2C 不变 → 仍修不了 TP Link 零 support。故必须允许有依据的局部放宽及其上限；上限一律钉死在原 ρ 后不得声称有 2C 收益空间。
