# ToN 密码攻击 · 冻结分数与支持度的连接级回放

本轮仅在超算复用上次 ToN 正式缓存。DAD 按单独执行卡继续评价原版 v12。ToN 只改变离线回放中的 λ，固定 p=4、基础头、集成方式、阈值、基准跨度、支持度、参考资格及旁路。无需下载新数据、重训、重新生成特征或重算近邻。三种子集成为主。先沿用[项目工作约定](../../../AGENTS.md)及[实验窗口四项长期约束](20261118_paper04_v12_next_experiments_handoff_codex.md)，核对[原始接纳与身份合同](../../p4_ton_password_frozen_v12_20261118/IDENTITY_AND_PAIRING.md)、[封存数组、数据库和 SHA](../../p4_ton_password_frozen_v12_20261118/received/HPC_ARTIFACT_SHA.json)。

## 一次回放，三张小表

1. **降低扣分能救回多少连接。** 在三台可按逻辑主机配对的目标上，按 λ = 0.25、0.20、0.15、0.10、0.05、0 回放；0.25 是已验收的 v12 对照，0 是 RAW 对照。每个目标内沿用原连接标识并区分采集与攻／正常，任一合格查询严格高于阈值即判该连接报过警。主结果用全包视图。每档列攻击／正常合格连接数、RAW 已报连接数、该档已报连接数，以及**相对 0.25** 从全程无警变为至少一次告警的攻击连接数和正常连接数。另报占 0.25 时已被完全撤警的 RAW 攻击／正常连接的比例及其分母。按主机列出后再汇总，特别并排看 Windows 10 的攻击恢复数和中间件服务器的正常误报回升数。旁路外带数据子集可沿用原掩码单列，子集内沉默与整条连接失警区分。严格跨实例的 CCNR 主分析仍记为未评价。各档是敏感性分析，不据此改写冻结配置。
2. **哪些连接被基础头从头漏到尾。** 用四目标 RAW 全包视图复现 76,677 个连接中 61,866 个至少一次告警、14,811 个完全没有告警，再在这 14,811 个连接内归类。以封存的全部合格入站查询为范围，有至少一个传输层数据长度大于零的包即归入“出现数据仍全漏”，其余归入“只观察到无传输载荷包”。使用独立的 transport_data 字段，不以旁路标志代替载荷长度。无数据组中可据实际 TCP 标志单列纯 SYN 等控制包，按协议列清 UDP 或不能确认握手语义的情况。两大类分别报各目标及合计的连接数、占漏检连接比例，并核对合计等于 14,811。“只观察到”只指纳入评价的入站包；数据长度大于零不能直接折算为登录尝试数。
3. **失警攻击与消除误报的裕度和支持度。** 在原版 λ=0.25、全包视图固定两个队列：Windows 10 中 RAW 至少报一次、CCNR 后整条无警的攻击连接；中间件服务器中 RAW 至少误报一次、CCNR 后整条无警的正常连接。只看这些连接里原本越过源阈值的包。对每包保留同一 UID 的 M_i（集成 RAW 分数减原集成源阈值）和三空间支持度 s_i。主表按原始帧序取每条连接首个 RAW 告警包，让每条连接等权，分别报 M_i 和 s_i 的 P25、P50、P75 以及连接数。另对队列中全部 RAW 告警包给出相同分位数及包数，单列包级结果；注明分位数算法，空组记为不适用。原来有多包告警的连接，只有全部撤掉才可进入队列。
