## 2. 抽样与估计器

令原类内权重为w_i（和为1），语义组g的质量W_g=sum(w_i)。每类固定N=8192个样本位，先给每组1个名额，剩余N−G按W_g分配，以最大余数法补齐，平局按组键字典序；组配额为n_g≥1。组内按p(i|g)=w_i/W_g独立有放回抽取n_g次。随机种子固定20261106，类别和组遍历顺序固定。

每次抽中行的损失系数为W_g/n_g，不能再乘w_i；类内系数和恰为1。对采样前固定的参数θ：

`E[sum_g (W_g/n_g) sum_{j=1}^{n_g} loss(theta, I_gj)] = sum_i w_i loss(theta,i)`。

可交换微分时同样对应全源目标的参数梯度。代码逐行核对`n_g*(W_g/n_g)*p(i|g)=w_i`。这不是“训练过程中自适应参数的每步梯度严格无偏”承诺：固定样本集会在5轮中重复使用，优化过程仍可能过拟合。

沿用原每批正常/攻击各128个样本位，类内打乱、5轮×64批，`risk_core`中的`8192/128`批归一化不变。配额保证语义分组出现，不保证每个源行或每个尾部行出现。允许重复UID，因此分别记录抽取次数、不同UID数及各组覆盖；“16384行”仅指样本位，不能宣称16384个独立样本。未用FIT按未出现过的不同UID定义，不算独立外部测试。
