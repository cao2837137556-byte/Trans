# D1/D2 规格复核回执

2026-10-22。回应 [DeepSeek复核](20261022_additional_ideas_response_review_deepseek.md)。已补 [D1/D2首轮登记稿](../diagnostics_d1_d2_spec_v1_20261022.md)，未实现或执行诊断、未修改冻结实验包。以下为明确选择，不再保留待选算法清单。

## M1：采用单条预登记，不做CAL选变体

接受FIT样本内分数不能承担规则泛化验证、CAL不可反复选结构的意见。首轮固定D1_LOCATION_CAP_V1，不用FIT效果挑规则，不做median/MAD等变体搜索，也不启动CAL交叉拟合。复用已有源FIT机械尺度不等于在FIT上选最优规则。

原源CAL阈值不动；CAL只进行固定候选上限的攻击保护标定，候选0/0.05/0.10/0.25，按每seed及集成整数零新增漏检取最大通过值，不看正常FPR选择。单条算法允许事先定义的参数标定，但不能将校准集上的保护结果称为独立验证。若以后比较多规则，需另行拆分并处理原阈值已使用全部CAL的事实，不能认为加一层交叉拟合就自动完全独立。

## M2：估计量、分组、封顶及回退已定义

首轮选择**位置修正，不作MAD标准化**：同设备同协议，原参考身份/整库截止保持，至少8个不同组件、组件等权、ESS=n；明确下中位数定义。MAD仅描述，不作除数，不存在待选尺度下限。源位置锚点使用专用SOURCE_REFS、同协议、排除当前被模拟设备，至少8组件，不用目标查询拟合。

逐seed修正为：

```text
delta = min(max(参考中位数 - 源锚点中位数, 0), lambda * 原源FIT分数尺度)
新logit = 原logit - delta
```

仍与原cut比较；先逐seed修正，再按原mean-logit集成与原ensemble cut比较。无合法参考/统计不足/时间不符直接原判；不借其他目标设备的protocol/global分布。原全局回退只是基础头回退。

源保护特意用完整lambda×尺度做压力检查，不只用源库当时可能为0的实际位置差。这更保守，可避免源参考与源锚点接近造成的空保护。缺合法CAL攻击或原已检出攻击压力覆盖的协议回退；lambda只有0通过时保持零操作，不调候选。

已核对源104组件：≥8的本设备源库仅ArloQ TCP8、SimCam TCP8、Amcrest UDP63，排除自身后的源锚点分别15/15/18组件。统计定义可落地，源设备覆盖限制仍必须披露。源保护通过不担保目标攻击。

不增加行权重敏感性预测对照；参考本轮统一组件等权，查询评价沿用原权重。MAD、分布和权重集中度只作描述，避免重新打开规则搜索。

## M3：资格边界只在指定前提下使用

同意。旧5.64014%/7.35325%仅适用于原头+B2、资格外原判的场景。本D1因min8更严格，应另算自己的资格残留，旧数值只是较宽松的下界。不推广到新头、全局阈值改变或几何正支持规则被移除后的更紧边界。

## M4：接受分组隔离，但必须纠正单类“跨域划分”

源正常是域0，目标正常是域1。**只用源训练、只用目标验证，训练集和验证集各只有一个域类别，既不能拟合域逻辑回归，也不能计算有效域AUC。** 这是数学定义问题，不能采纳复核中该主分析安排。源单类模型可以另行设计，但不属于本轮域二分类。

确定采用：源和目标各自按依赖组分折，再合并两域训练组拟合，合并两域留出组评价。目标正常及其域标签参与诊断器训练，文档如实说明；这不是源训练攻击头向目标部署的验证。严禁随机行拆分。

登记稿固定L2逻辑回归C=1、lbfgs、1000迭代上限、1e-4容差；E3/q14/拼接三个视图、3折、seed27；每域最多10,000组件代表。依赖组连接相同物理端点、组件及同捕获10分钟时间块；巨大连通组不人为拆分。至少6组/域、每验证折至少10组件且2组/域，不足记NOT_EVALUABLE。明确不是完全捕获/设备留出，避免过度声称。

每域等质量、域内设备×协议层等质量；标准化只拟合训练折；报各折AUC，不直接合并不同折分数算一个AUC。足够组数时才给固定预测的组级bootstrap区间，不作逐行重采样。主材料为可信参考，次材料为DEV正常查询，各自独立拟合，不混用目标标签边界。

解释表已加入：高AUC仅支持当前材料存在可利用的区分信号；低AUC是该线性探针未检出稳定差异，**不写“域差异不存在”**。q14/E3关联不能唯一归因或自动证明有害捷径；D2不控制换头、校准批准或前端重建。

## M5：代表性差不能事后删除或重标结果

接受事后代表性检查不反馈到模型。**不接受“看目标查询发现不一致后，缩小适用设备范围或把已执行失败改为整体NOT_EVALUABLE”。** 这会按已见目标结果改变报告范围。

登记为：参考与后续正常不一致时，保留所有设备、完整分母、真实FPR/漏检及原科学判定，另加REPRESENTATIVENESS_LIMITED解释。NOT_EVALUABLE只用于事前的材料/统计/分折不足，或该描述量本身无法计算；不能遮盖已得到的负结果。

## M6与后续顺序

接受单条规则失败不代表方法族上限。D1结束于一条固定规则的四库配对和代表性报告；D2结束于两材料×两池×三视图×三折，最多36次小探针拟合，含不可评价项。依赖、输入哈希和分折清单在实际执行前封存；当前没有新预测或新AUC。

顺序保持：覆盖/误报路径表＋D1/D2单轮 → 固定换头与同模块配对 → 综合决定后续。D1源保护通过、目标改善且零新增漏检时，才支持进一步研究该校准规则；任何域AUC都不能单独决定分支。主方案和主线已同步，现阶段无需再扩大诊断方法清单。
