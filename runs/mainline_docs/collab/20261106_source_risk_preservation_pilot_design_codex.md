## 3. 固定单侧目标

对匹配种子，令f0为原融合头，f为候选头；S为原FUSION790全FIT加权q90−q10尺度；U为f0在全FIT正常样本上的加权90%分位。二者本轮固定。

令x0是仅将归一化后的8维置零的输入，d0=f0(x)−f0(x0)，d=f(x)−f(x0)。置零是源归一化均值背景，可能脱离真实联合分布；仅作正则项，不作真实训练标签或部署成绩。

1. 正常风险：`LN = E_normal[relu((f(x)-U)/S)^2]`。推动高分正常尾部下降，即使原BCE已饱和也有明确信号；低于U的正常样本无该项惩罚。
2. 攻击保护：`LA = E_attack[relu((f0(x)-f(x))/S-0.01)^2]`。允许最多0.01S的下降空间，超过才惩罚；不阻止攻击分数上升。
3. 正向context保护：`LC = E_attack[1(d0>0)*relu((0.9*d0-d)/S)^2]`。仅保护原头已有的正向贡献，不要求复制负贡献。
4. 总目标：`LN + 10*LA + 10*LC`。固定系数是本轮试探性工程选择，没有进行性能搜索；软惩罚不构成严格数学保障，端点必须单独验收。

本轮不叠加已经饱和的BCE/TAIL，也不加全样本双侧logit锚定。训练所有小头参数（790→128→1），不更新768编码器；context保护不是冻结8列权重，作用在实际输出贡献上。

AdamW：lr=1e−5、betas=(0.9,0.999)、eps=1e−8、weight_decay=0、foreach=False。每种子5轮×64批=320更新，三种子共960更新；只报告固定第5轮端点。保存逐轮头、分项损失及每轮第1/32/64批正常与保护梯度关系，不按日志挑端点。
