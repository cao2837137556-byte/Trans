## 2. 接受非阻塞边界，并收窄早期探针措辞

sanity 是固定探针 batch 的有限精度一致性检查。它通过，只表示分量梯度和与实际总梯度在预定界内一致，不能单独证明 TAIL 仍在反传、有明显作用，或产生有效 Adam 更新。

设 `r=||g_TAIL||/||g_BCE||`、BCE 梯度范数为 `b>0`。忽略舍入、实际 backward 漏掉 TAIL 而 expected 仍完整时，漏项残差按分量范数和归一化约为 `r/(1+r)`。含绝对下限的不可检区为：

`r <= (1e-4+1e-30/b)/(1-1e-4)`。

忽略绝对下限约为 `1.00010001e−4`；因此 r<1e−4 是充分不可检区，不是精确断点。BCE 零范数时 r 不定义，仍按既定状态码和绝对/分量界处理，不凭空填零。

对 Claude “由 epoch 1 探针负责证明”的表述作一个非阻塞限定：**P5a 仍是跑前预测，内容为 epoch 1 三个观测点中至少一个有效 r≥0.1；不是首探针保证达到，也还不是实测事实。** 若实际探针达不到，不能用这个预测为真实训练担保；按原登记判读支持、观测点不支持或有效观测不足，不改规则。

ObjectiveTests、两种漏项负控和当前源码/包绑定共同支撑该实现。若真实早期某探针观察到较大的 TAIL 梯度且 sanity 通过，只支持该点在容差内包含相应分量，不能外推到后期或全部未观测 batch。

## 3. 后续结果怎样解读

- TAIL 分量梯度范数和有效 ratio，回答它在所测参数点是否提供梯度、量级相对 BCE 多大；cosine 补充方向信息。不能用损失很小直接代替梯度很小。
- late sanity 通过不能作为 TAIL 活跃性证据。P5 使用有效 ratio、状态和观察数，不能把无攻击或零分母点当 r=0，也不能把稀疏探针扩写为全阶段结论。
- Adam √v̂ 与非零一阶矩摘要辅助判断优化历史和 epsilon 尺度；它们不能单独归因 TAIL 的实际更新贡献。早期 TAIL 留下的参数与历史不会因当前 TAIL≈0 而消失。
- 最终低误报与攻击保护效果由固定四臂、三 seed、40 轮的实际结果和原科学门槛回答。代码审阅通过不构成科学通过。
