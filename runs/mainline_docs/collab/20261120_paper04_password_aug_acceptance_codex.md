# 密码攻击增强实验独立验收

2026-11-20。修订运行 r1 通过交付验收。增强头改善了留出主机的密码攻击检出，三种子集成在 Edge 上也保住了更多原有攻击告警。正常误报增加、部分泛洪检出下降，建议论文保留 v12 为主系统，把增强版作为受控对照。

## 验收依据

从 `received/CURRENT.json` 定位 r1。逐一核对远端清单内 66 份文件的字节数与 SHA-256，以及 18 项作业的阶段回执、作业号和 Slurm `COMPLETED 0:0` 记账。核对了部署包、包内文件、冻结参数、三份不同的模型摘要及源正常校准误报预算。作业 186173 冻结三个模型及阈值，之后才运行密码场景评价，最终作业号 186221。基于 D 盘配对表逐行复算原告警、新告警、新增、丢失、共同检出和共同漏检，三组比较共 192 行。另核对 128 行 v12 复现对照。此次复核使用回传表和回执，逐包大数组保存在超算。[超算验收](../../p4_password_aug_v1_20261120/received/r1/ACCEPTANCE.json) · [回传清单](../../p4_password_aug_v1_20261120/received/r1/RETURN.json)

实际补充 41,439 条攻击关联连接和 94 条带数据的正常连接。三组均分新增攻击权重，合计占攻击类权重的 20%。两台 ToN 训练主机的设备状态按移除 Windows 10 贡献后的时间窗重算。CIC 正常校准使用 33,147 条查询，增强集成在该校准集的加权误报率为 0.8674%。[训练输入](../../p4_password_aug_v1_20261120/received/r1/TRAINING_INPUTS.json) · [模型冻结](../../p4_password_aug_v1_20261120/received/r1/CANDIDATE_FREEZE.json)
