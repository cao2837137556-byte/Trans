# 冻结 v12 的 60 秒连接历史实验复核

2026-11-21。运行验收通过。预登记的旁路达到 Windows 10 密码攻击恢复目标，超出 Edge 和 UNSW 的正常误报预算。建议保留 v12 原判决，把本轮作为连接历史在不同业务中触发情况的配对实验。

## 原因与供体

Edge 的 9,710 条合格入站 TCP 正常查询中，9,705 条触发保护。源端学到的绝对门槛在该设备正常业务中太常见，重新放出了大量原已撤掉的误报。此结果适用于已测的活跃五元组门槛。[分组触发表](../../p4_ccnr_history60_v1_20261120/received/HISTORY_COVERAGE.csv)

原 v12 撤回的 4,406 个 Edge 登录 POST 均发往端口 80，每个 POST 实际获得支持的两条正常参考均对应端口 1883。作为对照，16,699 条原本正确消除的 Edge 正常误报查询中，16,459 条查询和两个供体都在 1883 端口、受保护设备均为响应端。Win10 被撤的 13,818 个旁路外带数据攻击查询中，有 13,713 个可确认查询时设备是端口 80 的响应端，而两个供体中设备均作客户端。部分其余记录角色证据不全。服务与角色是值得单独核查的差异；这些计数只描述原获胜供体，无法直接推算限制供体后的效果，现有资料也缺同服务正常登录的误报分母。[服务与角色明细](../../p4_ccnr_history60_v1_20261120/received/DONOR_SERVICES.csv) · [同服务正常对照覆盖](../../p4_ccnr_history60_v1_20261120/received/DONOR_MATCHED_COMPARISON.csv)
