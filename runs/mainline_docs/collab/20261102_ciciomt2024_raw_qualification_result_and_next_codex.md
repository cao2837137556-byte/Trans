## 独立讨论达成的判断

1. **因果主测试硬门失败，范围仅为当前四包角色组合。** 作者的 train/test 名称、发布年或 Windows 文件修改时间都不能代替捕获的真实先后。其他未取得文件没有被预判失败。
2. **正常材料仍有补充价值，但角色须另行闭合。** 11月材料可继续核实正常侧 FPR、正常 SYN 行为及跨日覆盖；重试另须序列号等证据，不能从 SYN 标志推断，也不能把全部正常 SYN 告警直接归因于守卫。它不能单独证明攻击召回或 ACK/UDP 撤警安全。正常侧增强 FPR 与较早攻击的 RAW 召回不能拼装为完整方法外部确认。本轮未运行这些评价。
3. **严格 RAW 回退不等于安全验证通过。** 对8—9月攻击没有可用过去银行，若增强没有实际参与，其零新增漏报只是结构性结果；须报告有效参考覆盖率，不能据此声称扩大正常库对非SYN攻击安全。
4. **有界核查 Benign 元数据是唯一当前救援入口，不扩大盲下攻击包。** 已登记目录确有 `Benign_train.pcap` 和 `Benign_test.pcap`，但尚未取得，其日期、字节数、设备、正常依据均未知。更早可信正常、完整两小时及同一目标仍需证明；只提供更晚正常的更多攻击大包不能解决当前问题。
