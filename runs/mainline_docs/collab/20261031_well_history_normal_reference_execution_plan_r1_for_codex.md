- **处理：** 最终 A/B 只评价一次，以逐设备保护门为硬判据（§4），不达标即结项；结论披露为**开发级**（A/B 已多轮接触，且无目标设备开发保护）。

## 4. 档位、门槛与停止
- **档位：** 只有 1 档（C1，§1.5 的 4,096 上限，事先由已有规则确定），无回退、无 Samsung 特例、无对照之外的分支。必要对照 = 179700 原结果（不重跑）。
- **DEV 门（B，A/B 之前）：** 在 HIST-DEV 上，对每台 B 目标设备，用 ensemble 头计算冻结 cut 下的 FPR。若三台中**任一台** C1 的 DEV FPR 未低于 support=0 对照，或三台加权（按 DEV 行数）FPR 降幅 <50%，则 `STOP_DEV_FAIL`，不看 A/B。A 无 DEV 门，直接随 B 进入一次评价。
- **A/B 一次评价（seed27/127/227 与 ensemble 各报告；判定用 ensemble，保护需四头全部满足）：**
  - `PASS`：A、B 池 FPR ≤2%，四台目标设备各自 FPR ≤2%；池召回 ≥99%；相对 179700 RAW 累计撤回：逐设备 ≤1pp、逐活动/攻击组 ≤5pp；原 RAW 召回 <99% 的设备/组不得撤回任何 TP。
  - `IMPROVED_NOT_PASS`：保护全部满足，且 B ≤9.019653949% 或 A ≤3.493481531%，但未 PASS。只报告。
  - `FAIL_PROTECTION`：任一保护不满足 → 结项。
- **直接结项条件：** `STOP_DEV_FAIL`；前端适配后任一目标设备新组件数为 0；任何预算超限；`FAIL_PROTECTION`；A/B 评价后不论结果均不追加档位、不重跑。结项后不复活局部几何、budgeted v2、参考竞争、源 Atomi 1C；后续仅考虑用户另批的表示/组件层改动。
