| 原因 | 可研究变更 | 必须保留 |
| --- | --- | --- |
| 合法早期记录存在但被选库漏掉 | 同预算/截止/协议下重分层选真实组件 | 规则源侧冻结，不按 A/B 改善量挑规则 |

**攻击否决（替换前稿「CAL 近邻禁止入资格」）：**  
FIT 构建/学习否决 → 源侧留出检验 → 规则冻结后 CAL 最终保护。若拆 CAL 作开发材料，必须披露并另取未用于规则选择的保护集。

三层攻击压力分别报告：结构合法静态 cap 可达；G 通过且 a>0 的可达；实际跨 cut 新增 FN。保守「理论可达>0 即筛」若采用，须登记为**新增设计限制**，不等于已漏检，也不排斥近边界攻击区分能力检验。

固定 HARD 检查点只适用于：50 维槽位、两组件代表、normalizer、FIT t/s、头与 cut 不变时的 bank/gate 干预诊断。改组件数/槽位语义 ⇒ 旧检查点失效；旧 CAL seal 不证明新资格已安全。

### 阶段 2 — 仅当阶段 0 显示「可达质量足够但参考使用失败」

可复用 WRONG **评价**构造规则作控制，但当前训练是 NORMAL_OWN_BANK_ONLY，**不是**现成 own/wrong 配对合同。新合同至少冻结：query/own/donor 身份、参考 UID、N/C、时间截止、matching、计划 hash、按 query 归一权重。

损失候选（非已定数值配方）：保留正常残差目标与攻击最坏合法 bank 保护；仅对 FIT 预定义的「own 支持强、wrong 支持弱、且存在应修正常残差」配对加排序/差异项。**不对每个 wrong 强制 a_wrong=0**（共享正常行为存在）。

归因主分母：先按**结构规则**冻结精确匹配集 M，再在 M 上比较两套完整部署决定（一侧 G 拒绝则回退 BASE，行与原权重保留）。双方都激活子集可另报，不能替换主分母。

泄漏红线：CAL 攻击不作否决原型/难例/loss/检查点选择；A/B 标签可作已披露诊断，不可挖训；已接触当前 CAL 压力须披露开发接触。

**成功声明（收窄）：** 在预登记效应下可说「匹配集合上 own 相对 wrong 的部署收益达门槛」；在 attribution 合同通过前，**不得**宣称已证明设备自身特异性入网适应。  
wrong_control.equally_effective=false **单独不够**（可能因 wrong 新增 FN）；须同时：own 绝对收益、攻击合同、QUERY_ONLY 对照、匹配覆盖、预登记 own−wrong 加权效应与依赖分组不确定性。

**停刀：** 条件配对下仍无稳定 own 优势 → 调整主张（允许共享参考机制），转入阶段 0 已定位的几何/强度备选；不人为在目标里制造身份差异。

### 阶段 3 — 备选机制（由阶段 0 差分触发，不再要求「1+2 先胜出」）

同一完整资格集 S、S 外均回退 BASE、同一全池分母 W 时：全池 FPR 差 = S 内加权报警差。若见「子集赢、全池输」，先查子集是否只是 WRONG 匹配集/资格交集/不同支持门。

资格集不同时，按 **交集 / 仅学习 / 仅 V3 / 均无** 四格分解再除以全池 W。

「资格内输 V3」可能来自 strength 映射、残差目标、采样、优化、尺度或攻击压力，**不**单独等于表征失败。仅当阶段 0 显示 V3 有效几何未被学习臂利用时，才研究可学习几何/几何+残差；若只是强度不足，不必立刻改表征。

| 方法 | 再议条件 |
| --- | --- |
| 加 epoch | FIT 优化未收敛且源侧留出一致；有限增量+停止规则；不看 A/B 挑轮 |

| 动 cap | 加权分账证明确实瓶颈，且有独立近边界真实攻击压力与完整新校准；不为跨 1% 直接放大 |
| 借鉴旧 Qref | 可借鉴关系度量归纳偏置后**重新初始化** FIT 训练；直接接旧权重仍不支持；warm-start 须语义映射+暴露审计+消融 |

## 5. 论文级成功 / 失败收束（去普遍化）

- **主成功：** 预登记合约下双池加权 FPR 与逐设备门槛达目标，攻击守门，且特异性归因合同 PASS（若主张个性化）。
- **次成功：** 严格保护下，可归因或可分解的修正机制稳定优于纯几何，给出迁移边界。
- **失败收束（r1）：** 在本次登记的数据、seed、预算及候选方法族内，未实现双池目标／自身参考归因；记录 V3 优势及覆盖、幅度、参考使用的有限证据；**停止该候选族的无依据重复训练**。  
  **不得**据此宣称「端侧有界学习一般无法达到双池 1%」或「误报只由几何与覆盖决定」。
