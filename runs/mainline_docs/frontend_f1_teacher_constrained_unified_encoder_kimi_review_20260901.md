# Kimi Review：教师约束统一语义编码器提案（Frontend-F1 方向）

- 日期：2026-09-01
- 审查人：Kimi（独立审查方）
- 对象：Codex 提出的「保留 H1-H4 语义层 + 旧 P2 教师约束下训练统一编码器」方案（纯文本提案，未形成正式草案）
- 性质：方向裁定 + 修改条件，非协议冻结

## 0. 总体裁定

**方向 ACCEPT，附 M1-M7 修改条件。**

这是 CE 学习型 blind-spot branch 因 29<30 独立攻击上下文封路之后，
唯一仍合法、且可能让 B（old_missing=true，11,640 目标）获得学习型表示的路线。
A 的丰富攻击知识通过蒸馏约束进入训练，不违反 blind-spot-only 训练的 29 上下文门，
因为训练对象已从「盲区单独表示学习」变为「全宇宙统一编码器 + 教师约束」。

但提案当前形态有四个硬伤，不修正不得进入草案阶段。

## 1. M1：谱系与部署结构必须澄清——建议「统一训练、扩展部署」

提案第一阶段是 A、B 全量走「H1-H4 → 新编码器 → 冻结 P2」。
这与 CE FROZEN（0b102b79…，Kimi 终审 1e68c55）的在役不变条款直接冲突：
CE 规定 old-finite 13,827 目标必须继续走冻结 E3/P2，逐目标不变。

裁定：

- 本提案不得作为 CE 协议的修订，必须开新谱系（建议命名 Frontend-F1）。
- 推荐结构：**训练统一、部署扩展**——
  训练时 A+B 全量参与（A 提供教师信号），
  部署时 A 仍走旧路径（一个字节不变），仅 B 走新编码器+冻结 P2。
- 该结构同时满足 CE 在役不变条款，且可直接作为 CE-2/CE-3 的编码器候选：
  B 侧 4,812 条 select 硬判决若下降 ≥482，即触达 CE-5 晋升门。
  两条路线因此可以合并，而不是互相排斥。
- full replacement（A 也换路）仍按此前裁定封存，
  仅当扩展模式经冻结实验确认不足时另立预注册。

## 2. M2：判决约束必须 label-aware，否则液压误报被蒸馏锁死（内部矛盾）

提案约束 4 原文：「A 上原来判攻击的样本不能大规模翻成正常」。

若不加区分地执行，A 上被旧 P2 判 attack 的良性样本
（已知 4,986 条 P2-hard/M7-normal 冲突良性即属此类）
会被蒸馏进新系统——等于把 76.3% hydraulic 误报作为训练目标继承下来。
这与提案自列的验收问题「hydraulic 是否有任何改善」直接矛盾。

裁定：

- 判决约束必须改写为 label-aware：
  **真攻击**的 hard 判决受保护（margin/tail 约束施加于此）；
  **真良性**的 hard 判决明确允许软化，且这正是 B 侧及 A 侧良性的改进来源。
- 合法标签范围：fit 池（4,385 fit 攻击 + fit 良性）可用于训练约束；
  select 数据全程不碰；viewed report 51,057 攻击维持 kill-only 零翻转哨兵。
- 「不能再做普通分数回归式蒸馏」的判断背书：
  纯分数拟合会把教师的错误一并拟合，tail/margin + label-aware hard 保护是必要修正。

## 3. M3：768D 坐标对齐约束过强，应降级为一个臂而非前提

提案约束 1 要求新 embedding 映射到旧 P2 可消费的 768D 坐标。

风险：CKDE-S Lane G 已判 netFound 表征几何
G1/UNSTABLE_OR_TEMPORAL_DEVICE_SUBSPACE（LODO worst distance 0.5757、angle 89.36°）。
强制坐标克隆会把已被证伪的几何结构作为先验注入新编码器。

裁定：

- 「与冻结 P2 输入接口兼容」（768D embedding + 第 769 维，经旧 normalizer）是硬要求；
- 「坐标系对齐/克隆」降级为一个可选臂；
- 允许一个已声明、参数计入编码器的轻量适配层（如线性 adapter），
  冻结 P2 本体不允许有任何参数变动；
- 若坐标对齐臂与功能约束（分数排序复现）冲突，以功能约束为准。

## 4. M4：hydraulic 必须从本路线验收标准中移除

hydraulic 误报目标 old_missing=false，在扩展部署下继续走旧路径，
本路线按构造对其零影响。「hydraulic 是否有任何改善」
不能列为第一阶段验收问题，否则会把一个按构造为否的问题写成期待。

hydraulic 表征质量线仍是独立主战场，需另行协议讨论
（CKDC 融合已封死，不得复用其规则）。

## 5. M5：B 攻击安全评估受 29 上下文独立性贫困约束，声明上限预冻结

B 侧攻击仅 162 行、29 个独立上下文、5 个家族。
即使训练合法性不再受此门限制（见 §0），**评估能力**仍受其限制：

- 「B 攻击不出现不可接受损失」只能作为有限证据声明；
- 必须逐家族、逐设备、worst-case 报告，禁止平均数遮蔽；
- 禁止逐族调参；162 行只作安全哨兵；
- 声明上限建议预冻结为：
  attack-information retention on the encodable blind-spot subset,
  with at most 29 independent attack contexts across 5 families。

## 6. M6：第二阶段新头的决策规则必须预冻结

「表示变好但旧 P2 用不了才训练新头」是结果驱动分支，必须预先写成机械规则：

- 定义「旧 P2 用不了」的量化判据（如 A fit 攻击 margin 复现失败的具体门槛）；
- 新头只允许一次训练尝试，受同样的 label-aware 攻击 margin 约束；
- viewed 51,057 攻击零翻转 kill-only 门对两个阶段均生效；
- 不允许第三个模型、逐族补丁、反复调参——背书提案此条。

## 7. M7：草案前需要 count-only D0 训练池普查

正式草案前，先做纯计数审计（不开分数、不开 PCAP、不训练）：

- H1-H4 上下文在 A/B、fit/select、benign/attack 上的分布；
- 跨界上下文排除规则的复用（CE learned branch M1 已排除 19 个跨界上下文，
  本路线应继承同一排除清单，保证可对比）；
- B 良性 fit 上下文的设备/协议覆盖；
- 本地训练资源预算与断点恢复方案的数值上限。

窄调研清单（H1-H4 序列参数、causal Transformer/GRU 兼容性、tail-aware
蒸馏损失、本地耗时）背书，限定为机械兼容性调研，禁止重新逛模型动物园。

## 8. 背书项

- 保留 H1-H4（ZT 已证 25,467 全 semantic-finite，层级分布 H1 13,953 /
  H2 1,909 / H3 9,579 / H4 26）——正确，语义层不重做。
- 旧系统全程在役、新系统 shadow、失败旧系统一个字节不变——正确。
- 晋升条件含 worst-device/worst-family 反平均数遮蔽——正确。
- 不找新数据集、Data-F0b 继续封存——正确；外部语料改变不了
  冻结 25,467 宇宙的上下文分母。
