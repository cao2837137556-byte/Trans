## 1. D1_LOCATION_CAP_V1

### 1.1 资产、资格与去重

使用已验收的新缓存和本次完成的QUERY_TAIL，seed固定27/127/227。各参考在自身时间点生成的768维E3＋14维q14，用同一源归一化器及对应冻结头评分；不能用原始794维直接代替782维模型输入。参考分数若未保存，只补冻结头前向。

OLD_BANK/B0/B1/B2分别评价；目标参考只能取本设备、同协议TCP/UDP的原封存库，不引入阶段分组、其他目标设备参考或新窗口。沿用整个库的截止时间和同捕获帧序检查。较早查询、窗口内重放端点保留原判与完整分母。允许截止后同组件延续，但必须单独报告continuation与distinct-component查询；不得将其解释为独立泛化。

一个库每个封存component_id只允许一个已选代表。物理身份用(source_sha256, frame, owner)核对，重复或UID冲突按数据异常停止，不在看到分数后换代表。各策略之间的重复参考不重复计数为新材料；不因参考与历史查询重叠删除查询，沿用v3身份/时间回退。

### 1.2 位置估计、权重、可估计性

设合格库R有n个不同组件，n≥8；每组件权重1/n，ESS=(Σw)^2/Σw²=n。无行级重复加权，不用目标评价权重决定参考统计。min8是本轮预先固定的估计下限，不代表8个统计独立样本或可靠尾部估计。

逐seed j计算m[R,j]=Q50({s[r,j]},组件等权)。所有分位数统一采用“累计归一化权重首次≥分位点的最小观测值”，按分数、component_id排序；偶数样本取该规则给出的下中位数，不对两个中心值插值。

MAD只作描述：Q50(|s[r,j]−m[R,j]|)，不用于除法、模型阈值或分支选择。因此MAD=0不会导致除零，也不需要再选择尺度下限。首轮不实现z=(s−m)/MAD；该变体若需要，应另立后续版本。

### 1.3 源位置锚点

使用原104条专用SOURCE_REFS，不挪用FIT/CAL查询充当参考。对协议p、当前被模拟/部署设备d，定义A[p,d]为SOURCE_REFS中同协议、排除设备d后的不同组件集合；不少于8组件时计算a[p,d,j]=Q50({源参考分数},组件等权)。

源CAL中模拟设备d的参考库时，也按此函数排除该设备；目标设备不属于源设备名单时，自然使用该协议全部源参考。设备身份只用于排除自参考和查本设备库，不作为网络输入。跨设备的源锚点是离线源参数，目标入网库仍不借用其他目标设备的数据。

该规则避免把一个源库的中位数直接与自身相减造成保护空转。它也不声称源锚点跨设备稳定；源材料分布和实际修正必须报告。

已只读核对源参考组件：TCP总23，UDP总81；≥8的源本设备库仅ArloQ-TCP8、SimCam-TCP8、Amcrest-UDP63。对应排除本设备后的源锚点分别有15/15/18组件。组件计数可支撑这一首轮规格，但源设备覆盖很有限；这些统计不是新模型效果。

### 1.4 唯一修正规则、原阈值与集成

复用已封存的源FIT分数尺度S[j]=Q90−Q10，按原训练权重正常/攻击各0.5计算。三个值为118.95627975463867、121.3746566772461、122.36117172241211；执行时按输入SHA绑定，不能仅从本文手抄替代。这里仅复用机械尺度，不用FIT误报改善选择规则或声称泛化性能。

对满足时间/协议/n/源锚点条件的查询q，逐seed：

```text
raw_shift[R,j] = max(0, m[R,j] - a[p,d,j])
delta[R,j] = min(raw_shift[R,j], lambda * S[j])
s_new[q,j] = s_old[q,j] - delta[R,j]
alarm_new[q,j] = (s_new[q,j] > original_cut[j])
```

所有计算转为float64；delta=0时精确返回原score，不改变浮点计算路径。对不合格行直接返回原score。仅减分，不新增原头没有的告警；有效原分数阈值落在[original_cut, original_cut+lambda*S]内。

固定集成按原seed顺序，对三个**修正后logit**采用原stack/float64 mean算术，与原ensemble_cut比较；不另拟合ensemble参考中位数，不改成投票或概率均值。原seed阈值与原集成阈值全部复用，**不重新在目标或参考中估1%尾部阈值**。本规则等价于有界位置校准，不是新的MAD标准化分数。

### 1.5 lambda标定：固定算法，不做效果选型

候选固定为{0,0.05,0.10,0.25}，一个lambda用于该头全部可标定协议、目标池和四种参考策略。CAL只用于原阈值回放及攻击封顶，正常CAL不用于比较规则形式或选择lambda。

源保护采用**全额封顶压力检查**：对每个协议，取原CAL攻击中至少有一个同协议、n≥8、时间合法的源供体库的查询。对每个候选，把这些查询每个seed的分数减去完整lambda*S[j]，而不是只减当时源库估出的较小raw_shift；随后按原seed/ensemble判定检查整数新增漏检全部为0。选择通过检查的最大候选，不按正常FPR选。由于实际delta不超过此上限，这比仅检查源库实际位置偏移更保守，可避免raw_shift=0造成“什么也没改却宣布保护有效”。

这里的源供体属于附加保守压力检查，允许与CAL查询不同设备，不要求几何正支持。必须同协议、供体≥8组件、供体自身被排除后的源锚点≥8组件、完整供体库截止严格早于查询，同捕获时参考帧也严格早于查询；源CAL查询与源参考组件仍须互斥。压力检查覆盖和真实同设备位置修正覆盖分别记录，不能混称。

逐协议要求存在合法源攻击配对，且每个seed与集成至少有一个原本检出的攻击可接受压力检查；不满足时，该协议在D1固定回退原判并报告NO_SOURCE_PROTECTION_EVIDENCE。若其他协议存在证据，lambda在这些协议的联合压力检查上选择；若全部缺失则lambda=0。若只有0通过，记录CAL_CAP_ZERO和零操作，不搜索新候选或放宽漏检容差。

同时保存每个候选的压力撤警UID/计数、原margin、合法供体覆盖，以及最终真实位置修正的源/目标改判。压力检查使用合格同协议源供体作额外校准检查，不意味着目标运行允许跨设备借参考。

这仍是在已使用的源CAL上标定参数，**不是新的独立源验证**；即使源压力检查通过，也不能保证目标安全。若未来比较多个规则，应另行设计源内拆分；仅给已有全CAL阈值加一层交叉拟合，并不能自动让整条流水线独立。

### 1.6 回退、状态与边界

| 情况 | 执行行为 | 报告状态 |
| --- | --- | --- |
| 无同设备同协议参考、参考未生效、n<8、源锚点<8、源保护证据不足 | 原score及判定不变；查询计入完整分母 | 对应原因码；该组校准不可估计/不可标定 |
| raw_shift≤0、lambda=0或S=0 | 精确原判 | NO_SHIFT/CAL_CAP_ZERO/ZERO_SCALE |
| 非有限值、身份错误、原score或阈值回放不一致 | 停止该诊断并保留现场 | ENGINEERING_ERROR，不算科学负结果 |
| 规则可执行但目标新增漏检或目标FPR未达标 | 保留真实输出，不自动调参 | 科学FAIL及具体原因 |
| 事后发现参考与正常查询分布不一致 | 保留完整结果和全部设备 | REPRESENTATIVENESS_LIMITED解释，不改成整体NOT_EVALUABLE |

不做device×protocol不足时借其他目标设备的protocol/global统计；这里“global回退”只指原基础头。先天材料不足与已执行规则失败必须分开。即使所有组都回退，整体头指标仍可计算；模块收益未得到检验，不能称模块成功。

位置校准与当前几何模块并列，各自相对同一头比较，不串联。逐seed/ensemble、两池四库报告加权/逐条FPR、召回、FP/FN、资格、实际修正和新增漏检。原验收门槛不改。

原5.64014%/7.35325%资格残留，仅适用于当前QUERY_TAIL+B2查询资格外保持原判的场景；本D1的min8资格更严格，原数字只能作为较宽松的下界，必须另算D1自身资格残留。它不约束全局改阈值或新检测头；原几何“正支持不变”边界不适用于本D1。

### 1.7 目标参考代表性：只解释，不筛设备

在完整评价后，同设备/协议比较参考与严格晚于整库截止的DEV正常查询分数Q50/Q90及MAD。查询使用原正常评价权重在该组内归一化，参考组件等权；两种抽样机制不同，报告其差异，不伪装成同分布检验。

逐条查询和按既有组件聚合的描述均保留；历史相同物理端点不得作为独立“后续样本”。缺后续正常或样本不足只使该代表性描述不可估计。**不能因目标查询显示不一致而改变已定方法、删除设备、缩小主分母或将已有科学FAIL重标为NOT_EVALUABLE。**

结束产物：资产/资格表、源位置与封顶回执、四库配对结果、代表性描述；每项只执行登记的规则一次。本轮失败只说明这一条规则在当前材料和资格下的结果，不是校准方法族能力上限。

## 2. D2_DOMAIN_LINEAR_V1

### 2.1 问题与两种材料

域标签y_domain=0表示源正常，1表示目标正常；它不是攻击标签。A/B分别分析。

- 主描述：源FIT正常与目标可信正常参考。目标参考取四个已封存库的并集，物理端点去重后每个component_id按固定hash取一个代表。该并集仅定义诊断材料，不成为新的部署参考库，也不被D1使用。
- 次描述：源FIT正常与目标DEV正常查询。明确使用了目标DEV正常标签来筛正常，只供诊断，不进入攻击头、D1拟合或规则选型。每component_id固定hash取一个代表，避免长流重复包主导。

两种材料分别拟合/报告，不把参考和查询混为一个目标池。协议限定为源与目标都有样本的TCP/UDP，其他协议计数单列。源FIT对原攻击头并非留出数据；D2留出只相对于探针训练，不能称全链路独立确认。

### 2.2 双域分组切分：修正单类方案

不能仅在源正常训练域逻辑回归、再仅在目标正常计算AUC：训练只有标签0，验证只有标签1，二分类训练和域AUC均不成立。源单类密度模型是另一种诊断，本轮不引入。

正确过程是：**源与目标各自先分训练组和留出组；两域训练组合并训练探针；两域留出组合并计算AUC。** 这明确使用了目标正常材料及其域身份训练诊断器，不是源训练攻击检测器的目标迁移测试。

固定依赖组按以下元数据关系求连通分量：相同物理端点、相同component_id、同一source_sha256捕获内的固定10分钟时间块属于同组；时间块以该捕获首个可核对时间戳为起点。跨块的同组件连通关系必须先合并再抽样。若捕获起点缺失，保守地用整捕获作为块，不临时改块长。

因此共享组件不跨折，同一时间块不跨折；不同时间块可能来自同一捕获。本轮不声称捕获级或设备级完全未见泛化，也不为满足折数拆开巨大连通组。若源/目标出现相同物理资产或组件导致域身份冲突，停止查身份，而不是保留两份相反域标签。

固定3折，按每域group_id的SHA256固定顺序轮转分配0/1/2折；同一材料/池的三个特征视图使用相同划分。每域至少6个依赖组；每个验证折每域至少10组件、至少2依赖组，训练折每域至少20组件。不满足时该材料/池记NOT_EVALUABLE，不减少组约束、改行随机切分或重复试随机种子。

本轮不另加设备留出训练矩阵。报告每折设备/捕获重叠，并明确其外推限制；以后如研究未见设备，应另立相应划分。

### 2.3 抽样、探针与权重

固定随机种子27、固定hash盐`d2-domain-linear-v1-20261022`。每域最多10,000个组件代表；按设备×协议分层，层内按依赖组轮转、组内按component_id哈希选取，按同一固定词典顺序补足名额。抽样不读模型分数或攻击标签。先完整建立依赖关系，再选代表，不能先丢行导致原相连组件被拆开。使用mmap读取所需特征。

探针固定为L2逻辑回归：C=1、solver=lbfgs、fit_intercept=true、max_iter=1000、tol=1e-4、class_weight=None，不选C、不加小MLP。输入分别为原768维E3、14维q14及782维拼接；禁止UID、设备名、捕获ID或域标签作为特征。原源变换沿用，随后每折仅用训练折拟合逐列均值/标准差；零方差列的标准差设1。不用留出折拟合缩放。

训练样本权重使两域各占1/2，各域内非空device×protocol层等质量、层内组件代表等权，再缩放至训练样本权重均值1。验证AUC采用相同层级的归一化权重并同时报告无权AUC，不能把新探针权重替换成原攻击评价权重。fold内缺一类直接不可评价。

不收敛记录PROBE_NOT_CONVERGED，不根据AUC换solver或加迭代追结果；实现错误可另版本修复，不能把技术失败当作无域差异。

### 2.4 指标、混杂与解释

主报各折AUC及三折等权均值。不同折模型的分数不直接合并成一个全局AUC；同协议和原固定包阶段的附表只在对应折两域各至少10组件且各2组时计算，使用同一个已训练探针，不为每个子组重训。

不做逐行bootstrap。每域≥20依赖组时，按域/折分层整组有放回重采样500次（seed27），在固定留出预测上给均值AUC的2.5%/97.5%百分位区间；少于20组只报折间范围和组数，不制造窄区间。此区间仅条件于当前模型、设备和采集，未包含训练不确定性，不是未见设备总体置信保证。

| 观察 | 允许解释 | 不允许推出 |
| --- | --- | --- |
| 分组留出AUC较高 | 固定线性探针能利用两组正常材料的差异；进一步看协议/设备/采集组成 | 换头无效、前端必须重做 |
| q14视图可分 | 当前包描述与域身份有关，可能含协议/阶段组成差异 | 攻击头必然使用了有害捷径 |
| E3视图可分 | 冻结表示包含可区分当前两组材料的信息 | 攻击信息不够、无法学习稳定边界 |
| AUC接近0.5或折间不稳定 | 该探针和该划分未检出稳定线性可分性 | 域差异不存在、校准一定可行 |
| 组数不足/验证单类 | 当前材料无法支持该诊断 | 两域相同或某模型失败 |

不设置AUC>0.8的开关。次描述读取了DEV正常/攻击标签以筛选正常，不能声称完全未接触目标标签；攻击样本和攻击类别标签不进入探针训练、调参或域差异归因。源/目标的设备、协议、活动和采集流程相互混杂，不能凭AUC唯一归因。D2不取消现代头候选、不批准D1、不触发自动前端重建。

结束产物：两类材料×两个目标池×三个视图的一轮固定3折报告（最多36次小型探针拟合），包含不可评价项，不扩展搜索；不重训前端或攻击头。
