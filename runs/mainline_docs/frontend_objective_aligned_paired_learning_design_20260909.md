# 回到项目目标：统一模型学习能力的双臂对照草案

日期：2026-09-09。
状态：ROUTE_DECISION_AND_DESIGN_DRAFT；不是冻结执行协议，不启动真实训练。
本轮范围：用户要求独立判断下一步。已阅读现有公开开发记录、N0 覆盖汇总、源代码片段与公开论文。
没有读取新模型张量、计算新预测、重新拟合、重放 PCAP、访问封闭角色或启动 HPC。

## 决定

下一项研究推荐：建立新前端下的普通监督学习基线，用一次预先定义的
“A 目标监督 / A+B 目标监督”对照回答：新系统学到多少旧攻击能力，加入 B 监督后发生什么。
先完成该实验的训练/检查名单资格与训练配方冻结，再实现并申请对应的真实执行范围。
不把五条零错当作设计下一实验的前提；不把全部数据喂完后的拟合准确率当作系统能力。

这是对 F5/N3 后续路线的主动调整：保留能复用的输入工程和模型实现，暂停继续增加
已知失败样本的最后层约束。也不默认完整 GRU 训练或更大模型必然成功。

## 为什么选择这项对照

| 已有证据 | 能支持的判断 | 不能支持的判断 |
|---|---|---|
| F4 所选字段的输入审计 PASS | 复用输入实现和身份审计 | 所有旧教师信息和预训练知识都已保留 |
| F5 训练 8,660 条；合法开发池 18,266 条 | 最初训练覆盖并不等于完整合法开发覆盖 | 所有 18,266 条可同时充当训练和独立测试 |
| ToN 训练有 2,000 条暴力破解、零 ToN 正常；开发池另有 4,000 条 ToN 正常与 2,000 条扫描 | 存在确定的行为/来源覆盖缺口 | 覆盖缺口是所有错误的唯一原因 |
| N3 在固定表示上满足 12,711 条拟合约束 | 已知有限集合可以联合修复；尚无依据断言必须换前端 | 对新样本、完整旧能力或任意流量都可泛化 |
| N3 原开发 B 正常仍错 853/3,720；外层 B 正常 1,224/1,224 正确 | 不同开发范围表现不同，B 能力也需完整报告 | 系统除了最新五条之外已无问题 |
| 外层旧可检出攻击 1,995/2,000；四条与历史 F1 错误重合 | 当前固定候选不满足该池零回退门槛 | 原因已查明，或整个 GRU 模型家族不可能成功 |

原实验同时改变了信息、历史和预训练来源，并包含训练中没有同名攻击类型的验证要求。
这些是有意义的困难测试，但不能把它们全部解释为“已教过的攻击又忘了”。
历史五条训练错误确有更新后丢失的证据；这也不能推广为其他来源错误的共同原因。

优先级理由：继续最后层补约束主要增加拟合证据；盲目全量训练没有清楚的比较对象；
立刻换架构同时引入更多变量。两臂普通学习对照能用最少的新候选直接检查项目的两项核心目标。
它不负责唯一识别表示、优化或知识缺失的因果机制，但能明确下一轮该检查哪一部分。

## 推荐对照及保持一致的条件

| 对照对象 | 训练用途 | 回答的问题 |
|---|---|---|
| 旧系统固定参考 | 不重新训练；只在身份、旧输入和用途合格的 A 检查目标上作配对参考 | 这些攻击和正常流量原来怎样判断 |
| 新模型 A 监督臂 | 新前端 + 全部可训练 GRU/分类头，使用新协议训练名单内的 A 标签 | 新系统在合理覆盖下能否学到原任务 |
| 新模型 A+B 监督臂 | 与 A 臂同结构、同初始化，额外使用训练名单内的 B 标签 | 加入 B 后，A 是否退化，B 是否改善 |

两臂均从未训练的共同初始化出发。不能从已有 F5/N3 权重启动“无 B 对照”，
因为其编码器和头已存在 B 及开发数据学习暴露。N3 保存为历史研究候选。

首个对照推荐复用 F4 输入和现有 GRU/分类头结构，训练整个模型，不只拟合 65 参数最后层。
这是一项控制变量选择，依据是现有有限集合可学习证据和工程可复用性，不是最终架构承诺。
新协议基线先采用真实标签的普通监督二分类损失，不加入旧分数强度拟合、辅助预测或 LP 修补。
这样先回答新系统的普通学习能力；不把该结果描述成“蒸馏本身有效”。
旧 P2 不接到新表示后部署，旧系统比较和新模型分类分开。

两臂共享 A 训练名单、A 输入、初始权重、A 呈现次序/次数、优化更新数和检查名单。
A 损失权重不能因为加入 B 被新的总样本数悄悄稀释。推荐损失形态为
L_A 与 L_A + lambda_B * L_B，各自按完整训练上下文归一；lambda_B、调度、预算和
终点候选规则在任何训练前一次固定，不靠试跑挑选。这里只给方法形态，不伪称数值协议已冻结。
不得沿用原 F5 中“缺 B 必失败”的四组验收规则来实现 A 臂。

这里严格比较的是 B 目标监督的增量。A 的必需因果前缀若含 B 事件，应在两臂共同保留并披露，
不能改变 A 输入来制造纯净对照，也不能把 A 监督臂声称为“从未接触任何 B 字节”。
A 臂不额外使用 B 专属样本、B 标签或 B 辅助学习。完整无 B 暴露是否可行需由名单审计判断。

## 数据划分是本方案的具体未完成项

现有 N0 已完成合法池盘点，不重跑 N0 或 F4。使用已封存的 18,266 条池与其元数据，
拟定一个新版本的开发学习/检查视图；原 F5 分区、失败结论、132 条排除记录及封闭角色保持原义。
旧协议下的验证角色不能在原实验里改名；如新协议重新分配已暴露开发记录，必须明确记录新用途并取得相应执行授权。

划分要求：

1. 输出完整目标名单、训练/检查角色、A/B、正常/具体攻击、来源、会话或其他已核实依赖组。
   使用覆盖和依赖信息确定名单，不按当前五条错误或 logits 选择训练样本。
2. 将“有相应训练覆盖的行为检查”和“训练未覆盖的行为迁移”分别报告。
   两者不互相替代；单一上下文的罕见类型不能拆成行后制造训练/检查独立性。
3. 优先保留完整会话/依赖组，并考虑时间顺序与前缀共享。不能仅凭不同 semantic_context_key
   宣布旧会话独立；不能从现有 N0 表中臆造未提供的时间或会话桥。
4. 单一来源的扫描或正常数据即使能按合法依赖组留出，也最多支持来源内开发检查。
   所有 18,266 条均已暴露；新初始化可以建立候选自身的拟合排除，不能抹去人和历史模型的选择暴露。
5. 数据源与标签的混杂单独披露：正常和攻击都来自 ToN 不代表它们来自同一捕获环境；
   只补各一份文件不证明来源捷径已消失。无法构成可靠对照的类别标为证据不足。
6. 保留 69 select 攻击及 select/viewed/report/FINAL 的封闭用途；不为补齐覆盖擅自打开或移入它们。

当前尚无已确认的同类行为、拟合排除且依赖清楚的独立确认池。本方案不承诺现有数据必然足够。
如果现有元数据不能完成上述必要划分，先交付精确缺失字段/目标范围及最小取证提案，
不自动解封、下载新数据或用随机按行划分冒充解决。这是训练前的解释性门槛，不是五条零错门槛。

## 一次实验的结果表与终止分支

每个固定候选只在预声明规则下产生结果。训练内检查与未参与该候选拟合的开发检查分开。
按 A/B、正常/具体攻击类型、来源、目标/上下文同时报告，列出分母与覆盖缺口。
同批 A 上列旧正确变错、旧错误变对、攻击检出和正常误报；B 同时报正常误报与攻击检出。
稀少 B 攻击或缺失类型不能从 B 正常释放量推断攻击能力。

| 结果 | 下一研究判断 |
|---|---|
| A 臂在有训练覆盖的检查任务上仍不能保持旧能力 | 先解决新学习路线本身；停止继续扩大 B，用误差结构设计表示/知识迁移或优化的定向对照，不直接宣布前端无解 |
| A 臂达到预声明目标，A+B 臂在同批 A 上退化 | 加入 B 监督在此固定配方下造成兼容性代价；再研究保护旧正确判别的学习方法，不靠抬高总准确率掩盖它 |
| 两臂 A 都保持，A+B 的 B 检查改善 | 得到此开发范围内的能力保持与 B 监督增量证据；先完成约定的两项目标证据，再另议设备入网 |
| 两臂 A 都保持，但 B 不改善或更差 | B 监督尚无新增收益，调查 B 学习问题；不宣布项目第二项成功 |
| 数据依赖不清、运行失效或资源界限不足 | 无相应科学归因；保留证据，停止该尝试，不追加种子/候选寻找成功 |

新对照要同时报告实际性能和逐目标回退。科学成功门槛必须预声明；本轮不设新容忍度，
不将历史五条失败事后改判 PASS，也不声称普通监督损失保证零回退。
一个固定配方的失败不等于 GRU 能力上限；通过也不等于未见攻击、新来源或新设备已解决。
