   These recorded families cannot be treated as the same inherited behavior

   metadata supplies lawful source/member/context coverage, not a validated

   A teacher field/history intervention cannot yet be executed from this scope.

These findings do not isolate how much of F5 failure comes from coverage,

## Concrete next design

Proceed next to a bounded **finite-training-set joint-decision feasibility design**,
using the existing legal F4 training scope and sealed terminal artifacts as
the reference evidence. The preferred question is whether the existing final
`Linear(64,1)` can satisfy all predefined protected training decisions while
the event projection, GRU, head_hidden and their activations remain fixed at
the sealed terminal state. The current source defines these layers at
`repo/ood/issue27frontend_f5_unified_student_v1.py:100`; inspecting that source
after N0 did not load the state or run a model.

The next design should specify one deterministic constrained feasibility solve
and full-set float32 verification, with exact margins, parameter bounds, solver
tolerances, identities and finite resource limits. This is parameter fitting,
even if a solver performs no optimizer steps: it needs a separate complete
protocol and authorization. It is not an executable zero-training extension
of N0 and does not authorize a change to the sealed terminal model.

A feasible solution would be a constructive witness conditional on the fixed
terminal features and finite protection set. Infeasibility would apply only to
that last-layer problem and its declared bounds/tolerances; a solver timeout
would establish neither feasibility nor infeasibility. None of these outcomes
proves global GRU capacity, holdout inheritance or retention under later updates.
This narrow question can be designed without first resolving old raw-field or
session-history joins.

The design must protect the complete predefined reference set jointly:
2,179 A attacks + 4,667 protected A benign + 68 B attacks = 6,914 targets,
with all other 1,746 A/B training rows still accounted for. It must specify an
initially feasible state or a bounded restoration/bootstrap procedure, checking
cost, and a decisive stop if no joint candidate is found. A rule targeting only
five failures, or local terminal gradient conflict by itself, is insufficient.
No new architecture, loss, optimizer or executable protocol is selected here.
The complete intervention and acceptance rules belong in the next design.

Keep ToN coverage and holdout generalization as a separate evidence account.
Using normal_1 for later learning would require a new protocol and explicit
authorization for exposed-development reallocation. Re-splitting it cannot
create an untouched or independently verified holdout. Finite-set fitting
success alone will not solve the full inheritance/generalization objective.
