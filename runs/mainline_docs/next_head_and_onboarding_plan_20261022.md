## 建议结论

进入一次有边界的现代检测头比较，并完成每个预定候选接入同一入网模块后的配对评价。当前方案先降到 FPR≤1% 不应成为换头前提；换头本身就是检验能否降低误报的一条路径。最终比较完整系统，同时保留头单独结果来区分贡献。

同时做一次限定范围的旧/新入网结果复盘，输出明确的误报处理路径表；优先加入下述两个小诊断，不把彻底解释所有历史差异、域AUC达到某值或当前模块调到达标作为前置条件。暂不同时改变前端、参考规则和检测头，以免无法判断收益来源。

## 新增前置诊断：只检验两个问题，不新增大规模实验分支

1. **参考分数校准。** 固定组件等权中位数位置修正，min8、MAD仅描述，源锚点排除当前模拟源设备，原cut不变；修正幅度由固定候选的源CAL攻击全额封顶压力检查确定。与当前几何修正并列，保留完整分母、时间回退及逐seed/ensemble零新增漏检检查。参考代表性事后描述不得反馈到规则、删设备或重标已执行的负结果。一次规则失败不是方法族上限；资格外原判时仍有相应资格残留约束。
2. **正常域可分性。** 固定L2线性探针、E3/q14/拼接、A/B分别、两类材料分别。源和目标各自按组件/捕获时间块依赖组划分后，两域训练组合并训练、两域留出组合并计算AUC，禁止仅源训练/仅目标验证的单类配置。3折、每域至多10,000组件代表，材料不足按登记记NOT_EVALUABLE。源/目标域标签参与诊断训练，DEV正常标签用途明确；不重训前端或攻击头。高AUC不证明换头无效，低AUC不证明无域偏移，不能据0.8重做前端。

两项均只做一轮固定规格报告，组数/统计量不足明确NOT_EVALUABLE；现代头适配可同时准备，预定候选不按域AUC筛掉。暂不加入阶段阈值、滚动参考或学习修正的额外组合，换头后的分支依据两个诊断和完整系统比较共同决定。

## 依据与不能推出的结论

1. 同缓存 RECENT 与 QUERY_TAIL 的 B 加权 FPR 为21.28324%和23.65666%，A为5.76093%和6.15818%。修复头没有取得正常侧改善，不能因其名称或实现投入而优先保留为最终模型。
2. 当前 QUERY_TAIL+B2 在B的加权FPR为16.59348%，相对头单独下降29.86%，32个配对输出零新增漏检。说明入网有实测作用，但未解决主要误报问题。
3. 旧两设备 A 的学习参考模块确曾将加权FPR从2.769602%降至0.317174%、误报374→30、无新增攻击漏检。该结果不被新版失败推翻；它也不证明旧输入/旧学习模块可直接安全迁移到当前路径和B。
4. 当前完整查询、当前头与 B2 的资格不变时，令H为原头加权FPR、s为原误报的加权资格份额，则完美消除资格内全部误报的乐观残留为H×(1−s)。A为5.64014%，B为7.35325%。若进一步保持当前支持度不变，仅调修正强度，按原误报正支持份额得到更紧的残留：A6.12924%、B11.09160%。这些是假定不损失攻击的事后乐观边界，不是实测新结果、验收门槛或新头下界；不能据此宣布入网思想整体无效。
5. 现有分数的事后诊断已显示，单一全局阈值不能同时让B加权FPR≤1%和攻击召回≥99%。换头可以改变特征组合和样本排序，因此值得检验；它无法保证弥补现有输入缺失的信息或源训练中没有覆盖的行为。

上述第4项由 `onboarding_new_lineage_v1_20261022/analysis/RESULT_SUMMARY_v3.json` 的 ensemble/head/normal 与 coverage/head_false_positives 计算，资格和正支持采用与FPR一致的正常评价权重。不得用按条数覆盖代入该加权边界。

## 第一步：一次已有结果复盘，产出后结束诊断阶段

只用已有本地报告、UID、参考元数据及保存的修正轨迹，不重训、不重提百万行E3。交付一张按池/设备/协议分组的误报路径表：

- 参考尚未生效：查询早于库截止，必须原头回退。
- 参考不合格：协议或不同组件数量不足，必须回退。
- 参考合格但支持为零：由E3/q14联合距离条件排除。
- 获得支持但修正不足以越过固定阈值，以及实际成功修正的误报。

对旧两设备A曾修正的344条误报，在UID及物理端点可核对时检查当前头/模块的处理路径；无法对齐的行明确记录。旧/新输入、检测头、参考身份和修正方法同时改变的事实必须保留，路径核对不等于已经隔离各改变的因果贡献。

输出要回答“当前问题主要在无合法参考、支持计算，还是分类分数”，不展开临时扩大窗口/改半径/调lambda的效果搜索。该复盘可与新谱系工程适配并行，完成后不反复追加诊断阻塞比较。

## 第二步：固定缓存，做一轮有上限的检测头比较

沿用已有现代头 v1r1 配方，输入均为同一768维近期E3＋14维当前包描述；冻结前端和源FIT/CAL、查询集合、权重含义。比较 MLP_QUERY_BCE、TabM、LightGBM，seeds27/127/227；保留已完成RECENT/QUERY_TAIL为解释锚点。

MLP_QUERY_BCE 与 TabM/LightGBM 采用可比较的普通加权二分类目标。QUERY_TAIL含额外TAIL目标，不能仅凭其与TabM差异将收益全归于网络架构。各家仍采用预登记的优化配方，因此结论是“检测头及固定训练配方替换”的作用，不是所有配置充分调优后的模型家族排名。

MLP仅在新缓存身份、训练配方、权重、环境及实际分数/决定回放满足原复用条件时复用；否则重训共同基线。最多九个终点，复用成立时新增六个。不因看到A/B结果临时换seed、选择中间轮次或扩大调参。

工程前置仅包括：新增本次重建谱系适配；复用原冻结包；接入入网v3时间/身份检查；目标依赖与真实小样验证。现有旧包不能直接改pin假装兼容。完整查询缓存和六个参考库可作为已封存输入复用，正常情况下无需重做前端解码/E3。资源先沿现有8CPU/16GiB单重阶段预算、小样实测；不把72h作业上限或过去37分钟当成预计耗时。

## 第四步：依据这一轮证据决定结构分支

所有模型报告A/B完整加权FPR、逐条FP/FN、攻击召回、设备最差情况、各seed及固定集成、资源成本。模块对每个自己的基础头检验零新增漏检；换头本身沿既定攻击保护和分组回归门槛评价，不擅自新增跨头逐UID零新增漏检硬门槛。A旧低误报作为重要历史比较，原完整系统1%/逐设备2%等验收标准不临时修改。

| 观察 | 后续决策 |
| --- | --- |
| 新头及其完整方案在两池改善，攻击保护通过 | 保留为候选，补新输入三设备回归与最终未消费独立确认；两池开发通过不等于论文最终确认 |
| D1固定规则源保护通过，目标资格内误报改善且零新增漏检 | 支持进一步研究该校准规则；完整系统是否达标仍按全查询指标判断，不能仅报资格内子集 |
| 新头改善，但多数残余误报缺合法参考 | 优先解决正常行为覆盖/可用时序；现有材料确实不足时登记补采需求，不能靠加大修正或复制单组件解决 |
| 残余误报有合法参考，但固定相似度无法安全识别 | 另立小规模“固定相似度 vs 可学习参考判别”方案，借鉴旧A正向机制，在新输入上重新设计源侧训练与攻击保护 |
| 多种头在相同输入下仍无明显联合改善 | 停止继续堆检测头；回到源训练覆盖、分布偏移与表示/汇总方式，先提出可验证假设再决定是否重提特征 |
| FPR降低伴随不可接受的攻击退化 | 保留负结果，不以低FPR选为最终方案，不通过目标阈值调整或删困难样本补成通过 |

即使所有首轮配方失败，也只否定本轮固定配方的效果，不能据此唯一归因于前端失效。学习参考模块不能凭空补足时间上不存在的参考；旧模块在B有过攻击撤警问题，因此不直接把旧校验器权重接入新表示或照搬旧阈值。

## 范围和结束条件
