## 4. 唯一固定配方

设每个设备与标签格中共有 F 个捕获，当前捕获有 S 个候选 streams，当前 stream 保留 K 个目标。条件权重 `q_i=1/(F*S*K)`，每个格内总和为 1。

`L_old = 0.5*mean_old_benign(BCE) + 0.5*mean_old_attack(BCE)`

`L_new = 0.25 * sum_(device,label) sum_i q_i*BCE_i`

`L_rank = 0.5 * sum_device sum_(attack a,normal b) q_a*q_b*softplus(-(logit_a-logit_b))`

`L_B = 0.8*L_old + 0.2*L_new`

`L_C = 0.8*L_old + 0.2*L_new + 0.05*L_rank`

TRAIN 的 29,304 个设备内正负目标组合可以精确计算，复用 570 行已有 logits，不增加前向曝光。设备、类别、捕获、stream 与目标层级权重全部在 B/C 中一致；B 同样计算排序诊断，训练系数为 0。不能把重采样收益冒称排序机制收益。重复或相同特征的目标保留既定权重，不在见分数后删重。

两个副本各自：seed **27**；新建 AdamW（lr **3e-4**，betas 0.9/0.999，eps 1e-8，weight_decay **1e-4**）；**200 次全量梯度更新**；microbatch **256**；全量梯度合并后 clip global norm **1.0**；无 scheduler、AMP、早停或最佳轮次选择。encoder/normalizer 固定，P2 全部参数训练。相较原 P2 的 50 epochs、批内更新、lr 1e-3，这是独立的有限继续学习配方，不冒称重跑原配方。

每次更新按已封存 UID 顺序遍历全部 11,529 旧行与 570 新行。旧微批贡献按完整类别分母加权并累积；新微批保留计算图，拼接后一次处理新 BCE 和全排序矩阵；全部梯度完成后才 clip 与 step。不能每微批各自归一化或 step。B/C 分别恢复同一 RNG 起点，前向顺序、次数、Dropout 随机流相同。每臂共 2,419,800 个训练行前向曝光，400 次总优化器更新；排序乘法的额外开销如实列出。

80% 历史 BCE 权重是保持能力的训练手段，**不是不退化保证**；20% 新监督、0.05 排序及 200 更新是事先固定的试验选择，不是已证明最优。仅终点参与检查。失败仅否定本次配置，不宣布排序、E3 或增强路线已被穷尽，不自动调 lambda/seed/轮数。

## 6. 结果如何决定下一步

不创建替代旧科学门槛的新 PASS，更不预先承诺 99% 或期刊等级。第一张表同时呈现全部能力：

- B/C 在旧攻击整体、future、各攻击族、熟悉正常、四个 OOD 池、ID fit 诊断、新 CHECK 各格的方向都不能被平均数掩盖。若宣称“无退化”，这些既定率必须逐项无恶化；任一项退化就列为真实权衡，同时给出幅度和翻转。
- B 有收益而 C 没有额外一致收益，优先保留简单 B；不因为预选了排序就包装其贡献。若两者互有胜负，报告 Pareto 权衡，保留 R 作现行基线，不从两个终点挑出一个冒称独立确认。
- 只有新 Hydra/CIC 正常改善而旧核心不改善，应称新增覆盖收益，不能称项目联合突破。训练侧拟合改善也不能替代 CHECK 改善。
- 训练目标下降但旧/新检查退化，说明这次新增监督或泛化关系不够；训练目标不下降只提示拟合/实现需要解释。训练曲线足以提供这一区别，不自动扩大诊断数据、换前端或开参数搜索。200 更新不是路线穷尽证明。
