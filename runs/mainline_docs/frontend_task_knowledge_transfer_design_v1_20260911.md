# 统一学生的任务知识迁移：实现方案 V1

2026-09-11。状态：DESIGN_COMPLETE_READY_FOR_IMPLEMENTATION；当前授权为方案设计，尚无实现或真实执行授权。
本方案是新的受控研究，原 F5、N1–N3、A/AB 的冻结规则与真实结果保持原状。

## 1. 目标与唯一推荐

目标是让统一 A+B 学生尽力继承旧 P2 的攻击能力，同时改善正常 OOD 误报；
优于旧系统是期望获得的实质增益。新设备入网以后单独增加，并检验同设备后续攻击。
不能把 A 的 84.05% 攻击召回当作继承终点，也不能只恢复两个已暴露的漂亮对比。

推荐：**从 A 初始化，用全部既定 A+B 真标签继续训练，以 A 的正确相对排序作保护，
并向统一编码器传递旧 P2 内部的任务贡献特征。** 单个部署模型仍为现有 F4+GRU+head。
旧 P2 只提供训练侧知识，不接到新表示后部署；没有运行时来源选模或正常释放门。

这项设计有三个明确能力来源：A 的已有知识；B 及全部真标签带来的纠错/新增学习；
旧预训练 E3 经 P2 形成的、超出一个报警分数的任务信息。只保 A 排序不提供第三项，
因此不能独立作为补足旧系统差距的完整解释。

本方案不是已证明有效的新方法。贡献向量仍可能携带来源捷径，F4 也可能无法表达
部分教师所用信息；若只能拟合而不能外推，本次候选即未实现目标。

## 4. 学生与真实标签损失

部署结构不变：131→64 GELU→单向GRU128→64 GELU→1，共91,265参数。
取每个目标事件处的因果状态h_i，禁止用后续事件或完整上下文末状态替代早期目标状态。
保持已封存的前缀、重置边界、packed padding与F4字段，不重新审计或重建历史输入。

C2增加一个**仅训练使用**的线性投影D：128→128，权重和bias均初始化为0，16,512参数。
预测D(h_i)为下文已经归一化的教师向量。梯度回传至GRU；原检测头仍由真实标签等目标训练。
部署移除D，推理仍只用原学生。零初始化使第一步教师损失先更新D，此后才能经D回传到h；
这是明确的数值行为，不是额外预热阶段，也不增加独立训练轮次。

S=197。每轮使用原配方的确定性A/B上下文排序与均分桶算法，复用epoch1–20。
A桶每步最多32上下文；B微批上限32。各原监督目标每轮一次；同批前向同时供相关损失使用。
上下文c的真实BCE先平均其全部监督目标；一步标签项：

`L_label(b) = (197/6286) Σ_{c∈A_b} BCE_c + (197/4297) Σ_{c∈B_b} BCE_c`。

不因额外教师项改变A/B监督分母，不重复前向伙伴样本或增加某个错误UID呈现次数。

## 5. A排序保护的完整定义

教师分数直接使用封存A训练postfit，不读取A在check/扩大池的数值构造损失。
E_c为上下文c中A训练目标、且A在固定0阈值判对的集合。按UID升序排序。
当前上下文均单标签；该事实作为固定名单的输入断言，不暗中泛化为混合标签实现。

`s_A = max(1, median_c [mean_{i∈E_c} abs(q_Ai)])`，只统计非空E_c。
每个epoch e=1..20，代表为
`E_c[(int(SHA256(UTF8(context_key)),16) mod |E_c| + e-1) mod |E_c|]`。
每A桶取所有攻击代表i、正常代表j组成对，要求component不同；不按报告错误或分数挑对。
多个目标的长上下文每轮仍仅一代表，防止其支配保护；20轮未覆盖所有目标时据实披露。

对每一对定义：

`m_ij = min(1, (q_Ai-q_Aj)/(2*s_A))`；`d_ij = (q_Si-q_Sj)/s_A`。

`H(v)=0.5*v^2`若`abs(v)<=1`，否则`abs(v)-0.5`。
`L_A(b) = mean_{(i,j)∈P_b} H(max(0,m_ij-d_ij))`；无对桶取0。

A判对两端保证教师差为正；以保存分数代入初始化时该项为0。对一个固定pair，
当前参数下该项为0意味着`q_Si-q_Sj >= min(s_A,(q_Ai-q_Aj)/2) > 0`；
它允许扩大间隔，不强制精确匹配教师置信度。保存分数的代数结论不代替实际前向等价验收。
该项是固定桶级平均目标，不伪称完整全数据所有正负对的无偏估计。
系数和半间隔/上限均为本次预先选择的设计常数，未通过真实试跑优化。

这一标量排序项可能只改变监督权重和排序偏好，不能单独解释旧预训练知识的迁入。
即使其损失为零，也只保护列明的训练对；不保证0阈值两端各自正确，更不保证未知OOD。

只读已保存训练分数的支持计算已经完成，见
`runs/frontend_knowledge_transfer_design_v1_20260911/metadata_support.json`
（SHA256 `854b3f857117cc688f26328a40ad31b6b48cccd31f6e7ca9a2e115e087003945`）：
A正确9,400＝攻击3,355＋正常6,045；全部6,286上下文可选代表；
s_A=29.98624610900879。20轮3,940桶全部非空，共967,530次pair、940,042个唯一pair，
全部9,400正确目标均成为代表；零margin/代数初始违例均0。
96.14%的pair涉及ToN两攻击族，全部跨source_group，不能称为充分的跨环境行为对照。
最终用唯一train终点预测重算实际pair并集的违反数、最差间隔和分族结果；不再模型前向。
训练过程中不同参数下出现的低损失，不能代替这项终点核查，更不能证明全体目标对受保护。

## 6. 旧P2任务贡献向量与特征损失

只为T的9,379条当前训练A目标生成教师特征。用原正常化器对768D E3表示作float64
标准化，加missing=0，转float32；旧MLP采用eval，无dropout：

`a_i = ReLU(W1*x_i+b1)`；`c_i = w_out ⊙ a_i`，c为128D。

数学上`q_P2 = b_out + Σ_k c_ik`。c记录各隐藏单元对旧判别的贡献，
相较单一总分保留贡献模式；对ReLU隐藏单元正比例缩放及输出权重反向缩放不变。
它不具有隐藏单元置换不变性，也不是可解释攻击语义或因果特征的证明。

权威旧logit仍由原float32 F.linear计算，不能用另一次c求和替换旧数值语义。
旧hard按原sigmoid float32→float64与冻结阈值0.065159872174263比较，必须与plan一致。
贡献缓存c采用float32乘积；重构核查则将float32的w_out和a分别升至float64后
重新相乘，得到`c_ref64`，再加升精度bias。禁止用已舍入c的升精度替代此定义。
float64重构与权威raw的差须不超过保守一致性容差
`(258*eps32/(1-258*eps32))*(Σ|c_ref64|+|bias64|)+1e-6`，eps32=2^-23。
这只是数值核查，不凭此容差更改hard或宣称逐bit等价。

令T_{c,y}为上下文c中属于T、标签y的目标，N_{T,y}为对应非空上下文数。
全训练侧一次确定标量：

`s_T = max(1e-6, sqrt(0.5 * Σ_{y=0,1} mean_c mean_{i∈T_cy} mean_k c_ik^2))`。

其中未截底的RMS必须有限且严格大于0，否则P停止；两标签eligible上下文都必须非空。
按固定plan元数据，攻击N_T1=3,329、正常N_T0=2,957；P须再次核对，不能按实际
成功读取的较小子集重新计算出另一个合法分母。
尺度在P由float64统计固定，目标转float32后封存，训练期间不重新估计。

归一化目标t_i=c_i/s_T；不逐坐标放大小权重单元，不把所有正常压成同一中心。
在C2的A桶内：

`L_T(b) = (197/2) * Σ_y [Σ_{c∈A_b:T_cy非空} mean_i mean_k H(D(h_i)_k-t_ik) / N_Ty]`。

使用全训练eligible上下文分母，空类桶为0，不能换成批内正负样本数。
所有T均有真实标签监督；B和教师判错的23条正常仅不接收此教师项，不删除或伪造标签。
不只选择“P2对、A错”目标，因为即使两者都判对，内部贡献模式仍可能提供附加知识。

三个损失：C0=`L_label`；C1=`L_label+L_A`；C2=`L_label+L_A+L_T`。
新增系数均为1；相同update最后统一反传完、裁剪并更新。不得按check/report调系数。
全局裁剪集合：C0/C1为91,265学生参数，C2为学生+D的107,777参数。
日志保存合并裁剪前学生梯度范数、D梯度范数和实际裁剪因子；不为诊断另作教师前向或反传。
C2辅助参数可能改变学生的裁剪比例，这属于该训练方法的整体影响，不声称只改变知识内容。
零特征误差只说明辅助投影能在训练侧读出教师贡献，必须通过下游联合结果检验检测头是否受益。

## 10. 与旧路线及文献的关系

F5已有旧标量margin、安全项及下一事件辅助任务，本方案不声称首次蒸馏或首次辅助学习。
新增假设是：旧P2任务贡献模式能为统一编码器提供有用的中间学习信号；A保护是防退化项。
CKBB正常残差/注意力释放、CKBJ的稀疏/密集历史错位与退化SSL、N1–N3有限head修补均不复用。
现有数据不支持强行跨设备匹配；通用域对抗或“所有正常聚在一起”不纳入此候选。

本轮在此前已读近期文献基础上，补充核对两项原始研究的摘要/接收信息：

- [Relational Knowledge Distillation，CVPR2019](https://arxiv.org/abs/1904.05068v2)：距离/角度关系迁移是既有方法，
  不能把当前标量间隔项包装为同样的高维关系蒸馏。视觉结果不保证本项目泛化。
- [A Comprehensive Overhaul of Feature Distillation，ICCV2019](https://openaccess.thecvf.com/content_ICCV_2019/html/Heo_A_Comprehensive_Overhaul_of_Feature_Distillation_ICCV_2019_paper.html)：
  教师/学生变换、特征位置和损失都是特征迁移设计因素，包含减弱无益信息的考虑。
  当前c=w⊙a为依据本地P2结构作出的任务相关投影，不声称直接复现论文或已完成首创查新。

此前已读[2026正常性漂移研究](https://arxiv.org/html/2508.15100v2)提供知识关系保持的网络检测参照；
其伪标签和CIC合成评估等设定不照搬。[流量基础模型综述](https://arxiv.org/html/2602.06636v1)
及[netFound v5](https://arxiv.org/abs/2310.17025v5)支持分清输入、预训练和任务读出的作用，
也提醒教师可能有捷径。本次未证明本地旧权重等于论文最新版。

普通特征蒸馏＋保护项仍不足以自动成为强论文创新。先检验它能否产生真实联合收益，
有正信号才继续证明贡献模式、迁移范围和新设备适应的独立价值。
