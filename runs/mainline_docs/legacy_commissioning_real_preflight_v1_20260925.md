## 3. 攻击审计：这 11 条漏检不支持“当前包被截掉”的解释

11 条漏检均来自 HeimVision 的 `interaction-attack-196`，分属 6 个规范化组件。保存的历史 Q 判断只用于冻结选样和比较，本轮没有重新评分。

| 观察 | 11 条漏检 | 22 条匹配正确对照 | 其中 9 条 TCP 载荷正确对照 |
|---|---:|---:|---:|
| 目标包保留在原前缀中 | 11/11 | 22/22 | 9/9 |
| 目标包字段保留到原转换器输出 | 11/11 | 22/22 | 9/9 |
| 目标包字段保留到 tokenizer 纯源码方法输出 | 11/11 | 22/22 | 9/9 |
| 存在过去其他传输连接混入 | 0 | 0 | 0 |
| 原前缀达到包数/突发数容量 | 0 | 0 | 0 |
| 原标签规则适用于当前目标 | 11/11 | 22/22 | 9/9 |
| 转换后输入包数 | 1–3 | 1–6 | 4–6 |

11 条漏检中，2 条只有 1 个输入包、3 条有 2 个、6 条有 3 个。22 条匹配正确对照含 13 条 SYN 和 9 条 TCP 载荷目标；后者分别有 4、5、6 个输入包。因此“短上下文的载荷攻击判别不足”是比容量截断更有依据的后续假设。

**这仍不是机制已证实。** 对照的冻结匹配条件是捕获、协议、活动、候选序号桶及不同组件，没有额外按载荷/SYN、包数或服务状态匹配；载荷子组和包数差异属于本次事后诊断。11 条来自 6 个组件、9 条载荷正确对照来自 9 个组件，不能当作独立设备复制，更不能从这种选择样本估计一般检出率。不能据此直接决定增加窗口、训练长度或启用载荷。

全部 53 条选中正确样本中有 7 条目标包字段未保留，但旧 Q 仍判断正确；全体 64 条均未观察到跨传输连接混入。这说明“目标包字段不在输入”既不能单独解释本批漏检，也不等于一定不能检出。原 prefix 的 `flow_duration` 仍可能反映没有保留进包字段的当前时刻，不能称目标彻底不可见。

这些结果只约束当前 DEV 选择样本，不外推到已消费 Netatmo 的 1,080 条漏检。本轮没有重开该确认集，也没有据此宣称所有前端问题已排除。

## 4. tokenizer 和语义的证据边界

原转换器的每次实际调用都和加帧追踪的副本做了数值摘要完全一致核对，共 64 次通过；原生产代码及输出规则未改。

本地没有完整 transformers 运行库。审计使用已固定 SHA 的 tokenizer 类纯方法，仅用惰性的 `object`/`dict` 替代基类和结果容器；数值分支、剥离载荷、前置标记、截断的源码逻辑被执行并追踪，形状及 attention mask 一致。本结果是**源码方法级证据**，不是目标超算上完整 tokenizer/encoder 运行时验证，更不是模型看见了足够语义的证明。

当前配置 `strip_payload=True`。这里说保留目标包，是保留了它经原规则处理的包字段，不能理解为攻击载荷内容也进入模型。漏检所用标签来自当前入站攻击源的 TCP 载荷规则；核对其适用性不等于重新人工确认了攻击意图。即使字段都进入模型，表示和分类器也可能分不开，需另行研究而非在本次预检中改动。

纯桥接结果内的 `source_bytes_verified=false`、`real_source_reads=0` 是桥接模块本身不负责读源的声明；外层真实读源由来源收据及解码器证明。`flow_summary` 内“不带回调无法判定映射”的字段保持原定义；本次具体映射在 `packet_token_method_audit` 和外层 `target_in_translated_packet_fields`。不能混淆层级，把这些 false 当成本次程序失败。

## 5. 下一步判断

**主线应先落实真正可验证迁移的入网材料，而不是马上重复训练或换前端。** 本次得到的是可执行的参考规划和具体缺口，尚未具备主动入网贡献的完整效果实验条件。下一步应沿冻结规则完成数据/采集准备审查：从已有清单确认未参与训练与设计的设备，落实同设备的可信正常观察、操作记录、随后正常和攻击配对，并在看结果前固定分母、时间关系和复制标准。如果现有材料不够，明确需要新增采集/下载的具体范围再决定；本轮没有新增数据或执行授权。

若先做现有数据的被动 DEV 可行性比较，必须单独声明 `UNKNOWN_PASSIVE`，保留旧困难回归池和原合法参考；不能冒充主动入网或独立迁移成功。当前两台 DEV 的 TCP 参考不足，是它的实际适用性限制，重复同一配置不会自动消除。

攻击增强保留为独立问题。后续若开展设计，优先核对现有合法 LEARN 证据中短上下文 TCP 载荷目标的训练覆盖、正常服务对照与表征可分性，再选择干预。此次小样本相关性不足以授权或支持直接重训。FULL 只撤销 Q 报警，不可能救回 Q 原漏检；补充正常参考可能误撤攻击报警，后续必须实际核验攻击不回退，不能从 Q 冻结推断安全。

历史科学结论不变：Job174666 的 Q=FULL 攻击 134797/135877，正常误报 51→30；加权相对收益 0.165755%，未达冻结 30% 门槛，仍为 FAIL。新独立确认名册尚未落实，三个旧确认设备已消费，独立 ID 仍 NOT_RUN。本轮没有新的准确率或误报率，也没有论文能力达标结论。
