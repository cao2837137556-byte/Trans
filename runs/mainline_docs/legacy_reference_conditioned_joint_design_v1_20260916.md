## 1. 目标与主张范围

主问题：给定新设备在查询发生之前、由外部依据确认正常的少量参考，能否降低后续正常流量误报，同时保住该设备攻击检出？设备入网只是取得参考的情境，联合能力仍是论文目标。

首版研究“新设备、已知攻击机制下的正常适应与攻击保护”，附带观察参考未覆盖的正常活动。现有 CIC2022 主要是 LOIC 洪泛与 RTSP 暴力破解，不能把 HTTP/TCP/UDP 选项说成三个独立未知机制。Hydra 仅两个已开发摄像头，不足以支持严格跨设备未知暴力破解机制结论。旧同名家族未见 91.91% 是原阈值下旧有效输入的开发结果，并非本候选的保证或新机制指标。

无需将攻击提高到 97% 设为继续论文的硬前提；但 OOD 降误报必须与攻击保留在同一运行配置下成立。未路由到新模块的旧攻击维持原 R，不能把它们加权平均后掩盖入网设备内部漏检，也不能声称它们得到提升。旧 hydraulic/predictive 若没有合法参考，仍是未解决池，不能以新摄像头收益代替它们。

## 4. 合格判定关注什么

1. 身份：名册、MAC/ARP、端点角色及捕获说明建立设备对应；IP改变不是自动否定，同名目录不是充分证据。
2. 标签：洪泛须有攻击来源、攻击端与受害端以及目标协议/请求语义的依据，区分攻击请求、响应和背景流量；不把整个攻击文件赋正类，不把不匹配的包赋正常。Hydra复用已有当前请求规则，不倒填整个连接为攻击。
3. 可比性：正常一般为网关视角，攻击README写攻击者视角。要查是否有足以排除主要服务/捕获捷径的例子，例如同协议服务正常与攻击、不同正常活动。仅删除地址字段不等于消除视角影响；缺这种证据时只能支持来源特定能力，不能宣称学到攻击不变机制。
4. 可部署信息：旧E3合法因果前缀、旧标准化、必要字段必须一致；身份只用于参考路由，不把设备ID、文件、日期或标签加入新模块。旧前端本身已有的端口等字段不偷偷改写。
5. 数据完整性：报告原始包、可标注目标、可编码目标、去重目标、独立会话/依赖组件、捕获和设备计数。越界协议单列；范围内提取失败保留在系统结果中，不能按成绩删样本。

这项资格工作有唯一的结束点：每个具名设备得到可用/不可用/证据缺失及原因，并据此给出真实规模。若标签或关键比较材料欠缺，则列出最小补充需求；不自动下载Idle/Active，不无限扩大数据普查。

## 5. 首选模型：小型关系修正模块

固定旧E3、原float64标准化语义、R和原阈值。正常参考保存多个会话的因果表示。设z为768维标准化有效表示，h_R为原R在eval模式下的128维隐藏输出，b_R为原logit。

建议具体实现：对每个参考r_i，计算

`u_i = ReLU(W1 [z-r_i, abs(z-r_i)] + b1)`，u_i为16维；

`c = [mean_i u_i, max_i u_i]`，c为32维；

`delta = W3 ReLU(W2 [h_R, b_R, c] + b2) + b3`，中间16维；

`s = b_R + delta`。

新增参数27,201，末层零初始化，起点与R一致。集合mean/max保留多个模式的查询相关关系，不强迫所有正常集中到一个中心，也不从头训练大型编码器。缺参考或输入不符合旧有效条件时，不计算该修正，走明确记录的原系统回退路径。

纠正可以升也可以降；没有“相似就正常”的硬放行。模块仍可能抵消真实攻击，冻结R不提供设备内安全保证。保留h_R也允许忽略参考的捷径，因此必须有普通对照和参考干预检查，不能仅靠结构名称认定机制生效。

参考构建候选规则固定为：最早三个合格正常捕获作为受控入网观察期，以其结束时间作为参考截止；只纳入截止前已结束且与查询无依赖重叠的会话。会话按预定hash抽样，最多64个，每会话一个截止时刻合法的因果端点表示；不足则使用实际数量并报告，不复制凑64。活动名仅用于检查覆盖和分项报告，不用于部署输入或偷偷挑选有利参考。全部查询都在截止之后；若三份参考耗尽可用正常捕获，该设备不具备后续正常检验资格。捕获数量不代表相同注册成本，因此同时报告观察时长、活动、会话和字节成本。首版参考注册后固定，不自动纳入预测正常流量。

## 6. 同一数据上的最小有效比较

| 方法 | 作用 |
|---|---|
| R | 原系统原阈值，保留基准 |
| Q | 冻结R上的普通查询残差头，仅用[z,h_R,b_R]；判断新增离线监督本身是否足够 |
| M | 普通条件MLP，输入[z,mean(S),std(S),h_R,b_R]；获得相同参考/标签，用常规汇总适配 |
| C | 上述逐参考关系模块；判断学关系是否优于普通适配 |

Q/M/C使用相同LEARN标签、查询、行呈现、正常/攻击及设备层级权重；M/C参考预算一致。各新增头都用一层16维隐藏层、残差末层零初始化；报告参数差异，不冒称完全等容量。首版不叠加蒸馏、排序、子空间或额外生成样本。

离线损失建议是逐设备等权的正常/攻击各半BCE；类别内部按活动/攻击模式、捕获和会话分层等权。设备缺某类材料不能隐式重归一化为“配对设备”。使用所有合格LEARN会话；长会话最多32个按时间覆盖的有标签目标供优化，完整因果上下文仍保留。评估保留全部预定合法目标并另报会话/捕获均衡结果。这里的32是资源抽样上限候选，不把抽样目标数当独立样本；资格统计后须同时给出全量会话数和被抽目标数才能冻结。

建议固定终点、无搜索：AdamW lr=3e-4、weight_decay=1e-4、40个分层epoch、batch256。一个epoch覆盖合格LEARN抽样查询一次；实际更新数由封存目标清单决定，不以重复episode虚增数据规模。提议三seed(27/127/227)用于预先规定的重复性检验，全部报告，不选最好seed；主结果采用三模型平均logit并同时列出单seed结果。以上均是新协议候选值，未改变任何历史冻结seed或预算。

主要运行点保持原logit阈值；各方法相同规则，不从DEVICE_HOLDOUT选阈值。低FPR曲线仅作辅助描述；若将来需要校准，只能另冻结DEV正常规则并让基线获得相同校准机会，不能在看到测试曲线后补一个有利阈值。

在同一冻结CHECK内加入两个零重训检查：错配正常参考（按预先确定且协议覆盖可比较的设备配对）及将参考预算上限从64缩至16。只有原始正确参考的主结果用于主张；干预不生成新“最好模型”。参考相近或实际参考不足16时变化小不自动证明无效，需结合Q/M比较解释。

## 7. 数据量以有效单位和精度决定

训练量：优先增加设备、正常活动、独立会话和捕获重复。11设备、219正常/76攻击是可检查的材料上限，不保证能训练出泛化。不得为了达到一个包数把同一洪泛长连接重复当新增监督。先按各角色实际单位核算，再决定当前设计是否值得训练。

测试量：包级FPR/TPR保留，以设备/活动/攻击方式分项；不只给合并均值。另报会话/捕获结果和R正确攻击的新漏检数、R漏检的新检出数。方法间比较必须使用同一批目标、相同参考成本和同一运行点。

作为数量级说明：独立同分布二项试验若零错误，95%单侧上界为`1-0.05^(1/n)`。n=54时上界约5.40%，n=227时约1.31%；至少299个独立零误报观察才能把该上界压至1%，0.1%需2995个。若真实FPR约1%，估计到约±0.5个百分点的普通近似需约1522个独立观察。这些不是包数门槛，更不是相关PCAP目标的置信区间。

同一连接、同一攻击运行的大量包高度相关；即使会话不同，也可能共享采集批次。主要不确定性按独立捕获/攻击运行及设备报告。只有三次攻击捕获时，不能从几十万包计算极窄区间；三台保留设备也不能证明广泛设备总体的1%保证。配对cluster区间若独立组太少，只报告有限样本差值、逐组结果和区间局限，结论可为INCONCLUSIVE。

因此1%作为首版低误报研究目标，0.1%暂作描述性指标，不将现有材料包装成已能认证该尾部风险。若需要正式1%保证或很窄的攻击非劣界，新增采集应优先补独立正常时段和攻击运行，而非更多同一洪泛包。

## 8. 结果怎样指导决策

研究目标：降低OOD正常误报，攻击检出不出现实际重要的下降；DEV上讨论的初始实际容忍范围为最多1个百分点攻击下降，而不是任何样本都不得变错。该容忍值是待冻结的新协议选择，不是已经通过的结论，也不代替不确定性判断。

必须同时看入网设备内的攻击保护和正常收益，各主要活动/攻击组不得被平均数遮住。ID及旧无参考路径应保持原行为，但它们不能稀释新模块的失败。若对低FPR或攻击非劣的证据不足，记录INCONCLUSIVE，不把工程通过或点估计达标叫科学通过。

- M与C均联合改善但C无额外收益：采用更简单、证据更好的方法，不为了神经网络复杂度保留C，也不宣称关系模块创新。
- C有联合改善且优于M，参考干预支持其利用参考：获得有限开发机制证据，再用保留设备检查；保留设备CHECK只开一次，不据其调参。
- 正常下降但同设备攻击明显受损：联合目标失败，查参考与攻击重叠或监督不足，不将入网误报下降单独晋升。
- 全部主要依赖服务/来源捷径，或材料不足以区别解释：不宣称机制成立；依据具体缺失信息补证，而非盲目继续同配方。
- 结构或输入工程异常：停止，保留日志，无自动重试；机械修复与新的真实运行按届时整体授权范围处理。

未来一次完整执行应把材料资格、特征准备、各预定臂、DEV判定和有条件一次DEVICE_HOLDOUT写为一个明确范围，减少逐文件/逐阶段重复授权；停止条件也写入。特征只准备一份并供各臂/seed复用，监督器落盘进度与结果，不需要LLM持续轮询。当前尚无该执行授权，E3目标总数/资源预算、参考规则的可行性与标签规则仍待资格结果，不假装已经可启动训练。

## 9. 审查结论与下一实质动作

首选机制仍值得研究；它增加了显式正常参考信息，直接对准OOD误报与攻击保护。但本次元数据核查不能证明11台都可用，不能替代原始标注和时序确认。尤其捕获视角与服务混淆、短正常捕获、攻击运行少，是当前最重要的三类材料风险。

下一实质动作是实现并执行**本记录列明的277个新增成员的有限原始资格检查，复用18个已有核查成员**，先产出真实设备/活动/会话/攻击运行分母及准确缺口，不生成E3特征或训练。它是进入本方案的必要数据准备，有明确对象和终点；当前仅完成范围准备，没有自动执行。

已读机制依据沿用 `legacy_joint_capability_mechanism_decision_20260916.md` 的 ICLAD(arXiv2603.19497v1)与漂移适应(arXiv2508.15100v2)原文。借鉴reference-conditioned inference与query隔离；不照搬ADBench划分、合成预训练规模或外文性能提升。公开数据的正常性依据与部署中可信参考的取得成本必须在论文里交代。

solved: 将方法落实到小型学习器、公平对照、具名设备角色、有限材料范围和样本量/统计解释；排除包数充当独立证据。
changed_mainline: design_only；用户接受的联合能力优先方向不变。
active_blocker: 277个新增成员尚未原始资格化；真实可用分母、混淆反例与训练资源量未知。
frozen: 原R、历史协议/结果、全部旧角色及已有无关修改不变。
superseded: 仅靠两个摄像头或原始包数量即可启动跨设备机制训练的假设。
next_action: 有限原始材料资格检查；不足即交精确补充需求，不自动训练/下载/HPC。
