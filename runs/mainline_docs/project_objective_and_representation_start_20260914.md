# 研究目标澄清与下一起点：统一输入上的有效预训练表示

2026-09-14。性质：用户目标澄清、有界历史/公开研究核对和下一步建议。
不是新冻结训练方案；没有模型加载、推理、训练、原始流量解码、数据或checkpoint下载。

## 用户确认的目标

用户明确不以复刻旧模型为研究终点：统一模型的攻击检测与泛化应争取超越旧系统；
训练覆盖过的正常OOD应在独立流量上低误报；未见设备通过后续入网适应处理。
“继承”保留为攻击能力参照，不继续作为无限延长旧决策/特征模仿的独立路线。
攻击能力必须与误报约束同时评价，入网适应必须核对同设备攻击保持。
系统规范、强基线、机制贡献和跨设备/环境证据共同决定论文竞争力，不预先承诺一区。
上述澄清不改变历史分母、门槛、数据用途或失败结论，不构成新真实执行授权。

## 从哪里开始

优先解决“统一输入用什么有效表示作为学习起点”，先审查保留/利用已有预训练知识的可行路径。
不默认当前从头训练的GRU必须继续，也不预定旧E3或最新netFound必然适用。
已有统一字段接口、合法角色划分、评估工具、AB等基线和失败证据均保留。
下一有界设计应选定一个有依据的主干能力干预，不同时改变前端、数据、损失并展开搜索。

本轮已核对的起点依据：

1. F1/F2/F3主要关闭的是新编码器模仿旧P2、粗输入矛盾或整事件词典OOV的具体路线，
   不是“旧E3参数在扩展输入下不可复用”的实证证明。不能换个名字重做已失败的路线。
2. 旧missing原因已做过拓扑审计，不再普查：非TCP/UDP、缺旧IP五元组及时间问题已知。
   实际netfound_flow只接收协议6/17，依赖IP/TCP/UDP布局；支持更多流量不是放开协议号即可。
   尚需核实固定官方checkpoint/tokenizer的原生语义、项目adapter限制及可保留参数范围。
3. 旧P2固定预训练E3后训MLP，当前学生从头学习投影/GRU/head，训练集合和加权也不同。
   因此输入字段相近不足以推出可迁移知识相近；当前训练近乎全对也不能证明跨环境能力。
4. 旧E3有真实攻击优势，也有困难正常OOD误报。保留旧知识只是能力来源候选，不能等同于目标完成。
   当前TRAIN攻击高度集中、来源单标签，训练证据的有效覆盖须与选定底座一起考虑。

## 下一设计必须交付的具体决定

- 旧A流量哪些原生输入语义与预训练参数能够保留；B流量哪些能合法表示，哪些需要新增学习。
- 一个优先底座/输入接口选择，明确为何优于当前GRU起点，以及新增知识来自何处。
- 配套训练信号及必需的合法训练支持；若存在真实数据缺口，明确对应材料，不把CHECK或查询加回。
- 一次最小、可执行的能力比较，使旧P2、现AB和新普通学习基线的作用清楚。
  先检验基础攻击与已覆盖正常OOD能力，再决定新机制与设备入网实验。

候选比较应有边界：优先审查本地旧E3知识可否用于统一输入；如存在本体语义不兼容，
以明确缺口选择一个合适的现代流量预训练候选。不能把“都值得试”变成多模型搜索。
该审查尚未完成，不声称新统一预训练接口已实现、旧模型已可处理B或新底座已选定。
