## 1. 要回答的问题与选择理由

**同一个已经用 A+B 学习的统一新学生，能否在继续提高攻击检测时保住已有正常 OOD 区分能力？**
从封存 AB 独立开始两个新臂：C0_AB 完全复用原 C0 普通标签目标，R_AB 完全复用原 R 目标。
每个新臂相对自己的历史对应臂，唯一指定干预是完整 student 起始状态 A→AB。
旧 P2 仍只通过合法 TRAIN 教师缓存起作用，部署仍是一个新 GRU 加新 head。

依据是已封存尾部分析：A、C0、C2、Q、R 在原合并 OOD 1%/0.1% 描述点的正常误报均来自
predictive-maintenance；AB 在这些点没有 predictive 误报。R 的 180 条与 A 重合 168 条。
全部 C0/C1/C2/Q/R 从 A 开始，AB 是从共同原始初始化另行训练的 A+B 学生，未做过本对照。
这支持检验起点及学习历史的作用，不证明 A 初始化、具体输入字段或教师损失就是根因。
R 的 95.16% 固定点攻击检出没有抵消 OOD 与低误报区间的弱点，旧严格 FAIL 仍保留。

当前选择比立即做教师输入屏蔽更易解释；任意屏蔽可能制造教师分布外输入。也不重复已有
19 字段输入审计、来源配对清单或有限训练集 head 拟合。输入/覆盖缺口仍保留为条件后续。

## 2. 文献与适用边界

- 本轮核对 [Fine-Tuning can Distort Pretrained Features and Underperform Out-of-Distribution，ICLR 2022](https://arxiv.org/abs/2202.10054)
  的原始摘要：继续训练可能提高 ID 却损坏 OOD，预训练状态与训练过程都值得检验。
  其理论是两层线性网络、实证为视觉任务；当前 AB 是本任务监督模型，而且完整 head 一起
  继承，不能照搬其随机 head 机制或将本对照称为 LP-FT。本次不新增线性探测或冻结层臂。
- 结合上一轮已核对的 [netFound v5](https://arxiv.org/abs/2310.17025v5) 原始摘要及
  [Causal Matching 作者摘要](https://www.microsoft.com/en-us/research/publication/domain-generalization-using-causal-matching/)：
  输入、既有表示、监督覆盖及来源捷径应区分。它们不证明换模型/配对损失必胜。
  本次不增加预训练、新数据、来源不变性损失、模型插值、冻结编码器或学习率搜索。

## 4. 损失与既有缓存的精确继承

L_label 不变：每个上下文内目标 BCE 取均值，再按各 owner 全局上下文分母计权；每桶为
`(197/6286)×sum_A_context(mean_target BCE) + (197/4297)×sum_B_context(mean_target BCE)`。
C0_AB 不计算保护/教师损失，不构造 D，不把 Q 去掉残差项误称为 C0。

R_AB 的四项系数仍全为1。L_Aguard 复用 A 的合法9,400行、原代表循环、跨 component 配对
与 s_A=29.98624610900879：`mean_pairs Huber(relu(margin-(qS_attack-qS_benign)/s_A))`，
`margin=min(1,(qA_attack-qA_benign)/(2*s_A))`。没有 ABguard 或新增 A 计算。
**AB 起点的 Aguard 可合法非零。** 不能以“初始保护 loss 不为零”停止科学执行，或改目标使其为零。
数值/身份/非有限异常仍停止；初始 loss 的科学大小不构成程序异常或筛臂标准。

教师仅原9,379条正确 A TRAIN（攻击3,357/正常6,022）；23条旧错判 A 正常和全部 B 只从
教师项排除，标签项不删行。全局类别/上下文分母2,957/3,329。定义原 M_b 加权算子：
`(197/2)×sum_y[(sum_eligible_context mean_eligible_target f)/N_Ty]`。
`L_q=M_b[Huber((qS-mT32)/s_q32)]`；`L_r=M_b[sum_128 Huber(e-mean_128(e))/127]`，
其中 `e=D(h)-t`、`t=c/s_T`，s_T=0.4098227709378718，h 不 detach。
先投影误差再逐坐标 Huber，总和除127，不做额外能量归一化。qS 始终由部署 head 输出。

直接复用已封存 aligned-P 的 margins.f32le、teacher_index.json、preparation_receipt.json：
tauT=-2.66353170637526；s_q64=24.467974454982155；
s_q32=24.467973709106445，float32字节hex=`69bec341`。使用封存 float32 margin/scale，
不再次 derive、估计尺度、筛教师、改 margin 或重新物化 P。
旧 receipt 的 recipe_sha256 仍为旧 Q/R 配方 SHA，不得改写为新配方 SHA 或跳过来源核验。
新入口记录“新配方引用该旧已封存缓存”的关系，分别检查两种身份。

R 缓存加载核对完整 manifest、对应原9,379行 UID/context/label/row 与全局分母、形状、
有限性、margin32字节及sign与保存的旧硬判一致。验证只比较封存值，不重新求尺度/教师。
原guard尺度按固定常量和缓存核对，不重新估计其统计量。
新 C0_AB 的训练回调不能访问教师或保护数值，统计中这些项为0，误差均值为null，不能除以0。
