# 新材料的上下文隔离与服务对照规则

2026-09-17。用户授权处理未完成获取与已定位的隔离、对照问题。本记录将规则落实为可审查的代码与合成验证；**尚未生成真实样本 UID 清单、特征或训练结果，不是完整训练 recipe**。旧 R、前端代码、历史分母/阈值/seed/损失和已封存结果不变。

## 1. 这次修复的具体对象

新 Active 全网捕获中，不同设备可能共用 DHCP 广播五元组。旧前缀按五元组聚合，直接在全网捕获上共享缓存，会混入另一设备的历史。没有直接跨角色包或完全相同的字节，并不能排除这类上下文共享。

`repo/ood/legacy_reference_context_scope_v1.py` 给出未来新样本准备的过滤器。它不替换 E3 编码器，也不把 MAC 或设备角色变成模型输入。应用位置必须在**查询选择和每一次参考/查询前缀 append 之前**；只删除查询而把不合格包留在上下文中，不符合本规则。

## 2. 可执行的隔离约束

1. 以已核实的物理设备 MAC 确定所属设备，按设备、原始捕获、旧规范连接键分别维护前缀。归属信息仅用于隔离与审计。
2. 同时剔除 UDP `0.0.0.0:68 ↔ 255.255.255.255:67` 的查询及上下文；不将该共享 DHCP 键中的包加入任何参考前缀。
3. 单个上下文包必须只涉及当前所属设备这一台范围内设备；涉及另一设备或同时涉及两台范围内设备的包不能共用。
4. 每个查询只使用同捕获、同设备、同旧连接键、帧位置不晚于查询的上下文。其他连接的时间异常不能污染该查询。
5. 保留原始捕获顺序，不排序、不用后续包回填。如果本连接较早帧的时间晚于查询，抛出 `ContextOrderError`，按旧时间倒退失效规则处理；不能悄悄跳过该包来“修好”前缀。原有 header/protocol/completeness 与持久失效规则仍须执行。
6. 参考必须是同设备、同拟议用途中的独立正常来源，整个参考观察区间严格早于第一个查询。攻击目录中的成功播放、模型低分或后续应答都不能替代正常性依据。
7. 保留设备的正常参考可作为入网时可获得的信息，但不能用于拟合模型、归一化参数或校准阈值。查询标签、全文件事后统计和流审计结果都不进入部署特征。

合成验证覆盖当前合法上下文、未来帧、不同设备/捕获/连接、双设备归属、DHCP 双向包、相关连接时间倒退、无关连接时间异常、参考时间相等/来源不明/跨角色等情形。记录见本次 run 的 `context_guard_verification.json`。这些检查不替代未来真实样本清单与特征准备的验收。

## 3. 服务对照不能靠改标签补齐

以协议、方向和**设备本地服务端口**核对正常/攻击重合，不能把正常设备访问远端云服务器的 80 端口误算为设备本地 80 服务的正常对照。端口重合也不能单独证明业务和采集视角匹配。

前五天 Philips 的本地 TCP/80 记录具体为：11 月 8 日 5 条流、11 月 10 日 28 条流，共 33 条流、330 个双向包、33 个 HTTP 请求；正常入站包为 165 个。它是可进一步标注的局部正常服务证据，不能复制成所有设备的对照，也不等于 33 次独立实验。补齐日期后的最终汇总单独列出。

已有两摄像头核查没有在正常候选中看到 RTSP/554 对照；Nmap 捕获含扫描、成功播放及视频的混合流。继续保留混合/未分配状态，不把其中的 PLAY 或视频自动标为正常训练增量。官方正常网关采集与攻击机器采集的视角仍未证明相同。

## 4. 对缺口作有限而明确的处理

服务对照缺口限制的是“排除了服务/来源捷径”这类主张，**不是所有开发性训练的统一禁行条件**。既有 R/Q/M/C 条件参考设计仍可在相同合法查询、标签、参考成本及运行点下检验有限开发收益；完整训练/标注 recipe 和执行授权尚未由本记录替代。

为检验关系模块是否真的利用参考，预先规定保持查询不变的参考干预，并与 query-only、普通 pooled-reference 方案公平比较。这能检验参考带来的增量，不能独自证明任意未知攻击泛化、跨采集视角稳健或消除了全部捷径。若 C 不优于同信息 M，不能因神经网络更复杂而宣称关系机制创新。

所有结果必须分别报告正常 ID 误报、入网/OOD 正常误报和对应设备攻击检出，并注明已知攻击机制与更强未知攻击主张的区别。不能用无变化的旧攻击大池稀释新设备内部的攻击漏检，也不能由大量相关包给出虚假的独立 1% 风险认证。

此阶段下载范围止于已具名七日。后续进入一次有限开发机制实验前，下一件具体工程工作是把这些规则接入样本清单生成与验收，并封存正常/攻击标注、参考预算、训练/校准/评估用途和精确 UID。无需再次泛泛盘点数据或为了凑包数扩大下载；确需新增对照时，必须指出缺失的具体行为与有限范围。
