# 方法章节中文工作稿（Codex，2026-11-08）

方法身份与证据索引见同目录claim_evidence_codex.md。本文描述当前冻结算法；源码中的实现名仅用于复核，投稿时再统一术语。未补齐的编码器谱系与字段定义明确留待复现附录，不用旧few-shot稿补全。

论文定位：《基于上下文约束正常参考的物联网入侵检测》。本文件为实现细节底稿；连贯正文见manuscript_maintext_v1_codex.md。

## 1. 任务与可用信息

对每个流量查询i，检测系统输出攻击分数及固定阈值告警。源域FIT用于分类头训练和特征/几何拟合；独立正常CAL用于阈值校准。目标环境允许访问经既定资格检查的正常建档与历史参考，但不使用目标查询标签重新训练分类头。A/B用于开发评价；Edge未参与开发，作为跨数据集外部评价单列。本文研究利用设备正常参考抑制误报时，如何通过上下文约束控制攻击告警损失。跨数据集是实验设置，不设为独立方法贡献。

## 2. 表示与源训练分类头

查询输入为x_i=[z_i,q_i,c_i]，维数768+14+8=790。z为冻结E3编码的源归一化表示，q为保持原定义的14维查询描述，c为源归一化后的设备上下文。分类头为Linear(790,128)、ReLU、Linear(128,1)，输出实数攻击分数a_i^(k)。三个随机种子k∈{27,127,227}分别训练，编码器保持冻结。

上下文按逻辑capture、受保护设备和协议聚合，仅统计入站流量。在1秒和10秒窗口中分别计算包速率、IP字节速率、源身份数和有向五元组连接数，共8维；10秒窗口的包数与字节数除以10，身份与连接数不除以10。逻辑时钟取t_i=max(t_(i-1),raw_timestamp_i)，保留已处理前缀中满足t_i-W<t_j≤t_i的包，当前包计入，不读取未来包。所有帧推进时钟，即使该帧不贡献入站统计。A跨capture重置；B历史按封存索引的逻辑时间序前缀重放，不宣称所有数据均按原PCAP物理块顺序处理。

8维统计先log1p变换，再用全部源FIT的float64总体均值/标准差标准化，恰为零的标准差设1，结果转float32。E3复用冻结源FIT归一化，q14不变。分类器输入的E3源标准化与后续几何计算的单位化分开，不能混为同一步。

源训练沿用加权BCE与正常高分尾部配对损失之和，固定40轮、batch256、AdamW（学习率0.0003、weight_decay0.0001）。每轮起点从源FIT正常样本选择加权质量为1%的高分尾部，轮内固定，从中有放回采样128个负例，以softplus(a_negative-a_positive)形成配对项；两侧均反传。并列分数的剩余质量按权重分摊。采用第40轮，不挑种子或检查点；这是按轮更新尾部的训练配方，不借用其他优化算法的收敛保证。精确原始权重、尾部采样与batch估计式以D/TRAINING_SPEC_FROZEN.json的training.parent_recipe为准。最终训练验收见D/FINAL_TRAINING_ACCEPTANCE.json，不将训练前规范的NOT_STARTED状态当作当前状态。

## 3. 合法参考与三空间支持

参考来自合法正常资料，按partition、device、protocol分组。查询时间必须晚于该参考库reference_end；若存在同capture的bank_end_frame，则查询帧必须超过它，同capture参考帧还必须早于查询帧。资格不成立、库缺失或合法组件少于两个时，不实施正常参考扣分。完整库不是未来全部正常流量的集合。

设R_i为合法参考集合。对参考r，编码距离d_z为源标准化后单位向量的1减内积（截断到[0,2]）；q14与上下文距离d_q、d_c为逐维均方根差。三空间联合距离定义为

\[
D(i,r)=\max\{d_z(i,r)/\rho_z,\ d_q(i,r)/\rho_q,\ d_c(i,r)/\rho_c\}.
\]

先在每个component_id内取最小联合距离，再跨不同组件取第二小值D_(2)(i)。支持强度为s_i=clip(1-D_(2)(i),0,1)。缺少合法双组件或可用源几何时取s_i=0。这里要求两个不同组件，不等于假设它们统计独立，也不是简单取两个最近参考行。三维计算遍历全部合法参考，可重新选择支持者，不能仅检查旧二维匹配的两个代表。

三个半径按协议由合法源FIT正常查询的第二组件距离拟合，使用冻结权重的0.9分位数。TCP的(ρ_z,ρ_q,ρ_c)约为(0.635035,0.378432,1.230296)，UDP约为(0.538952,0.272750,1.787982)；完整精度及资格UID摘要在论文METHOD_FREEZE.json。比值的零半径约定为：距离也为0时比值0，否则无穷大。当前已冻结半径均为正。

## 4. 单向修正与告警

令g(s)=1-(1-s)^3（s>0），g(0)=0；λ=0.25。正常情况下，每个头的修正分数为

\[
\widetilde a_i^{(k)}=a_i^{(k)}-\lambda b_k g(s_i).
\]

b_k依种子顺序固定为118.95627975463867、121.3746566772461、122.36117172241211，来自封存OLD782的源FIT尺度。OLD只描述扣分尺度；当前分类器和阈值仍属于FUSION790。早期前端评价使用新头自身尺度，当前论文最终版本是在开发诊断后选定的旧源尺度组合，需如实披露选择过程。

对q14[0]=1、q14[2]=1且q14[5]=0的SYN-no-ACK守卫行，所有设备均保持RAW分数。其余行无支持时同样保持RAW。每头严格以score>cut判为告警；三个cut依次为-23.04324722290039、-23.315204620361328、-22.614715576171875。集成按27/127/227顺序以float64对修正分数取算术均值，使用单独源CAL校准的阈值-23.2497984568278；不是多数投票，也不是平均三个阈值。

修正项非负，因此本机制只能保留或撤销RAW告警。加入第三空间使联合距离不减、支持不增，在相同尺度下减少扣分，可保住二维修正误撤的告警，也可能保留更多正常误报。该代数关系解释了设计折中，不证明所有域上的检测最优性。
