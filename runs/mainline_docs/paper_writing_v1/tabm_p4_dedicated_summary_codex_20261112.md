# TabM检测头与3D正常参考：独立迁移实验结果

本文件专门整理已完成并验收的TabM迁移实验，对应恢复作业183558，与六项p4机制对照分别归档。正文4.8和表9此前已纳入本实验；本次补充独立入口、逐设备分解及配对变化，未重复执行或整理六项机制控制。

结论：参考模块在TabM上大幅减少正常告警，并伴随少量攻击查询撤警；CIC和Edge表现较好，UNSW仍有设备集中的误报和基础头检出短板。当前主系统保持完整库MLP p4，TabM是迁移证据，不自动替换主头。

## 1. 比较协议与来源

复用既有TabM三种子权重和共享790维输入。每个种子模型保持32成员攻击概率均值，使用自身源FIT加权Q90−Q10尺度和自身源正常CAL阈值。p=4、λ=0.25、SYN保护开启；未套用MLP基准logit尺度，未裁剪修正分数，未重训。p3校准元数据复用于p4，p4执行及原p3桥接由各变体回执和指标确认。

直接来源为 `runs/p4_tabm_acceptance_v1_20261111/tabm_p4/` 下MAIN_TABLE、METRICS、PAIRED_CHANGES及VERIFICATION；原p3在同级tabm_p3，统一状态为上级FORMAL_ACCEPTANCE。原183549失败记录保留，183558恢复完成，不将旧失败描述成当前仍未完成。
