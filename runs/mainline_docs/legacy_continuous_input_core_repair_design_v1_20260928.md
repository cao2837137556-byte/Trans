## 1. 决定与目标

选定一条最小的实质修复路线：**保留现有冻结 E3 编码器，把永不滚动的早期前缀改成包含当前包的近期片段，并补充同一连接内持续更新的行为统计；使用真实标签重新学习攻击打分，按相同新输入重新学习正常参考校验。**

不直接把新窗口送进旧 Q 后就声称修复完成，也不再开一个覆盖所有协议的新前端项目。训练、参考、CAL 和检测必须使用同一版本的输入定义。旧系统保持独立不动，旧权重和成绩作为对照。

首轮回答两个问题：

1. 当前攻击行为真正进入模型后，相似攻击套路跨设备/采集环境的检出能否接近原系统约 99% 的水平？不仅是恢复外部 Q 的 59.94%。
2. 在这个新的攻击底座上，入网正常参考能否降低 OOD 误报，同时不再把正确的攻击报警撤销？

这是修复后的联合能力验证，不是论文最终确认。当前使用过的 CIC DEV、UNSW 数据均是开发证据；独立 ID 和新的独立确认后续补。

## 2. 为什么选这条路线

Job177299 已经确认：五台设备各只有七种源字段/特征/联合分数；第七个攻击查询后冻结约 63.5 分钟，涉及 72,523/72,553 条攻击。E3 不消费一直增长的 duration。这个事实足以要求修复持续输入，但不能证明所有漏检都由此造成。

另外两项失败必须分开：Q 完全漏掉 Motion/Samsung；FULL 又撤销 14,605 条 Q 正确攻击。只修 Q 或把旧 FULL 原样挂到新输入上都没有依据。正常与攻击的旧摘要不完全相同，也不等于可泛化地分离。

只滚动包内容仍可能看不出相似报文的持续速率；只加统计又会保留陈旧内容。因此以近期内容加小量行为统计为主候选，同时保留内容单独修复的消融。**持续输入修复不等于新的学习创新**；是否有额外的参考学习贡献，必须胜过无需学习的参考对照。

## 3. 新输入契约：近期内容和持续状态

### 3.1 归属、因果与生命周期

- 支持范围仍是当前已定义的 TCP/UDP 合法输入。不能据此声称支持所有协议。
- 状态键保持 `owner + source/capture identity + canonical bidirectional 5-tuple`。owner 只做归属和方向判断，不进入神经网络。
- 按捕获位置处理所有符合原上下文资格的包，不只更新被选为查询的包。每个查询先更新当前包，再获取不可变快照；帧号和时间均不得越过查询。
- 原 owner/多设备混合/DHCP/协议/时间回退保护继续有效。新实现不得绕过这些规则。时间回退、缺失必要字段或不一致身份触发停止并保留原因，不能删行。
- 新活动片段只在该键首次出现、capture 改变，或距上一包 **大于 60 秒**时开始。恰好 60 秒不重置。没有标签、攻击区间、查询序号或数据角色触发的重置。
- SYN/FIN/RST 本身不重置。尤其不能每个 SYN 都开启新状态，把 SYN flood 的累积行为抹掉。这里称“键内活动片段”，不冒称完整 TCP 会话重建。
- FIT/CAL 划分仍以原完整依赖组件为单位；60 秒重置不允许把原组件拆到两边。禁止跨连接设备级累计，避免引入新的跨角色依赖。
- 实验执行时内存不足必须停止，不能通过未记录的 LRU 淘汰静默改变输入。过期状态按上述 60 秒语义回收；capture 结束全部释放。

### 3.2 近期内容

保留本地 checkpoint 的 12 burst × 6 packet 容量和 10 ms 同方向 burst 规则，但改变保留方向：

1. 每方向维护最近 12 个真实 burst；burst 由完整合法事件流中该方向相邻包间隔 `>10ms` 产生，不能由被抽样后剩余包重新分组。
2. 每个 burst 保留最后六包。按最后活动位置选出两个方向合计最近 12 个 burst；稳定同分顺序使用最后帧号。
3. 去掉距查询时间大于 60 秒的保留包，删除空 burst；剩余 burst 按首个保留包的 `(timestamp, frame)` 排列。
4. 新 translator 直接接收这些 burst 边界，不再调用旧函数的“重新分组、取最早 12/6”。最多 72 包；当前查询包必须保留到 tokenizer 的有效 header token。
5. 头部字段、无 payload 占位及 strip-payload 规则与旧编码接口相同。方向与 TCP seq/ack 相对锚点使用**当前窗口内**最早保留包及旧 translator 的首两行锚点规则。窗口滚动可改变锚点，训练/参考/检测一致；不是全连接固定序号坐标。
6. 每 burst 的 bytes/count/IAT 按实际保留包计算并明确命名，不能伪称全流统计。全流最近行为由下一节单独传递。

每个 UID 必须保存：source SHA、owner/键哈希、query frame/time、状态重置原因、保留 frame 列表、burst ID、当前包的 token 偏移/有效 attention、输入语义版本及实际 tensor SHA。未来追加包不得改变已导出快照。

**合格标准是当前包确实映射到有效 token、状态确实使用合法历史，不是要求每一行 embedding 不同。**相同流量可以有相同表示。旧 source hash 也不能代替实际 tensor hash。

### 3.3 26 维轻量行为状态

两个时间半衰期 `h∈{1,10}` 秒。每方向按 owner 发出/owner 收到定义；IP/MAC 值只决定归属，不作为数值特征。对全部合法事件递推：

`S_h(t) = 2^(-(t-t_prev)/h) S_h(t_prev) + event_value`。

每方向、每尺度保存 N（包数）、B（IP bytes）、SYN&&!ACK、ACK、RST、FIN 四种计数。查询时两个方向均衰减至当前时间，当前方向再增加当前包。UDP 四个 TCP flag 指示全部为 0。

输出每方向/尺度六项：`log1p(N*ln2/h)`、`log1p(B*ln2/h)` 和四个 `flag_count/max(N,1e-12)` 比例，合计 24 维；再加整个键上一包的 `log1p(Δt_seconds)` 和 `has_previous`，共 26 维。新片段首包这两项为 0、0。它们是因果强度摘要，不是无偏的固定窗口 pps 估计。计算状态用 float64，输出模型输入用 float32。

字段选择只使用已有包头和相对时间，不输入地址、端口、绝对时间、文件名、设备编号、标签、攻击速率档标签或未来结束时间。1/10 秒借鉴成熟流式统计的短/长尺度；60 秒是固定失活界限，**并无本项目最优性的证据，不搜索这些超参**。

### 3.4 tokenizer / batching 的额外修复

本地 `SimpleDataCollator` 根据同 batch 最大 burst 长度/数量 padding；实际 E3 又使用扁平 `arange` 位置和由 `dataset_burst_sizes.max()+1` 推导的 stride。不能忽视 batch 对输入张量位置的影响，也不能仅因旧 source hash 相同就去重复用 embedding。

新缓存按单个样本的 `(protocol, max_header_tokens_per_burst+1, burst_count)` **精确形状分桶**，桶内按 UID 排序，固定 batch16；末 batch 不补伪样本。相同样本的 stride 和位置不依赖其他长度样本。原有冻结 tokenizer/vendor 不改；E3 float32/eval、原 masked-mean 不改。禁止以伪造 burst size 实现 padding。

实现验收需分别证明：不同同行样本下实际有效 tensor 一致；同形状不同 batch 序列的 embedding 数值误差在固定容差内。前者可无模型合成验证，后者并入一次目标环境预检。**未证明旧 1→多 feature 全部由 batching 造成**。首轮不采用基于 source hash 的特征去重加速。

## 4. 检测与训练：清楚的两种职责

主链只有：`因果输入 → 冻结 E3 + 26维状态 → 一个攻击分数 → 合规正常参考校验 → 最终报警`。

### 攻击打分

新建一个 `794→128 ReLU→1` 的小型 MLP，使用源 FIT 真标签重新拟合；不加载旧 P2/Q 权重，不蒸馏旧陈旧片段分数。128 隐层沿用原 P2 的量级。没有 dropout/BN/新编码器。旧 E3 的表示知识继续复用，旧 P2/Q/FULL 独立保留为历史能力对照，不再串入新主链。

这是明确取舍：新输入的语义和归一化已经变了，固定旧 P2 再用残差抵消会保留不必要的耦合。代价是无法承诺原权重能力逐项继承，所以必须以原数据集完整 DEV 做回归验证，并设置同结构旧输入控制。

### 正常参考校验

保留“攻击证据”和“正常适应证据”两种职责，不把正常相似性当作确定无攻击。新校验器仍采用旧 FULL 的共享线性投影、L2、同协议 top2、攻击最坏合法参考约束，但输入换成一致的新表示与状态，所有参数和 cut 重新建立。**不宣称这一数学机制已经解决迁移，也不把它命名为新学习发明。**

- 输入先按源 FIT 标准化；E3 768 维和状态 26 维分别作 `v/max(norm(v),1e-12)`，再各乘 `1/sqrt(2)` 后拼接，并以相同公式归一化拼接向量。两部分各有固定权重，避免仅因维数而压没状态。合法的全零标准化块映射为零并计数，不能因样本恰好等于 FIT 均值而拒收；非有限值停止。投影后也采用同一安全归一化，零投影的相似分数为0并报告，不改成无参考。
- W 为 `64×794`、无偏置，查询/参考共享且双方有梯度。RAW 对照直接使用同一拼接向量的余弦，不学习 W。
- 沿用当前可信正常入网参考的固定 UID、时间界限、同协议和至少两个不同依赖组件要求。单参考/无参考不凑数、不延长观察，直接用新攻击分数。新参考记录必须也从当时的合法历史生成，不能借用之后状态。
- 正常对本设备早期参考；攻击取所有合法更早源训练设备参考组的最大正常证据。只用源 FIT。沿用预算 2/8/ALL 循环，避免重新发明已试过的约束。
- 正常损失 `softplus(-10*r_own)`；攻击损失 `softplus(10*r_worst)`。各类质量各 1/2；类内按设备→活动/模式→捕获→原 `session_id`→行等权，精确沿用 `legacy_qref_data_v1.class_weights`；分割所用 `component_id` 与加权所用 `session_id` 不混写。
- 首轮**不训练九个旧辅助头、不产生 H 追加重权**：新攻击头尚未在新表示上过拟合，不能照搬“Q 已训练全对、必须额外制造错误”的前提。它是有意限定的输入修复试验，不是对所有参考学习潜力的一次穷尽。
- 最终报警仍为 `attack_logit > tau AND NOT(valid_reference AND normal_evidence > cut)`。RAW 和 learned 分别有源 CAL cut。校验器不能救基础漏检；必须逐条统计新增漏检。不能通过抬高攻击分数或投票回旧 R 隐藏失效。

### 优化和 CAL

三个 seed 固定 `27/127/227`。三个攻击头结构各三次，参考度量三次，共 **12 个小头**，E3 不训练且新特征只计算一次。40 epoch、batch256、AdamW(lr3e-4, weight_decay1e-4, betas0.9/0.999, eps1e-8, foreach=False)，最终 epoch 唯一终点，无早停/调参/追加轮次。CPU float32 确定性运算；权重汇总 float64，每 UID 每 epoch 一次；分层权重规则如上。MLP 同 seed 使用同一初始768列和偏置，状态26列初始化为0，使 RECENT 与 RECENT-STATE 初始函数一致，但可学习状态列。

每种表示只用源 FIT（不包含参考/CAL/DEV）计算均值/标准差，scale=max(std,1e-6)，不裁剪。分类 BCE `N/b * sum(w_i*BCE_i)`，不在 batch 内重新归一化。无需参考的基础头使用全部 FIT；校验器使用旧规则确定的可用参考子集，正常/攻击两类重新各归一到1/2，明确报告剩余覆盖，不能静默改变基础头分母。

每个头及三 seed 平均 logit 的攻击阈值只由源 CAL 正常确定：在候选集 `{−inf}∪实际正常logit值∪{+inf}` 中，取使**设备→活动→捕获→session→行等权 FPR≤1%**的最小阈值；严格 `>` 报警并保守处理 ties。只有这一个工作点；源 CAL 攻击只报告检出，不能为凑99%放宽阈值。旧0.065阈值不跨表示复用。

RAW/learned cut 沿用对全部源 CAL 攻击、所有合法源参考组的保护：`max(0, max_similarity)+1e-5`；ensemble 先对同一参考组平均，再求最大。**CAL中所有攻击均参与，不能只选已报出的攻击。**cut≥1而不能撤警是合法的无收益结果，不回退到宽松 cut。CAL 曾被旧 Q 看过，但新头不加载它；E3预训练暴露仍未获独立证明。

### 报告和判定

同时报告 normal FP/分母、attack TP/分母、每设备/协议/速率区间和组件宏平均；两池主指标均使用各自原 metadata 的 `1/label_metric_weight_denominator`，核验其原层次/抽样规则，不用训练权重替代。不能仅报相关包的总体百分比；只有5个外部设备/15攻击区间，不把72,553包当独立重复实验。每 seed 和预指定 ensemble 均列出。

首轮预先设定的**开发继续门槛**（不是旧实验门槛的修改）：

1. 输入当前性/因果/身份资格全通过；否则禁止优化器。
2. 联合候选在 CIC DEV 和 UNSW 两池的 ensemble attack recall 均≥99%，每设备≥97%；CIC DEV 与原 Q 99.986086% 差不超过0.1个百分点。每个 seed 两池总体≥97%，不只挑一个幸运 seed。
3. 联合候选两池主加权 normal FPR 均≤1%，每设备加权FPR≤2%；learned相对基础 RECENT-STATE 新增攻击漏检为0（逐池、逐seed及ensemble）。RAW使用同一零新增漏检判据单独判定，RAW失败不使已通过的主候选自动失败。任何同设备异常不得被总体平均隐藏。
4. 若声称 learned 正常适应有效，它相对同一基础头的主加权正常误报至少降30%，两池分别满足；基础FPR为0时记NO_ROOM_FOR_GAIN，不以0/0宣告30%改善。对 RAW 与固定错误参考对照的优势必须单列。RAW 更好时，不宣布学习创新成功或自动换主方案。

门槛是目标驱动的工程筛选，不是功效计算或一区录用条件。达到门槛也只有开发证据；source CAL 正常不是独立 ID 测试，ID继续标明 NOT_RUN。

不符合时用已经保存的分数/输入归因一次，不自动重试：基础攻击失败，优先查看源训练 SYN/行为覆盖及域差，禁止继续调撤警模块；基础成功而 learned 丢攻击，则参考兼容性问题未解决，不能牺牲攻击换误报；两者都成功再做原域更广回归、独立 ID、基线/消融与未参与设计的确认。

## 6. 实现顺序、成本与停止边界

下一步是**实现**这份契约：新版本输入/state/translator/provenance，精确形状 batching，单一攻击头与参考接口，合成验收、缓存/训练/评分执行器和超算小包。旧实现与缓存不覆盖。不是再做一轮泛泛方案讨论。

后续一次真实链条应为 P（校验→原始因果重建→新特征封存）→T（源 FIT 全部小头→终点封存）→K（CAL定点→固定开发评分→导出）。一次完整执行授权可以覆盖整条已交付链；失败停止零自动重试，已授权的机械阶段无需反复询问。当前设计授权不启动它。

P须同时完成仍缺的远端旧 LEARN/DEV完整缓存 SHA/UID 与近期重复尾段统计，供 OLD-MATCHED；本地不完整预分配数组禁用。原始流重建时额外统计**最终 FIT**的 TCP SYN&&!ACK 与 payload、方向/速率分布和独立组件数，不能用此前候选53,856替代最终训练支持。若 FIT 完全没有合法 SYN&&!ACK 或正常 TCP，停止并说明训练支持缺失；非零亦不称足够泛化。源标记/标签仅进监督和审计，不能控制输入。

先完成全部原始清单、字段、依赖闭包、磁盘/内存与运行环境检查，再进行一次目标环境合成前向/资源计时；计时属于P内固定前置步骤，不循环试资源。目标阶段需验证当前帧进入真实模型tensor以及三角色输入合同一致，不能只在仿真translator层PASS。用固定生成张量校验数值/shape，实际样本的provenance全量校验；不得以抽64条代替百万行合法性。

按此前148,408行约28,796秒线性估计，新1,095,200行仅E3就约 **59小时**，形状分桶/真实长度改变后可能更慢。这不是耗时承诺。新float32特征原始量约3.48GB，加source provenance、旧缓存、训练中间件和原始解码需另估。不可直接将旧8小时说成新任务8小时。
