# 面向真实检测输出的迁移修正：Q/R 两臂设计

2026-09-12。状态：DESIGN_COMPLETE_READY_FOR_IMPLEMENTATION。本轮只做文献核对、方案与审查；未新增教师计算、学生推理、优化器训练或评估。机器口径见同目录 `frontend_task_aligned_transfer_recipe_v1_20260912.json` 及各自 SHA256 侧车。旧配方、旧结果和严格继承 FAIL 均保留。

## 1. 决策与目标

**推荐继续迁移路线的一次有界修正：直接监督新系统真正用于检测的分数，并用一个增量臂检验教师内部贡献模式是否有额外价值。** 不延长 C2，不同时加入梯度投影、尾部损失、换前端或扩数据。

共同目标仍是：A+B 共用的新前端和新检测头尽力恢复旧攻击能力，同时降低正常 OOD 误报；随后研究新设备入网。两臂均使用全部已冻结的 15,073 条 A+B 训练目标，不是只修几条漏检，也不是手头全部原始数据的全量训练。旧 P2 只在合法的 A 训练白名单上提供教师信息，B 继续由真实标签学习。

通俗地说，上一轮让训练专用的辅助头模仿旧系统的内部贡献，但部署时另一个头负责打分。此次先要求真正打分的头学习教师判断，再比较“附加内部信息”是否值得学。辅助头学得像不再能代替真实分数监督；但没有声称以前的教师完全没用，也没有证明这次必然提升。

## 2. 证据支持什么、不支持什么

固定 C2 TRAIN 诊断已 COMPLETE/verified/sealed：教师到共享编码器的梯度非零；teacher/label 均值余弦 −0.851657，134/197 桶反向；任务方向误差 MAE 4.22779 logits。攻击内部教师/辅助读出相关 0.819036，而教师/部署分数相关 −0.187735。它说明辅助拟合和部署读出并不等价，支持把监督直接放到部署分数上。

**负夹角不是有害迁移的充分证据。** 正确攻击的 BCE 导数为 sigmoid(q)−1，仍希望 q 增大；若 q 已超过正确教师的有限目标 m，对称蒸馏导数为正，希望 q 回落，两者自然反向。正常样本也有对应情形。故不以“消除负夹角”作为新门槛，不把固定端点欧氏梯度当成历史 AdamW 轨迹或泛化因果。同类内部排序不同也不自动意味着攻击/正常分离失败。

C0 已有低误报区域退化，不能把所有损失归因于教师项。修好任务迁移只是本轮最有针对性的假设检验，不是已定位唯一根因。旧 P2 的 B 路径为缺失时全报警，不能把其 B 攻击命中当作内容识别；总体旧口径仍原样保留，同时必须分 A/B 解读。

## 4. 精确学习规则

真实部署始终为原 student 的 `qS=head(h)`，阈值 logit 0。输入、因果前缀、GRU、head 和 A 初始状态不变。部署 91,265 参数；R 额外使用训练专用 `D=Linear(128,128,bias=True)`，16,512 参数，权重/偏置全零初始化，h 不 detach；部署删除 D。

定义 H(v)=v²/2（|v|≤1），否则 |v|−1/2。教师白名单 T 原封不动：9,379 个训练 A 目标，其中攻击 3,357、正常 6,022；排除 B 5,671 和旧 P2 错判正常 A 的 23 条，仅从教师项排除，真实标签项一个不删。N_T0=2,957、N_T1=3,329。

对每个原训练桶 b 定义加权算子：

`M_b[f] = (197/2) * sum_y [(sum_{c in A_b with T_cy nonempty} mean_{i in T_cy} f(i)) / N_Ty]`。

整个固定端点目标的 M 为 `mean_b M_b`；训练仍按原桶逐次更新，不能用桶内重归一化替代此分母。

**Q：直接任务分数迁移。** 已封存的 canonical 教师 logit 为 qT，原概率阈值 pT=0.065159872174263。

`tauT = log(pT) - log1p(-pT)`；`mT=qT-tauT`；`s_q=max(1,sqrt(M[mT²]))`。

`L_q(b)=M_b[H((qS-mT)/s_q)]`。

tauT、mT、s_q 的派生在未来 P 中以 float64 计算并封存，s_q 此刻不取真实数值；训练使用一次转换后的 mT32、s_q32，按 `(qS-mT32)/s_q32` 的 float32 顺序计算。教师是否合格仍由旧 canonical_hard 判定；P 同时检查 mT64 与 mT32 的 `>=0` 是否与旧硬判一致。任一不一致即 STOP，保留原白名单、阈值及行数，不能静默丢行、改标签或修阈值。有限性也必须通过。

缓存接口明确：原 teacher_index 的行号键为 `row`，含 `canonical_logit` 与 `canonical_probability`，没有 `canonical_hard` 键。这里的旧硬判指保存的 canonical_probability 转 float64 后按原阈值比较，并与原 TRAIN plan 的 old_hard 及真标签核对；不重新 sigmoid、不重新跑教师。行号、UID、context_key、label 连接全部沿用原索引。

只做一个全局正尺度，不按类别或来源中心化，不把每条 margin 除成相同常数，不截断教师 margin，不从评估结果选择权重。系数 1 是固定尺度后的设计选择，不表示与 BCE 梯度同强或理论最优。直接迁移可能保留教师有用的边界/置信度，也可能仅相当于有限置信度正则，不能预先归因知识继承。

**R：在 Q 上加一个贡献结构项。** 复用已有 `t=c/s_T` float32 缓存，原 s_T=0.4098227709378718 不变。令 `P(v)=v-mean_128(v)*1`，先计算 `e=D(h)-t`，再 `r=e-mean_128(e)`。

`L_r(b)=M_b[(sum_{k=1}^{128} H(r_k))/127]`。

这是在原 128 贡献坐标中逐坐标 Huber 求和后除以子空间维数 127，**不是 mean_128 后再除 127**。不重新归一化剩余能量，不自适应加权，不据能量弱而增强信号。P 中只记录原/剩余能量供解释，不用它筛臂。该鲁棒损失不具旋转不变性。

| 新臂 | 总损失 | 要回答的问题 |
|---|---|---|
| Q | L_label + L_Aguard + L_q | 直接约束实际输出是否改善联合能力？ |
| R | L_label + L_Aguard + L_q + L_r | 额外贡献结构及其辅助训练包是否还有增量？ |

所有项系数均为 1。L_label、L_Aguard 的精确公式、代表目标循环、跨 component 配对和 s_A=29.98624610900879 全部继承已封存原配方；复用 guard 缓存，不重新选教师或保护样本。

代数上可以写 `zS=P(D(h))+qS/(128*s_T)*1`、`zT=P(t)+mT/(128*s_T)*1`，于是 `s_T*sum(zS)=qS`。这只说明任务方向由真实 head 承担；实现不需要构造 z，更不能用重构和替换部署 qS。float32 不逐 bit 保证恒等。L_q+L_r 也不是统一 Huber(zS−zT) 的严格分解。

**输出坐标正交不等于共享参数梯度正交。** R 项对 head 的直接梯度仍为零，经共享 h 却可影响 qS，仍可能冲突或引入来源捷径。方案没有证明剩余信息一定被部署 head 使用，亦不保证 R≥Q。

## 5. 固定预算与对照

两臂分别从完全相同的封存 A 独立开始，非 C2 续训。每臂 seed 2705、20 epochs、每轮 197 更新，共 3,940 更新、301,460 目标呈现；合计 7,880 更新、602,920 呈现。原 A/B 上下文排序、32 上下文 microbatch、A 后 B 梯度累计、一次全局 clip、一次 AdamW 更新保持。AdamW lr=1e−4、weight_decay=1e−4、betas=(0.9,0.999)、eps=1e−8、clip=1；其他旗标按 JSON，无 scheduler/早停/搜索。

Q 裁剪 student；R 裁剪 student+D。R−Q 是一个辅助学习包增量，包含额外参数及全局裁剪影响；不是已隔离的纯知识内容效应。只评估各自 epoch20；两臂全部封存后才 E，不依据中途表现选择模型或停科学上较差的一臂。

复用 C1/C2/C0/AB 已披露结果与未来授权 E 中的封存逐行参照，不重训历史臂。实现验收必须验证共同底座公式、更新/呈现和 optimizer 语义等价；若不等价则先 STOP，不能继续声称公平对照。Q−C1 比较直接任务迁移包，R−Q 比较额外贡献包，R−C2 为整个新配方差异，不能称 C2 单变量修复。

此次能力筛选不新增 Q_const/R_perm。但在论文中分别声称“逐样本教师知识有效”或“贡献结构本身有效”前，必须另做对应负对照（Q_const 保留类别/上下文权重与 s_q，以类别加权均值替代逐样本 margin；R_perm 保持 Q，按同标签及 eligible-context-size 固定置换剩余目标）。这些是后续有正信号才设计冻结的归因实验，此次不执行、不预定自动继续。

## 7. 联合判定、继续与退出

保留原评价：固定 logit0 的 overall/future/16族宏均值及逐族、A/B、4个正常 OOD 池/池宏均值/最差池、151条 ID 检查与逐目标翻转；同时报告用一个全局数学阈值、整组处理 ties 的 TPR@FPR≤1%，以及 0.1%、AUROC 和同阈值逐族召回。排序阈值只用于描述，不部署、不回流训练。ID=151 不足以支撑 0.1% ID 误报结论；18,000 OOD 的 0.1% 对应最多 18 个误报，不能称高精度稳定估计。

一个对照的 development_joint_gain 仍用原口径：主排序、固定 overall/future/family-macro 召回、OOD pool-macro/worst FPR 均不劣，至少一项改善；单 seed 小差不能叫突破。除此机械口径，0.1% 退化和逐族/逐池崩塌必须显著披露，不能被平均数掩盖。原共同 A-check 的零回退诊断分别对旧 P2 与固定 A 做，历史严格 FAIL 不会被本实验覆盖。

实用里程碑仍需对齐旧总攻击 237,631/244,050、future 127,027/131,391 的精确计数，并与正常 OOD 改善联合判断；另保留 AB 的低 FPR 优势作参照，不凭相对 C1 小涨就宣布恢复。99.99%/97% 是愿景，未成为本次门槛。future-query 也不能自动等同全新未见攻击族。

## 8. 对突破可能性的判断与审查结论

**攻击和 OOD 同时改善在机制上可能，但目前没有充分证据估计概率或保证幅度。** 教师在合法 A 上提供攻击/正常两侧的有限分数，B 真实标签又可纠正旧系统的缺失行为；如果当前瓶颈确是有效判断未进入部署输出或过度置信，Q/R 有机会共同受益。若旧教师携带来源偏差、共同前端缺少必要行为信息、训练覆盖不足，则二者都可能失败。新设计无法凭空制造训练中没有的新设备/攻击行为。

训练22来源组/24成员均为单标签，上下文也单标签，没有已核验同设备正常/攻击交叉；约93.41%训练攻击集中在 ToN 两族，B 攻击仅71条。故暂不把来源去相关或因果设备不变性写成可由本数据证明的创新。后续 CIC IoT2022 配对入网数据的已有 PENDING 路线仍保留，但不替代当前核心能力验证。

独立数学/协议审查支持本次两臂有信息价值，并已纳入：BCE 饱和反例；Huber/127 精确分母；阈值浮点边界 STOP；输出正交不保证梯度正交；Q 有限置信度混淆；R 正则/裁剪混淆；F5 已做直接 margin 的历史；AB 低 FPR 对照。未加入被建议为可选的额外训练梯度探针，避免扩大此轮测量；原训练日志与终点拟合已足够先判能力。

当前贡献定位是有依据的迁移修正假设。分解、Huber 和 KD 本身不是论文创新；只有联合能力增益、对应归因对照及独立确认成立，才能论证项目的实质贡献。本轮没有科学新结果。
