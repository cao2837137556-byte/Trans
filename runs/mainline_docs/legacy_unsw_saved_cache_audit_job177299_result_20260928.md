## 对修复方向的影响

本轮命中原规格的第一条结果分支：后期查询的有效源字段与保存特征共同恒定。它表明现有判定无法利用这段后续输入的时间/速率变化修正早期判断。当前优先级应从继续调检测头，转为设计持续判定的输入与状态更新契约。

下一步是方案设计与审查，重点不是再增加模块数量：

1. 明确每次判定要表达的当前行为，以及部署可执行的因果状态更新/过期规则。优先检查在已有 E3 容量内使用近期内容能否补足所缺信息；是否需要跨连接行为统计由任务证据决定，不预先堆叠。
2. 状态边界不能由攻击标签、未来流量或已知攻击区间决定。训练、入网参考、校准、评估使用同一输入语义；不能只替换外部测试输入并沿用旧阈值宣布提升。
3. 保留两条独立责任：Q 需要提升跨来源攻击判别；正常参考相似不应自动成为撤销强攻击证据的充分条件。已经尝试过的条件头、最坏参考保护、简单增加训练轮数不是新的突破点。
4. 方案要包含最低成本的机制验证和停止条件，再决定真实能力训练：既要验证后续变化确实可见，也要保留原数据能力、ID/OOD 误报和最终攻击检出约束；不以输入变化或合成 PASS 代替性能提升。
