## 当前最有证据支持的研究判断

项目已经分别获得“攻击与部分OOD区分”的能力证据，以及“统一输入覆盖与
新增流量学习”的工程/开发证据。尚未把二者汇合为一套经充分验证的统一系统。
研究投入应以**统一输入上的可迁移正常/攻击表示学习**为主，优先处理有用
信息、学习覆盖和表征质量；末端阈值、门控、正常分支暂不列为默认突破口。

旧E3/P2是能力参照，统一前端与新GRU是实现起点。不能默认GRU就是最终编码器，
也不能因旧netFound有正信号，就把预训练的单独因果收益视为已证明。更强表示、
保留有效历史/字段、补足训练行为对照是需要取舍的能力来源；具体机制仍须
相关文献、兼容性与证据支持，本文不虚构已选定的新架构。

“模型能力”和“数据”不能完全割裂：CKDC的获准选择池有4,986条正常冲突，
却没有P2报警/M7正常这一危险象限的攻击样本。它说明当前学习/选择证据缺少
关键反例，不是paper04完全没有此类攻击（历史已披露诊断在其他用途分区观察
到它们）。那些历史暴露不能自动转为合法训练或独立确认。简单融合两种旧
能力也已受检验：CKDC-D0F的全视图正常证书覆盖正常冲突为0，路线关闭。

输入覆盖不等于信息充分；现模型91,265参数且从头训练，不能据此断言容量够
或不够；旧netFound也有困难OOD失败，不能承诺换大模型就解决。小池有限拟合
见证与继承测试不重做，历史严格继承FAIL保留，不用修改旧判定来宣布进步。

## 本轮收敛的学习机制假设（未冻结、未实现）

优先研究：在可比环境内学习正常与攻击的差别，再学习哪些差别能在其他环境
复现。编码器与判别器共同接受真实标签及匹配对照监督；保留不同正常行为
模式，仅对语义核实为同一攻击机制的跨环境关系施加约束。不能把所有正常
压成一个中心、把所有攻击压成一个方向，也不把观察配对宣称为因果干预。

该假设针对环境/业务变化与攻击标签混杂的风险，尚未证明它是当前全部失败
的根因。它与CKBB的E/R/H历史残差、CKBJ的时序/自监督任务及正常释放门的
差别在于新增有区分力的监督关系。旧方案没有提供此关系，不代表此关系必然
有效；当前GRU的容量和F4的信息充分性也仍是需要实证判断的因素。

真实前提是多个环境各有可比正常与同机制攻击；训练环境之外另有独立环境
才能检验迁移。现有审计未建立这种交叉：CKDE-R的5个攻击设备各无更早合法
同设备正常，设备×攻击族无交叉环。Gotham/ToN的扫描或暴力破解标签也不能
自动视为同机制。数据缺口因此可能在训练侧，不能只补新设备正常测试流量。
接续现有合法元数据与CIC IoT2022的PENDING节点；不足时明确需要何种受控
采集或新数据获取，不用合成身份变化冒充真实环境。该假设的特定数据前提
不构成“所有其他表示学习均须等待配对数据”的一般结论。

决定性比较须让普通监督学习与新机制使用相同数据、输入、编码器和训练预算，
在留出环境看正常OOD误报与攻击保持能否共同改善；可用正确配对与打乱配对
的对照检查收益是否依赖真实关系。若普通学习已获得相同收益，应归于数据
补足；若收益依赖牺牲攻击或不能迁移，不通过机制假设。具体预算、门槛和
执行协议尚未制定，更未改动旧冻结条款。跨环境已知机制迁移、未见攻击族
泛化和新设备正常历史适应分别取证，不互相替代。

本轮定向文献核对：

- [Domain Generalization using Causal Matching, ICML 2021](https://www.microsoft.com/en-us/research/publication/domain-generalization-using-causal-matching/)：作者页指出按类别直接对齐不足，提出对象匹配；视觉/医疗证据不能直接证明网络流量适用。
- [A Novel Contrastive Loss for Zero-Day Network Intrusion Detection, TNSM 2026](https://arxiv.org/html/2601.09902v1)：CLAD用正常/攻击监督学习正常vMF分布，CLOSR扩展到开放集识别；主实验为Lycos2017，结论仍把跨网络泛化与few-shot列为后续工作。它是相关比较候选，未证明本文正常OOD与攻击共存目标已被解决。

配对、对比损失和不变性学习均不是新概念。潜在贡献必须来自经验证的流量
对照构造及可迁移判别机制，不能先用方法名称宣布创新或论文档次。

也不能凭“高阶模型”“正常历史”这些名称制造效果确定性。

论文的目标问题保持稳定；一区投稿潜力取决于可解释的方法贡献、相对强基线
的联合收益和可信泛化证据，不能从一个误报率、模型大小或工程PASS数量判断。
本轮仅完成现状统合与优先级判断，无训练、额外推理、受限访问、下载或HPC。
