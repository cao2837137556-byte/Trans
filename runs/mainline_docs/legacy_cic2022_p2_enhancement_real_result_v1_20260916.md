使用冻结的原五个正常开发池（辅助正常＋四个 OOD），要求每池经验 FPR≤1%，原始概率曲线上的攻击检出为 **R 90.9224%、B 57.5735%、C 57.2720%**；raw-logit 对应为 90.9224%、57.5735%、57.2731%。因此退化不只是旧固定阈值不再适配，同一表示上的 P2 更新也恶化了本开发池的低误报区分表现。这里 E3 表示始终冻结，不能把本次结果归咎为“新前端失败”。曲线仅作描述，未选择或部署新阈值。
