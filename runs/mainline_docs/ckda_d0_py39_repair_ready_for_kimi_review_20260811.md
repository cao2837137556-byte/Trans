## Exact repair

`repo/ood/issue27ckda_netfound_py39_compat_v1.py` applies one fail-closed,
syntax-only transformation to a copied vendor tree:

1. require the exact upstream file SHA-256 above;
2. require exactly one literal `match problem_type` block;
3. replace it with the semantically equivalent `if/elif/else` branches;
4. parse all 17 vendored Python files using the Python 3.9 AST grammar;
5. emit `PY39_COMPAT_AUDIT.json` with upstream and patched hashes, replacement
   count, source count, and `semantic_change=NONE_SYNTAX_EQUIVALENT_IF_ELIF`.

The official source cache and checkpoint are not modified.  The model
checkpoint identity remains 698,780,900 bytes and SHA-256
`e6237f49ce58840f8bf7d0cafa5ae80f58d05ea158053d031792d0369d7f5105`.

The login-node installer now compiles every vendored netFound Python source
with the actual frozen Python interpreter before `sbatch`.  Therefore this
failure class is moved from a compute allocation to a pre-submit gate.
