## 对增强实验有实际影响的发现

内部 `6-Attacks/Readme.txt` 写明两大类：LOIC Flood，选项为HTTP/UDP/TCP；RTSP brute force，工具为Nmap/Hydra，之后还测试直播端点。根 README 写“三种攻击”，本包内部则写“两种”；保留工具和目录层次，不能据此自行制造多个独立未见攻击家族。

关键原文：**“The network traffic was captured on the attacker machine for 3 or more minutes.”**

这意味着攻击捕获来自攻击机。同一设备的正常交互如果在其他位置捕获，报头可见性、方向、背景流量和连接完整性可能不同。只有同设备名称不足以证明方案需要的可比正常—攻击环境；否则模型可能利用采集差异。当前没有正常内部说明，尚不能断言差异必然存在或本数据必然不可用。

README没有给出攻击者/受害者具体地址、攻击起止时间或逐连接标签。它提供实验来源，不能把攻击文件中的每条连接都标为攻击。攻击后直播验证也可能包含正常业务行为，未匹配到攻击依据的连接不能自动变成正常负例。

因此当前收获是明确的原始候选与新的采集说明，**没有模型能力提升结果，也没有合格训练行数**。这不是需要重跑旧实验的问题；需要解决的是新增监督能否真实区分攻击行为与正常业务。
