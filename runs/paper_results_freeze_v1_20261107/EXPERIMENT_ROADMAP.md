# 冻结方法后的实验优先顺序

结果：下一阶段以同口径基线对比为主，补齐外部确认、统计可靠性和运行代价，暂不修改主模型。
影响：现有2×2后处理消融、前端RAW消融、历史参考对照及全种子/全设备结果可复用，不必全部重跑。旧2026-07基线草案和2026-11-01论文清单仅作问题来源，其115维、385标签预算、27/37/47种子和旧C3配置不能直接移植到当前790维版本。
下一步：完成资产盘点、正式同口径执行卡和真实切片预算预检后再提交；本清单未提交任何作业，也未授权修改冻结方法。

## 1. 第一优先：基线比较

目标是回答两个不同问题：完整检测系统是否有竞争力，以及相同融合头的复杂正常参考修正是否优于简单方法。两类比较分表，不能拿内部RAW/C5消融替代外部检测器。

|对比层次|建议候选|公平输入和作用|当前状态|
|---|---|---|---|
|完整检测系统|Kitsune/KitNET|保留其原生AfterImage流式特征与正常训练流程；对齐实际查询端点，使用同等合法正常数据访问范围|仓库有历史谱系，但尚未确认与本冻结版全口径一致的可直接复用结果|
|同冻结表示的经典检测器|Isolation Forest|在预先固定的表示上训练，单独报告是否包含编码器成本；不能拿其低成本训练掩盖共享特征提取成本|需固定特征块、训练池及源域超参数选择规则|
|同冻结表示的神经基线|Autoencoder或Deep SVDD，首轮选一个|正常拟合；与有攻击监督的本方法明确标注标签信息差异，不能将差异全部归于模型优劣|需审核现有实现/资产并冻结一个候选；不同时铺开大量训练|
|有攻击监督的简单头|逻辑回归或小型树模型，首轮选一个|与FUSION790共享合法源FIT攻击标签、表示和源CAL规则，检验复杂小头是否必要|需盘点已有头；若无等价资产则为新基线训练，不是主模型修改|
|相同FUSION790上的后处理|普通1-NN/固定k-NN或单组件支持修正|参考库、三个空间、尺度、守卫和阈值条件对齐；固定一个最近邻版本，不按目标成绩选k|可优先复用超算分数/参考数组；移除双组件约束单独标明为机制消融|

建议先做“简单近邻后处理＋一个经典同表示基线”的真实切片，检查端点、校准与预算后批量运行其余代表性基线。没有完成适配和实测前不给出虚构总时长。若论文声称优于近期先进方法，还需依据最终论文贡献与任务设置补一个真正相关的近期方法；上述最小集合本身不支持SOTA结论。

候选实现来源已核对：[Kitsune作者实现](https://github.com/ymirsky/Kitsune-py)、[scikit-learn IsolationForest官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.IsolationForest.html)、[Deep SVDD作者实现](https://github.com/lukasruff/Deep-SVDD-PyTorch)。这些链接只证明可审计的实现入口，不表示已固定依赖版本或证明适合本数据。正式执行前记录commit、许可证、环境和网络离线闭包。

### 正式执行卡必须固定的共同比较条件

1. 同一A/B/Edge查询UID、标签、普通/分层加权/HT权重、建档后及全视图，不能只对某基线删除难样本；缺少有效输出要单独报告覆盖率，不能默认为正常。
2. 同一数据访问上限：合法源FIT/CAL和目标建档正常数据，完整库实验也允许可适配基线接触相同历史正常资料。各方法实际使用哪些信息须逐项列明；不能只给本方法历史库而不给比较方法。两小时-only另成匹配信息条件的附表。
3. 阈值数值因分数尺度不同而允许不同，但按相同、预登记的源CAL正常误报预算规则确定；本方法现有阈值保持不变。不得在A/B/Edge标签上找最优阈值，再作为部署性能。目标正常重校准如需比较，单列为事先定义的适配臂，不能混入源校准主表。
4. 超参数、归一化、早停和模型选择只使用合法源数据及预登记的正常建档适配流程。目标查询标签只用于最后评价。统一种子27/127/227和算术集成规则；不挑最好种子。正常单类方法与攻击监督方法分栏报告标签权限。
5. 原生表示的系统比较与相同表示的分类器比较分开，避免故意让成熟方法使用不适合的输入；不能把适配版称为无改动的原论文复现。逐包与逐连接输出对齐规则必须先通过真实UID/时间端点检查。
6. 同时报告普通/加权正常误报、HTTP/UDP和其他攻击分组检出、误报数、漏检数、设备与种子，以及资源。ROC/PR只能作评分能力辅助，不替代固定阈值的主结果。A/B/Edge已消费身份不因新基线运行而改变。

## 3. 已有结果可以回答和不能回答的内容

- T2已经完成几何×尺度消融；不需要为了换表名重跑。
- T3提供同配方REFIT782、STATS8、FUSION790的RAW对照；分块置零/置换诊断可解释固定模型依赖，不等同重新训练消融，不能据此声称每一维都必要。
- T4及供体留存审计提供历史参考覆盖证据；“无历史库”下降不应算作三维几何算法的独立缺陷，也不能包装成历史资料免费的优势。
- 三个训练种子已完成，集成好不等于每个种子稳定；暂不通过增加种子或挑选种子修饰结果。
- 原99.9%全口径目标未达并不妨碍做公平对比和写论文，但必须保留目标及实际差距。不能保证基线会输，也不需要等所有指标都成为100%才开始写作。

## 4. 最小执行顺序

冻结主方法与论文表（本轮完成）→ 盘点基线资产并固定同口径执行卡 → 真实切片预检与资源预算 → 同口径基线运行 → 配对统计和端到端开销 → 合格未参与设计数据的冻结确认。外部数据资格盘点可与基线准备并行进行；所有大工件在超算处理，仅回收结果、诊断和SHA。敏感性与事件延迟按最终论文主张补充，不阻塞开始写方法和已有结果章节。
