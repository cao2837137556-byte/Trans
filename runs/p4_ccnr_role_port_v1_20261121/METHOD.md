# 冻结 v12 上的 TCP 角色与服务端口参考筛选

本轮是中性配对检验。主结果事前指定为 **R2＋U1**。六种筛选组合和两个覆盖对照全部报告。60 秒旁路那一轮的目标和误报预算仅作参照。

| 配置 | TCP 服务端查询 | TCP 客户端查询 |
|---|---|---|
| R1 | 同角色 | 同角色 |
| R2 | 同角色、同本地服务端口 | 同角色 |
| R3 | 同角色、同本地服务端口 | 同角色、同远端服务端口 |

U1 的未知角色仅与未知角色匹配，未知无服务端口条件。U2 的未知查询支持置零、未知参考排除。UDP 沿用原规则。参考与查询都按各自原始捕获前缀中的首次初始 SYN 无 ACK 确定受保护设备角色。只观察到入站 SYN 时受保护设备为服务端，只观察到出站 SYN 时为客户端。记录当前帧之前的连接状态，当前初始 SYN 即时计入。同一尚未关闭生命周期的同方向、同初始序列号 SYN 视为重传。可辨别的新初始 SYN 重新判定角色，RST 或双向 FIN 后再见初始 SYN 也新建状态。反向同时开时用首个已观测到的发起方向，另计该类证据。已见 SYN 后可以在该采集分段内保持角色，接入中途且截至当帧无起始证据记 unknown。参考元数据有原包物理帧号时用该帧在原始捕获顺序的前缀，沿用冻结时间与开放资格。

原 v12 的时间窗口、同设备与协议、三空间半径和联合距离、双组件取较弱者、模型及分数、源阈值、p=4、λ=0.25、SYN 旁路全部来自已验收缓存。R2 完整对照在全部满足条件的原参考中检索。覆盖对照仅用 R2 的不同合法组件数，少于两个则回到 RAW，其余沿用原 v12。两个 U 口径独立检查逐查询及四个头的告警集合包含关系。连接级归因为 v12→覆盖→R2 的互斥新增，有覆盖通道告警的连接计入覆盖项，剩余新连接计入重匹配项。每个查询或连接沿用原权重前的全量分母，原有告警的保留率以 RAW 该组有警数为分母。

Win10 主结果限旁路外带数据包，18,194 条合格连接、RAW 14,024 条、原 CCNR 245 条。全包副视图、ToN .152/.190、Edge 密码 POST/全包、正常全量和旧泛洪并列。Edge 正常另外按角色和确定的服务端口分层。从上一轮已封存的原获胜供体和身份证据重新绑定 73 条 502 与 1 条 443，记录原两小时参考的 502 组件规模、两臂按时点合法组件数、实际可替代的相容组件和误报变化。这些查询全部在主 Edge 误报分母内。合法网页登录正常样本沿用原资格核查。

正式评价前，分别在实际计算节点做完各池的引用和查询身份、完整角色覆盖清点、原始帧角色抽核及实际小切片支持重算。原包、特征和大数组留超算。小表、中文摘要、各阶段回执与 SHA-256 回传 D 盘。
