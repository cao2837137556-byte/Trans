# Edge 同参考信息预算的独立 kNN 对照

结果：标准 `k=5` 距离对照已实现，源 CAL 的四个 RAW 加权误报工作点已完成校准，未读取任何 Edge 模型分数。
影响：外部执行时可比较 RAW、同库 p1 消融、冻结 C5/p3 与独立 kNN。kNN 只有一个距离分数，四个阈值对应四个源工作点，不是四个独立检测头。
下一步：真实切片只核验运行与接口；正式外部评价仍需整体执行卡冻结及用户授权。完整论文的强基线组合仍未宣称齐备。

## 固定方法

`knn5.py` 实现常规点级 kNN 异常距离：先按原源域 normalizer 标准化 768 维 E3，再做 L2 单位化，取第五近邻的欧氏距离，越大越异常。k 在任何距离计算之前固定为 5；不按源或外部效果搜索 k。

参考信息预算与 C5 相同：同一批合法两小时参考、同设备/协议、相同完整银行可用时间及物理帧约束，无外部额外历史，无评价期正常吸收。该标准距离对照选择只使用 E3，未使用可见的 q14 或三头 logit 作为特征；使用信息子集不等于额外预算。kNN 允许同组件不同点作近邻，不借用 C5 双组件支持机制。少于五个合法参考、银行尚未可用或参考/查询 UID 重放时保留 RAW。独立检测器未附加 SYN 守卫：它的保护范围与 C5 不同，源攻击召回和外部结果均须如实报告。

源正常 CAL 的 `core.class_weights` 与原 RAW 完全相同。固定未评分行 RAW 的误报质量后，在有限距离上选取使加权误报不超过 RAW 目标的最小阈值；比较符为严格 `>`，同分成组，保守处理无法精确匹配的离散工作点。源攻击只用于校准后的召回报告，未用于阈值选择或强制零撤警。没有调大阈值以“保护”结果，也没有按源召回换 k。

这是独立标准非参数比较器，并非给 p1 换名字。它仍依赖同一冻结表征，不能替代整个论文中其他表征/独立检测范式的强基线。后续如需训练 Isolation Forest、OCSVM 或神经基线，应单独明确其训练数据、信息预算与授权。

## 已完成的源侧证据

- 原封存源 CAL：33,147 正常、115,672 攻击；合法 kNN 评分分别为 30,197 / 108,593，其余 10,029 行固定 RAW 回退。
- 实际 46,931,467 距离对，2 CPU 线程，11.19 秒，峰值 RSS 1,076,592,640 字节。预先硬上限为 600 秒 / 1.5 GiB；未扩展预算。
- 四阈值（27、127、227、ensemble 工作点）为 `1.1929950558809033`、`1.1996403182574658`、`1.1966587586932518`、`1.1923376342171`。
- ensemble 源正常加权 FPR：RAW `0.9743052620%`，kNN `0.9742126164%`。源攻击加权召回 `89.2105256508%`；它是源 CAL 描述，不能当独立泛化结果。
- 所有源输入已核对既有 SHA；`SOURCE_INPUT_SEAL.json` 在距离计算前锁定合同、实现与输入。
- `test_knn5.py` 检查真实第五近邻算术、同组件合法性、可用时间、帧边界、UID 连接、回退、同分工作点与源 donor 限制。
- `verify_source.py` 独立用直接欧氏相减核对固定 64 条源样本、严格阈值决策、RAW 回退、保守源 FPR 与阈值最小性。

## 接口

`KNN5Bank(ref_rows, ref_e3, normalizer, feature_uids=...)` 创建固定银行；`distances(query_rows, query_e3, feature_uids=...)` 返回 `distance/reason/pairs`。NaN 距离表示显式 RAW 回退，不表示无异常。

`decisions(distance, raw_four_decisions, SOURCE_CALIBRATION.json['cuts'])` 返回一个距离分数在四个固定工作点下的决策。外部过程禁止调用 `source_cuts`、修改 `k` 或重拟阈值。

`calibrate_source.py` 只读本地既有源数组，并拒绝覆盖已有结果。大数组 `SOURCE_KNN_ARRAYS.npz` 保留本地、仅备份 SHA；源码、合同与小回执可入 Git。
