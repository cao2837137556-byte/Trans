`SLICE_CARD.json` 在任何 Edge 模型运行之前由 adapter 的 `preflight_plan_r2_stratified/SLICE_FRAME_PLAN.json` 转换并附 SHA。65 个合法原始物理端点固定为 20 个参考（TCP 16、UDP 4）、17 个正常查询、12 个 HTTP 查询（SYN/PSH+ACK/ACK-only 各4）和16个 UDP 攻击方向查询。选择仅依赖原包头部、时间与组件身份，不依赖模型。小参考子集只用于接口，不充当正式外部库。

执行入口：`run_preflight.py --slice SLICE_CARD.json --output <new-directory>`，正式运行时还须加 `--strict-runtime`。入口不覆盖已存在目录；监督子进程600秒硬停、1个数值线程、6 GiB进程树RSS、100个逻辑编码端点及10000个小样距离对硬上限；不会自动重试或提交作业。每阶段和每编码批留回执，故障终态保留。

精确待执行请求见 `RUNTIME_PREFLIGHT_REQUEST.json`，包含既有Linux依赖、1 CPU/6 GiB/600秒上限、完整交付清单、`--tshark` 与 `--raw-directory` 路径映射及禁止通过后自动评价的边界。这是准备好的请求，不是已经提交的超算任务。
