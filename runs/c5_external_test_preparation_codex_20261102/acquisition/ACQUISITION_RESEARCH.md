## 2. 新查明、会影响资格判断的事实

作者预印本第 4.2—4.4 节补充了此前官网摘要没有给出的细节：

- 真实 Wi-Fi 目标为 **7 台：3 个医疗设备与 4 台摄像头**。目标名为 Sense-U Baby Monitor、SOS Multifunctional Pager、SINGCALL SOS Button、Ecobee Camera、Blink Mini、M1T Laxihub、Owltron。25 台真实设备总数不能直接当作当前 IP 前端的目标人口；控制 iPad、攻击 Raspberry Pi、AP/网关及 BLE/模拟目标须另分角色。MAC 表在预印本 Table 3 图中，本轮未逐行读取 MAC。
- Idle 记录为 **两次各 13 小时**；Singcall SOS 在 idle 不产生流量。Active 为分批累计 26 小时。Power 大约只有开机 2 分钟、关机后继续 3 分钟，单独不足当前 7200 秒观察合同。
- 原作者 train/test 是按 PCAP 文件分组约 80%/20%；它没有自动提供所需历史先后顺序。必须查真实时间及角色。

这些事实来自作者的早期公开版本，仍需以实际官方原包和最终设备表核实；尤其不能把全网 13 小时直接当作每台设备有 13 小时有效正常支持，更不能据此宣布历史早于攻击已成立。

官方已明示 TCP Flood、UDP Flood 及 SYN Flood 等类型。**没有从已读官方材料得到显式 ACK-flood 文件名、TCP Flood 的实际 TCP flag 分布或 UDP-IP-fragment 专类。** 作者预印本第 4.3.1 节只列攻击类型，没有给出 TCP Flood 生成命令或协议位；全文可搜索文字也未找到 hping、Scapy 或 ACK flood。因此不能由名字推断其使用 ACK。ACK/UDP 覆盖必须成为原包资格门：对明确攻击方向、时间和受害设备命中的包，分别统计 **攻击者→受害者的 ACK=1、SYN=0**（并细分 ACK-only、PSH+ACK、其它组合）和 UDP；SYN+ACK 单列，不能代替这一硬要求，仅看到反向响应中的 ACK 更不算满足 ACK 攻击覆盖。

## 3. 分两级取得最小材料

### 3.1 先取目录与小说明，不取整包

1. 保存登记后 `WiFi_and_MQTT/`、`profiling/`、`attacks/` 的完整目录页；继续进入实际原始 PCAP 的 train/test 子目录，记录叶路径、字节数和官方 URL。子目录层级以实际页面为准，不假定 `pcaps/` 等未核实名称。
2. 取 README/使用条款、设备型号—MAC—IP 表、攻击者/受害者映射、时间表、标签生成规则、采集日期/时区、公开校验值；不存在的项标为缺失。
3. 记录完整候选目录，才能区分“选择最小资格预检文件”与“按效果挑数据”。不要把 CSV 当作冻结原包前端的替代输入，也不需要全量 CSV。

### 3.2 目录核实后选择最小原包资格集合

|必须覆盖的角色|优先候选位置/类别|真实文件名与大小|资格目的|
|---|---|---|---|
|合法正常参考历史、7200 秒入网观察以及独立后段正常|profiling 的 idle 与 active 原始 PCAP；必要时使用有明确正常说明的 benign 原包|待登记目录核实|证实同一设备、真实先后、足够包数与持续时长；不能只用夜间静默证明正常覆盖|
|实际正常交互与正常 SYN 发起|active / interaction 中与入选设备对应的原包；若上行已覆盖则不另取|待核实|覆盖正常 ACK/载荷/UDP 与合法 SYN，检查 C2 在频繁发起连接设备上的代价|
|非守卫的直接 TCP 攻击|明确 TCP 攻击原包，优先 TCP Flood；须用官方标签/方向与真实 flags 验证 ACK 类|待核实|至少包含非 SYN 守卫、攻击者发出的 ACK 类攻击；不存在则 ACK 资格未过|
|直接 UDP 攻击|DoS UDP Flood 或 DDoS UDP Flood 原包|待核实|验证 UDP 型攻击及反向响应分账|

这是**角色集合**，不是承诺固定下载四个文件：一个文件可能覆盖多项，一项也可能需要多个分片。按目录元数据、时间和角色覆盖选择满足约束的最小总字节集合；同等候选按规范化相对路径确定次序。记录所有排除原因，不读取模型分数，不以 RAW/C5 效果选择设备、捕获或文件。

最小集合只用于资料/原包资格检查，不能直接冒充“数据量足够”的最终外部实验。正式评价清单须在资格后、模型揭盲前锁定；默认考虑全部合格真实 Wi-Fi 目标，资源不足时另在不看分数的前提下固定设备/日期覆盖策略，报告实际设备数、正常时长、场景/会话数与攻击子类数量。
