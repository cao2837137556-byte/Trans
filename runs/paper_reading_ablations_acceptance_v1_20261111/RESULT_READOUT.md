# 最终3D：SYN保护与指数消融正式验收

结果：两项均通过工程及指标一致性验收。SYN保护在B上保住295条攻击关联查询告警，代价是28条额外正常误报；p从1提高到3显著降低误报，进一步到4仍有收益，但会损失A的攻击告警。因此不能写成保护无代价、p=3唯一最优或p=4全面更好。
影响：为冻结最终3D配置补齐两项单因素证据。五配置共用同一模型/库/尺度/λ/阈值/查询，主方法仍为p=3且保护开启，不根据本批结果重新选参。

## 4. 论文可以怎样表述

可用正文草稿：在固定最终三空间几何、完整参考库与源校准工作点下，SYN保护在B上保留了295条原本会被修正撤销的攻击查询告警，同时保留28条正常误报，表明该规则具有可量化的攻击保持收益与正常告警代价。支持映射从线性提高到三次可显著减少正常告警，但并非对攻击无影响；从三次继续提高到四次仍可改善B/Edge误报，却在A上额外撤销6条集成攻击告警。因此结果体现的是跨评价条件的折中，而不是三次映射的唯一最优性或四次映射的全面优越性。

必须保留边界：
- 本批是预先固定配置的敏感性/机制消融，不是重新调参或更改冻结默认值。保留p=3+保护开启；不隐瞒p4在B和Edge上的收益。
- 全时段A的BASE加权误报仍为5.412342%，P4亦相同；Edge BASE种子127加权误报3.610879%、HTTP检出97.59%，不以集成好结果掩盖。
- 本批没有让Edge HTTP/UDP达到99.9%原目标；P4集成零正常告警也不能写成系统在部署上零误报。
- 不计算独立伯努利显著性或从相关查询推导事件检出率。未开展外部新数据、λ/双组件、端到端时延等额外实验。
